## 🟢 Easy

### 1. Reverse Linked List — LC 206

**Intuition:** Classic 3-pointer technique. Reverse every pointer one by one.

```java
public ListNode reverseList(ListNode head) {
    ListNode prev = null;
    ListNode curr = head;

    while (curr != null) {
        ListNode next = curr.next; // save next
        curr.next = prev;          // reverse pointer
        prev = curr;               // move prev forward
        curr = next;               // move curr forward
    }

    return prev; // new head
}
```

**Dry Run:**
```
List: 1 → 2 → 3 → 4 → 5

Step 1: prev=null, curr=1  →  null ← 1   2 → 3 → 4 → 5
Step 2: prev=1,    curr=2  →  null ← 1 ← 2   3 → 4 → 5
Step 3: prev=2,    curr=3  →  null ← 1 ← 2 ← 3   4 → 5
Step 4: prev=3,    curr=4  →  null ← 1 ← 2 ← 3 ← 4   5
Step 5: prev=4,    curr=5  →  null ← 1 ← 2 ← 3 ← 4 ← 5

curr = null → stop
return prev = 5 (new head) ✅
```

### 2. Palindrome Linked List — LC 234

**Intuition:** 3 steps — find middle → reverse second half → compare both halves.

```java
public boolean isPalindrome(ListNode head) {
    // Step 1: find middle using fast & slow
    ListNode slow = head;
    ListNode fast = head;

    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
    }

    // Step 2: reverse second half
    ListNode secondHalf = reverse(slow);

    // Step 3: compare first and second half
    ListNode left = head;
    ListNode right = secondHalf;

    while (right != null) {
        if (left.val != right.val) return false;
        left = left.next;
        right = right.next;
    }

    return true;
}

private ListNode reverse(ListNode head) {
    ListNode prev = null;
    ListNode curr = head;

    while (curr != null) {
        ListNode next = curr.next;
        curr.next = prev;
        prev = curr;
        curr = next;
    }

    return prev;
}
```

**Dry Run:**
```
List: 1 → 2 → 3 → 2 → 1

Step 1: middle = node 3
  slow stops at 3

Step 2: reverse from node 3
  second half: 1 → 2 → 3

Step 3: compare
  left:  1 → 2 → 3 → 2 → 1
  right: 1 → 2 → 3

  1==1 ✅
  2==2 ✅
  3==3 ✅

return true ✅
```

## 🟡 Medium

### 3. Reverse Linked List II — LC 92

**Intuition:** Navigate to node just before `left`. Then pull nodes one by one to front of sublist.

```java
public ListNode reverseBetween(ListNode head, int left, int right) {
    ListNode dummy = new ListNode(0);
    dummy.next = head;

    // Step 1: move prev to node just before left
    ListNode prev = dummy;
    for (int i = 1; i < left; i++) {
        prev = prev.next;
    }

    // Step 2: curr is the first node to be reversed
    ListNode curr = prev.next;

    // Step 3: reverse right-left times
    for (int i = 0; i < right - left; i++) {
        ListNode next = curr.next;
        curr.next = next.next;
        next.next = prev.next;
        prev.next = next;
    }

    return dummy.next;
}
```

**Dry Run:**
```
List: 1 → 2 → 3 → 4 → 5, left=2, right=4

prev = node 1
curr = node 2

Iteration 1:
  next = 3
  2.next = 4       (curr skips over next)
  3.next = 2       (next points to curr)
  1.next = 3       (prev points to next)
  List: 1 → 3 → 2 → 4 → 5

Iteration 2:
  next = 4
  2.next = 5
  4.next = 3
  1.next = 4
  List: 1 → 4 → 3 → 2 → 5 ✅
```

### 4. Swap Nodes in Pairs — LC 24

**Intuition:** Reverse every 2 nodes. Use dummy node to handle head swaps cleanly.

```java
public ListNode swapPairs(ListNode head) {
    ListNode dummy = new ListNode(0);
    dummy.next = head;

    ListNode prev = dummy;

    while (prev.next != null && prev.next.next != null) {
        ListNode first = prev.next;        // first node of pair
        ListNode second = prev.next.next;  // second node of pair

        // swap
        first.next = second.next;
        second.next = first;
        prev.next = second;

        // move prev to end of swapped pair
        prev = first;
    }

    return dummy.next;
}
```

**Dry Run:**
```
List: 1 → 2 → 3 → 4

dummy → 1 → 2 → 3 → 4
prev = dummy

Iteration 1:
  first = 1, second = 2
  1.next = 3
  2.next = 1
  dummy.next = 2
  List: dummy → 2 → 1 → 3 → 4
  prev = 1

Iteration 2:
  first = 3, second = 4
  3.next = null
  4.next = 3
  1.next = 4
  List: dummy → 2 → 1 → 4 → 3
  prev = 3

prev.next = null → stop

Result: 2 → 1 → 4 → 3 ✅
```

### 5. Rotate List — LC 61

**Intuition:** Rotating by k is same as breaking the list at position `(n - k % n)` and connecting tail to head.

```java
public ListNode rotateRight(ListNode head, int k) {
    if (head == null || head.next == null || k == 0) return head;

    // Step 1: find length and tail
    ListNode tail = head;
    int length = 1;

    while (tail.next != null) {
        tail = tail.next;
        length++;
    }

    // Step 2: make it a circular list
    tail.next = head;

    // Step 3: find new tail at position (length - k % length - 1)
    int stepsToNewTail = length - k % length - 1;
    ListNode newTail = head;

    for (int i = 0; i < stepsToNewTail; i++) {
        newTail = newTail.next;
    }

    // Step 4: break the circle
    ListNode newHead = newTail.next;
    newTail.next = null;

    return newHead;
}
```

**Dry Run:**
```
List: 1 → 2 → 3 → 4 → 5, k=2

Step 1: length=5, tail=5

Step 2: make circular
  5.next = 1
  1 → 2 → 3 → 4 → 5 → 1 → 2...

Step 3: stepsToNewTail = 5 - 2%5 - 1 = 5 - 2 - 1 = 2
  newTail = node 3

Step 4: newHead = 4
  3.next = null

Result: 4 → 5 → 1 → 2 → 3 ✅
```

## 🔴 Hard

### 6. Reverse Nodes in K-Group — LC 25

**Intuition:** Check if k nodes exist → reverse them → recurse on the rest → connect.

```java
public ListNode reverseKGroup(ListNode head, int k) {
    // check if at least k nodes remain
    ListNode check = head;
    int count = 0;

    while (check != null && count < k) {
        check = check.next;
        count++;
    }

    // less than k nodes remain → don't reverse
    if (count < k) return head;

    // reverse k nodes
    ListNode prev = null;
    ListNode curr = head;

    for (int i = 0; i < k; i++) {
        ListNode next = curr.next;
        curr.next = prev;
        prev = curr;
        curr = next;
    }

    // head is now tail of reversed group
    // connect tail to result of next group
    head.next = reverseKGroup(curr, k);

    return prev; // new head of this group
}
```

**Dry Run:**
```
List: 1 → 2 → 3 → 4 → 5, k=2

Call 1 (head=1):
  k nodes exist? Yes (1,2)
  Reverse 1,2 → prev=2, curr=3
  1.next = reverseKGroup(3, 2)

  Call 2 (head=3):
    k nodes exist? Yes (3,4)
    Reverse 3,4 → prev=4, curr=5
    3.next = reverseKGroup(5, 2)

    Call 3 (head=5):
      k nodes exist? No (only 1)
      return 5

    3.next = 5
    return 4

  1.next = 4 → 3 → 5
  return 2

Final: 2 → 1 → 4 → 3 → 5 ✅
```

### 7. Reverse Nodes in Even Length Groups — LC 2074

**Intuition:** Groups have sizes 1, 2, 3, 4... Reverse a group only if its **actual size is even**. Last group may be smaller than its group number.

```java
public ListNode reverseEvenLengthGroups(ListNode head) {
    ListNode prev = head; // prev always points to last node of previous group
    int groupSize = 2;    // start from group 2 (group 1 always has 1 node, odd)

    while (prev.next != null) {
        // count actual nodes in this group
        ListNode node = prev;
        int actualSize = 0;

        for (int i = 0; i < groupSize && node.next != null; i++) {
            node = node.next;
            actualSize++;
        }

        // reverse only if actual size is even
        if (actualSize % 2 == 0) {
            // reverse actualSize nodes starting from prev.next
            ListNode curr = prev.next;
            ListNode nextGroupHead = node.next;

            // disconnect group from rest
            node.next = null;

            // reverse the group
            prev.next = reverse(curr);

            // curr is now the tail, connect to next group
            curr.next = nextGroupHead;
        }

        // move prev to end of current group
        for (int i = 0; i < actualSize; i++) {
            prev = prev.next;
        }

        groupSize++;
    }

    return head;
}

private ListNode reverse(ListNode head) {
    ListNode prev = null;
    ListNode curr = head;

    while (curr != null) {
        ListNode next = curr.next;
        curr.next = prev;
        prev = curr;
        curr = next;
    }

    return prev;
}
```

**Dry Run:**
```
List: 5 → 2 → 6 → 3 → 9 → 1 → 7 → 3 → 8 → 4

Groups:
  Group 1 (size 1): [5]        → odd, skip
  Group 2 (size 2): [2, 6]     → even, reverse → [6, 2]
  Group 3 (size 3): [3, 9, 1]  → odd, skip
  Group 4 (size 4): [7, 3, 8, 4] → even, reverse → [4, 8, 3, 7]

Result: 5 → 6 → 2 → 3 → 9 → 1 → 4 → 8 → 3 → 7 ✅
```

## Summary Table

| Problem | Key Technique | Trick |
|---|---|---|
| Reverse List | 3 pointers (prev, curr, next) | Follow the 4-step order |
| Palindrome | Reverse second half | Find middle first |
| Reverse Sublist | Dummy node + pull nodes to front | Count right-left iterations |
| Swap Pairs | Dummy node + swap 2 at a time | prev tracks behind each pair |
| Rotate List | Make circular + break at new point | k % length handles large k |
| Reverse K-Group | Reverse k + recurse | Check k nodes exist first |
| Even Length Groups | Count actual size + reverse if even | Last group may be partial |
