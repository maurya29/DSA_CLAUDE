# All Dummy Node Solutions in Java

---

## 🟢 Easy

### 1. Remove Linked List Elements — LC 203

**Intuition:** Use dummy node so you can delete head node without special case. Check `curr.next.val` and skip if it matches target.

```java
public ListNode removeElements(ListNode head, int val) {
    ListNode dummy = new ListNode(0);
    dummy.next = head;

    ListNode curr = dummy;

    while (curr.next != null) {
        if (curr.next.val == val) {
            curr.next = curr.next.next; // skip the node
        } else {
            curr = curr.next; // only move forward if no deletion
        }
    }

    return dummy.next;
}
```

**Dry Run:**
```
List: 1 → 2 → 6 → 3 → 6, val=6

dummy → 1 → 2 → 6 → 3 → 6
curr = dummy

Step 1: curr.next=1, 1≠6  → move curr to 1
Step 2: curr.next=2, 2≠6  → move curr to 2
Step 3: curr.next=6, 6==6 → skip: 2.next = 3
Step 4: curr.next=3, 3≠6  → move curr to 3
Step 5: curr.next=6, 6==6 → skip: 3.next = null

Result: 1 → 2 → 3 ✅

Key: we do NOT move curr when we delete
     otherwise we might skip the next node
```

### 2. Remove Duplicates from Sorted List — LC 83

**Intuition:** Since list is sorted, duplicates are adjacent. If `curr.val == curr.next.val` skip `curr.next`.

```java
public ListNode deleteDuplicates(ListNode head) {
    ListNode dummy = new ListNode(0);
    dummy.next = head;

    ListNode curr = head; // start at head, not dummy (no deletion of head here)

    while (curr != null && curr.next != null) {
        if (curr.val == curr.next.val) {
            curr.next = curr.next.next; // skip duplicate
        } else {
            curr = curr.next; // move only if no deletion
        }
    }

    return dummy.next;
}
```

**Dry Run:**
```
List: 1 → 1 → 2 → 3 → 3

curr = 1

Step 1: curr=1, next=1, 1==1 → skip: 1.next = 2
        List: 1 → 2 → 3 → 3
Step 2: curr=1, next=2, 1≠2  → move curr to 2
Step 3: curr=2, next=3, 2≠3  → move curr to 3
Step 4: curr=3, next=3, 3==3 → skip: 3.next = null
        List: 1 → 2 → 3

Result: 1 → 2 → 3 ✅
```

## 🟡 Medium

### 3. Remove Nth Node From End — LC 19

**Intuition:** Dummy + fast & slow. Move fast N+1 steps ahead so slow stops just BEFORE the target node.

```java
public ListNode removeNthFromEnd(ListNode head, int n) {
    ListNode dummy = new ListNode(0);
    dummy.next = head;

    ListNode slow = dummy;
    ListNode fast = dummy;

    // move fast n+1 steps ahead
    for (int i = 0; i <= n; i++) {
        fast = fast.next;
    }

    // move both until fast hits null
    while (fast != null) {
        slow = slow.next;
        fast = fast.next;
    }

    // slow is just before target node
    slow.next = slow.next.next;

    return dummy.next;
}
```

**Dry Run:**
```
List: 1 → 2 → 3 → 4 → 5, n=2

dummy → 1 → 2 → 3 → 4 → 5

Move fast n+1=3 steps:
  fast = 3

Move both until fast = null:
  slow=1, fast=4
  slow=2, fast=5
  slow=3, fast=null → stop

slow.next = slow.next.next
  3.next = 5 (skip 4)

Result: 1 → 2 → 3 → 5 ✅

Why n+1 steps? So slow lands BEFORE
the target, not ON it — needed to delete!
```

### 4. Partition List — LC 86

**Intuition:** Two dummy nodes — one collects nodes less than x, other collects nodes >= x. Connect them at the end.

```java
public ListNode partition(ListNode head, int x) {
    ListNode lessHead = new ListNode(0);    // dummy for < x list
    ListNode greaterHead = new ListNode(0); // dummy for >= x list

    ListNode less = lessHead;
    ListNode greater = greaterHead;

    ListNode curr = head;

    while (curr != null) {
        if (curr.val < x) {
            less.next = curr;
            less = less.next;
        } else {
            greater.next = curr;
            greater = greater.next;
        }
        curr = curr.next;
    }

    // IMPORTANT: cut off any old links from greater list
    greater.next = null;

    // connect less list to greater list
    less.next = greaterHead.next;

    return lessHead.next;
}
```

**Dry Run:**
```
List: 1 → 4 → 3 → 2 → 5 → 2, x=3

curr=1: 1<3  → less:    dummy1 → 1
curr=4: 4>=3 → greater: dummy2 → 4
curr=3: 3>=3 → greater: dummy2 → 4 → 3
curr=2: 2<3  → less:    dummy1 → 1 → 2
curr=5: 5>=3 → greater: dummy2 → 4 → 3 → 5
curr=2: 2<3  → less:    dummy1 → 1 → 2 → 2

greater.next = null  (cut old links!)
less.next = greaterHead.next

Result: 1 → 2 → 2 → 4 → 3 → 5 ✅

Why greater.next = null?
  Last node in greater (5) might still
  point to something old — must cut it!
```

### 5. Odd Even Linked List — LC 328

**Intuition:** Two dummy nodes — one for odd positions, one for even positions. Connect odd list to even list at the end.

```java
public ListNode oddEvenList(ListNode head) {
    if (head == null) return null;

    ListNode oddDummy  = new ListNode(0); // dummy for odd positions
    ListNode evenDummy = new ListNode(0); // dummy for even positions

    ListNode odd  = oddDummy;
    ListNode even = evenDummy;

    ListNode curr = head;
    int position = 1;

    while (curr != null) {
        if (position % 2 == 1) {
            odd.next = curr;
            odd = odd.next;
        } else {
            even.next = curr;
            even = even.next;
        }
        curr = curr.next;
        position++;
    }

    // cut old links
    even.next = null;

    // connect odd list to even list
    odd.next = evenDummy.next;

    return oddDummy.next;
}
```

**Optimized (without position counter):**
```java
public ListNode oddEvenList(ListNode head) {
    if (head == null) return null;

    ListNode odd  = head;
    ListNode even = head.next;
    ListNode evenHead = even; // save even head to connect later

    while (even != null && even.next != null) {
        odd.next  = even.next;  // odd skips even
        odd       = odd.next;

        even.next = odd.next;   // even skips odd
        even      = even.next;
    }

    odd.next = evenHead; // connect odd tail to even head

    return head;
}
```

**Dry Run:**
```
List: 1 → 2 → 3 → 4 → 5

odd=1, even=2, evenHead=2

Iteration 1:
  odd.next = 3  → odd list:  1 → 3
  odd = 3
  even.next = 4 → even list: 2 → 4
  even = 4

Iteration 2:
  odd.next = 5  → odd list:  1 → 3 → 5
  odd = 5
  even.next = null → even list: 2 → 4
  even = null → stop

odd.next = evenHead(2)
  1 → 3 → 5 → 2 → 4

Result: 1 → 3 → 5 → 2 → 4 ✅
```

### 6. Swap Nodes in Pairs — LC 24

**Intuition:** Dummy node gives you a `prev` before the first pair. Swap each pair by relinking, then move prev forward by 2.

```java
public ListNode swapPairs(ListNode head) {
    ListNode dummy = new ListNode(0);
    dummy.next = head;

    ListNode prev = dummy;

    while (prev.next != null && prev.next.next != null) {
        ListNode first  = prev.next;       // first node of pair
        ListNode second = prev.next.next;  // second node of pair

        // swap
        first.next  = second.next; // first skips second
        second.next = first;       // second points back to first
        prev.next   = second;      // prev points to second (new front)

        // move prev to end of swapped pair
        prev = first;
    }

    return dummy.next;
}
```

**Dry Run:**
```
List: 1 → 2 → 3 → 4
dummy → 1 → 2 → 3 → 4

prev = dummy

Iteration 1:
  first=1, second=2
  1.next = 3         → 1 → 3
  2.next = 1         → 2 → 1 → 3
  dummy.next = 2     → dummy → 2 → 1 → 3 → 4
  prev = 1

Iteration 2:
  first=3, second=4
  3.next = null      → 3 → null
  4.next = 3         → 4 → 3
  1.next = 4         → 1 → 4 → 3
  prev = 3

prev.next = null → stop

Result: 2 → 1 → 4 → 3 ✅
```

## 🔴 Hard

### 7. Remove Duplicates from Sorted List II — LC 82

**Intuition:** Delete ALL nodes that have duplicates (not just the extras). Use dummy + prev pointer. If duplicates found, skip ALL of them using a while loop.

```java
public ListNode deleteDuplicates(ListNode head) {
    ListNode dummy = new ListNode(0);
    dummy.next = head;

    ListNode prev = dummy; // prev always points to last confirmed unique node

    ListNode curr = head;

    while (curr != null) {
        // check if current node has duplicates
        boolean isDuplicate = false;

        while (curr.next != null && curr.val == curr.next.val) {
            curr = curr.next; // skip all duplicates
            isDuplicate = true;
        }

        if (isDuplicate) {
            prev.next = curr.next; // skip ALL nodes with this value
        } else {
            prev = prev.next; // move prev only if no duplicate
        }

        curr = curr.next;
    }

    return dummy.next;
}
```

**Dry Run:**
```
List: 1 → 2 → 2 → 3 → 3 → 4

dummy → 1 → 2 → 2 → 3 → 3 → 4
prev = dummy, curr = 1

Step 1: curr=1
  curr.next=2, 1≠2 → not duplicate
  prev moves to 1
  curr = 2

Step 2: curr=2
  curr.next=2, 2==2 → isDuplicate=true
    inner while: curr moves to second 2
  isDuplicate=true → prev.next = curr.next = 3
  List: dummy → 1 → 3 → 3 → 4
  curr = 3

Step 3: curr=3
  curr.next=3, 3==3 → isDuplicate=true
    inner while: curr moves to second 3
  isDuplicate=true → prev.next = curr.next = 4
  List: dummy → 1 → 4
  curr = 4

Step 4: curr=4
  curr.next=null → not duplicate
  prev moves to 4
  curr = null → stop

Result: 1 → 4 ✅

Difference from LC 83:
  LC 83: keep ONE copy of duplicate  → 1→2→3→4
  LC 82: delete ALL copies           → 1→4
```

## Summary Table

| Problem | Dummy Nodes | Key Trick |
|---|---|---|
| Remove Elements | 1 dummy | Don't move curr on deletion |
| Remove Duplicates I | 1 dummy | Skip extra copies only |
| Remove Nth From End | 1 dummy | N+1 gap so slow lands before target |
| Partition List | 2 dummies | Cut greater.next to avoid stale links |
| Odd Even List | 2 dummies (or none) | Save evenHead before loop |
| Swap Pairs | 1 dummy | prev gives anchor before each pair |
| Remove Duplicates II | 1 dummy | Inner while skips ALL duplicates |

---

## The 3 Golden Rules (Never Forget)

```
1. dummy.next = head          → always attach to real list
2. Start pointer at dummy     → so you can delete/insert at head
3. return dummy.next          → never return head (it might be deleted!)
```

---

## When to Use 2 Dummy Nodes?

> Whenever you need to **split** the list into two separate lists and **join** them later.

- Partition List → less than x  /  greater than x
- Odd Even List  → odd positions / even positions
