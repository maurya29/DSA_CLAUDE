# Dummy Node Technique — Both Iterative & Recursive Solutions

---

## 🟢 Easy

### 1. Remove Linked List Elements — LC 203

**Intuition:** Dummy node lets you delete head node without special case. Check `curr.next.val` and skip if matches target. Recursively skip matching nodes on way forward.

#### Iterative
```java
public ListNode removeElements(ListNode head, int val) {
    ListNode dummy = new ListNode(0);
    dummy.next = head;

    ListNode curr = dummy;

    while (curr.next != null) {
        if (curr.next.val == val) {
            curr.next = curr.next.next; // skip node
        } else {
            curr = curr.next; // only move if no deletion
        }
    }

    return dummy.next;
}
```

#### Recursive
```java
public ListNode removeElements(ListNode head, int val) {
    // base case
    if (head == null) return null;

    // recurse first
    head.next = removeElements(head.next, val);

    // on way back decide to keep or skip current node
    if (head.val == val) {
        return head.next; // skip current node
    } else {
        return head;      // keep current node
    }
}
```

**Dry Run (Iterative):**
```
List: 1→2→6→3→6, val=6
dummy→1→2→6→3→6, curr=dummy

Step 1: curr.next=1, 1≠6 → move curr to 1
Step 2: curr.next=2, 2≠6 → move curr to 2
Step 3: curr.next=6, 6==6 → 2.next=3
Step 4: curr.next=3, 3≠6 → move curr to 3
Step 5: curr.next=6, 6==6 → 3.next=null

Result: 1→2→3 ✅
```

**Dry Run (Recursive):**
```
List: 1→2→6→3, val=6

remove(1)
  1.next = remove(2)
    2.next = remove(6)
      6.next = remove(3)
        3.next = remove(null) = null
        3≠6 → return 3
      6==6 → return 6.next = 3
    2.next = 3
    2≠6 → return 2 → 2→3
  1.next = 2
  1≠6 → return 1 → 1→2→3

Result: 1→2→3 ✅
```

### 2. Remove Duplicates from Sorted List — LC 83

**Intuition:** Since sorted, duplicates are adjacent. Skip `curr.next` if it equals `curr`. Recursively skip duplicates on way forward.

#### Iterative
```java
public ListNode deleteDuplicates(ListNode head) {
    ListNode dummy = new ListNode(0);
    dummy.next = head;

    ListNode curr = head;

    while (curr != null && curr.next != null) {
        if (curr.val == curr.next.val) {
            curr.next = curr.next.next; // skip duplicate
        } else {
            curr = curr.next; // move only if no deletion
        }
    }

    return dummy.next;
}
```

#### Recursive
```java
public ListNode deleteDuplicates(ListNode head) {
    // base case
    if (head == null || head.next == null) return head;

    // recurse first
    head.next = deleteDuplicates(head.next);

    // on way back skip if duplicate
    if (head.val == head.next.val) {
        return head.next; // skip current, keep next
    } else {
        return head;      // keep current
    }
}
```

### 3. Remove Nth Node From End — LC 19

**Intuition:** Dummy + fast & slow. Move fast N+1 steps so slow lands just before target. Recursively count from end and skip the Nth node.

#### Iterative
```java
public ListNode removeNthFromEnd(ListNode head, int n) {
    ListNode dummy = new ListNode(0);
    dummy.next = head;

    ListNode slow = dummy;
    ListNode fast = dummy;

    // move fast n+1 steps ahead
    for (int i = 0; i <= n; i++) {
        fast = fast.next;
    }

    // move both until fast hits null
    while (fast != null) {
        slow = slow.next;
        fast = fast.next;
    }

    // slow is just before target
    slow.next = slow.next.next;

    return dummy.next;
}
```

#### Recursive
```java
public ListNode removeNthFromEnd(ListNode head, int n) {
    int[] count = {0};
    return removeHelper(head, n, count);
}

private ListNode removeHelper(ListNode node, int n, int[] count) {
    // base case
    if (node == null) return null;

    // recurse to end first
    node.next = removeHelper(node.next, n, count);

    // on way back increment count
    count[0]++;

    // if this is nth node from end, skip it
    if (count[0] == n) return node.next;

    return node;
}
```

**Dry Run (Iterative):**
```
List: 1→2→3→4→5, n=2
dummy→1→2→3→4→5

Move fast n+1=3 steps: fast=node3
slow=dummy

Move both:
  slow=1, fast=4
  slow=2, fast=5
  slow=3, fast=null → stop

3.next = 5 (skip 4)

Result: 1→2→3→5 ✅
```

**Dry Run (Recursive):**
```
List: 1→2→3→4→5, n=2

remove(1)→remove(2)→remove(3)→remove(4)→remove(5)→remove(null)

On way back (count increments):
  node=5: count=1, 1≠2 → return 5
  node=4: count=2, 2==2 → return 4.next=5 (skip 4!) ✅
  node=3: count=3, 3≠2 → 3.next=5, return 3
  node=2: count=4 → return 2
  node=1: count=5 → return 1

Result: 1→2→3→5 ✅
```

### 4. Partition List — LC 86

**Intuition:** Two dummy nodes collect nodes less than x and greater/equal to x separately. Connect them at end. Recursively route each node to correct partition.

#### Iterative
```java
public ListNode partition(ListNode head, int x) {
    ListNode lessHead    = new ListNode(0); // dummy for < x
    ListNode greaterHead = new ListNode(0); // dummy for >= x

    ListNode less    = lessHead;
    ListNode greater = greaterHead;
    ListNode curr    = head;

    while (curr != null) {
        if (curr.val < x) {
            less.next = curr;
            less      = less.next;
        } else {
            greater.next = curr;
            greater      = greater.next;
        }
        curr = curr.next;
    }

    // IMPORTANT: cut stale links
    greater.next = null;

    // connect less list to greater list
    less.next = greaterHead.next;

    return lessHead.next;
}
```

#### Recursive
```java
public ListNode partition(ListNode head, int x) {
    // base case
    if (head == null) return null;

    if (head.val < x) {
        // keep head, recurse on rest
        head.next = partition(head.next, x);
        return head;
    } else {
        // head goes to greater partition
        // find first node < x after head
        ListNode result = partition(head.next, x);

        // attach head at end of less partition
        head.next = getGreaterHead(result, x);
        getLessTail(result, x).next = head; // less tail connects to head

        // tricky — easier to use iterative for this one
        // see note below
        return result;
    }
}
```

> **Note:** Pure recursion for partition is tricky because you need to track two separate list tails simultaneously. The iterative two-dummy approach is the **recommended and cleaner solution**. Below is a cleaner recursive alternative using helper lists:

```java
// Cleaner Recursive Alternative
public ListNode partition(ListNode head, int x) {
    if (head == null) return null;

    // recursively partition the rest
    ListNode rest = partition(head.next, x);
    head.next = null; // detach head

    if (head.val < x) {
        // head belongs at front of less partition
        head.next = rest;
        return head;
    } else {
        // head belongs after all less-than-x nodes
        if (rest == null || rest.val >= x) {
            // no less partition — just prepend
            head.next = rest;
            return head;
        }

        // find the tail of less-than-x nodes
        ListNode curr = rest;
        while (curr.next != null && curr.next.val < x) {
            curr = curr.next;
        }

        // insert head after less partition
        head.next  = curr.next;
        curr.next  = head;
        return rest;
    }
}
```

**Dry Run (Iterative):**
```
List: 1→4→3→2→5→2, x=3

curr=1: 1<3  → less:    dummy1→1
curr=4: 4>=3 → greater: dummy2→4
curr=3: 3>=3 → greater: dummy2→4→3
curr=2: 2<3  → less:    dummy1→1→2
curr=5: 5>=3 → greater: dummy2→4→3→5
curr=2: 2<3  → less:    dummy1→1→2→2

greater.next = null
less.next = greaterHead.next(4)

Result: 1→2→2→4→3→5 ✅
```

### 5. Odd Even Linked List — LC 328

**Intuition:** Two pointers weave through list — odd skips even, even skips odd. Connect odd tail to even head at end. Recursively route nodes to odd/even positions.

#### Iterative
```java
public ListNode oddEvenList(ListNode head) {
    if (head == null) return null;

    ListNode odd      = head;
    ListNode even     = head.next;
    ListNode evenHead = even; // save to connect later

    while (even != null && even.next != null) {
        odd.next  = even.next; // odd skips even
        odd       = odd.next;

        even.next = odd.next;  // even skips odd
        even      = even.next;
    }

    odd.next = evenHead; // connect odd tail to even head

    return head;
}
```

#### Recursive
```java
public ListNode oddEvenList(ListNode head) {
    if (head == null) return null;

    ListNode evenHead = head.next;
    rearrange(head, head.next);
    return head;
}

private void rearrange(ListNode odd, ListNode even) {
    // base case: no more pairs to process
    if (even == null || even.next == null) {
        // connect odd tail to even head
        // find even head by traversing from odd
        // Note: we save evenHead in main method
        return;
    }

    odd.next  = even.next;       // odd skips even
    even.next = even.next.next;  // even skips odd

    rearrange(odd.next, even.next); // recurse on next pair
}
```

> **Note:** The recursive version needs evenHead saved externally to connect at the end. Here is a cleaner self-contained recursive version:

```java
// Cleaner Recursive Version
public ListNode oddEvenList(ListNode head) {
    if (head == null || head.next == null) return head;

    ListNode evenHead = head.next;
    oddEvenHelper(head, head.next);
    return head;
}

private ListNode oddEvenHelper(ListNode odd, ListNode even) {
    // base case: even chain exhausted
    if (even == null || even.next == null) {
        odd.next = (even == null) ? null : even; // will be overwritten
        return odd;
    }

    odd.next  = even.next;        // odd skips even
    even.next = even.next.next;   // even skips odd

    ListNode oddTail = oddEvenHelper(odd.next, even.next);
    return oddTail;
}

// Full clean recursive solution
public ListNode oddEvenListClean(ListNode head) {
    if (head == null || head.next == null) return head;

    ListNode[] evenHead = {head.next};
    buildOdd(head, head.next, evenHead);
    return head;
}

private void buildOdd(ListNode odd, ListNode even, ListNode[] evenHead) {
    if (even == null || even.next == null) {
        odd.next = evenHead[0]; // connect odd tail to even head
        return;
    }

    odd.next  = even.next;        // odd skips even
    even.next = even.next.next;   // even skips odd

    buildOdd(odd.next, even.next, evenHead);
}
```

**Dry Run (Iterative):**
```
List: 1→2→3→4→5
odd=1, even=2, evenHead=2

Iteration 1:
  odd.next=3  → odd list: 1→3
  odd=3
  even.next=4 → even list: 2→4
  even=4

Iteration 2:
  odd.next=5  → odd list: 1→3→5
  odd=5
  even.next=null → even list: 2→4
  even=null → stop

odd.next = evenHead(2)
Result: 1→3→5→2→4 ✅
```

### 6. Swap Nodes in Pairs — LC 24

**Intuition:** Dummy node anchors before each pair. Rewire 3 pointers to swap. Recursively swap first pair then recurse on rest.

#### Iterative
```java
public ListNode swapPairs(ListNode head) {
    ListNode dummy = new ListNode(0);
    dummy.next = head;

    ListNode prev = dummy;

    while (prev.next != null && prev.next.next != null) {
        ListNode first  = prev.next;
        ListNode second = prev.next.next;

        // swap
        first.next  = second.next;
        second.next = first;
        prev.next   = second;

        // move prev to end of swapped pair
        prev = first;
    }

    return dummy.next;
}
```

#### Recursive
```java
public ListNode swapPairs(ListNode head) {
    // base case: 0 or 1 node
    if (head == null || head.next == null) return head;

    ListNode first  = head;
    ListNode second = head.next;

    // first points to result of rest
    first.next  = swapPairs(second.next);
    // second points back to first
    second.next = first;

    return second; // second is new head
}
```

**Dry Run (Iterative):**
```
List: 1→2→3→4
dummy→1→2→3→4, prev=dummy

Iteration 1:
  first=1, second=2
  1.next=3, 2.next=1, dummy.next=2
  List: dummy→2→1→3→4, prev=1

Iteration 2:
  first=3, second=4
  3.next=null, 4.next=3, 1.next=4
  List: dummy→2→1→4→3, prev=3

Result: 2→1→4→3 ✅
```

**Dry Run (Recursive):**
```
List: 1→2→3→4

swapPairs(1):
  first=1, second=2
  1.next = swapPairs(3)
    first=3, second=4
    3.next = swapPairs(null) = null
    4.next = 3
    return 4 → 4→3
  1.next = 4 → 1→4→3
  2.next = 1
  return 2 → 2→1→4→3

Result: 2→1→4→3 ✅
```

## 🔴 Hard

### 7. Remove Duplicates from Sorted List II — LC 82

**Intuition:** Delete ALL nodes that have duplicates. `prev` tracks last confirmed unique node. Inner while loop skips all copies of duplicate value. Recursively skip entire duplicate groups.

#### Iterative
```java
public ListNode deleteDuplicates(ListNode head) {
    ListNode dummy = new ListNode(0);
    dummy.next = head;

    ListNode prev = dummy;
    ListNode curr = head;

    while (curr != null) {
        boolean isDuplicate = false;

        // skip all nodes with same value
        while (curr.next != null && curr.val == curr.next.val) {
            curr        = curr.next;
            isDuplicate = true;
        }

        if (isDuplicate) {
            prev.next = curr.next; // skip ALL nodes with this value
        } else {
            prev = prev.next;      // move prev only if unique
        }

        curr = curr.next;
    }

    return dummy.next;
}
```

#### Recursive
```java
public ListNode deleteDuplicates(ListNode head) {
    // base case
    if (head == null || head.next == null) return head;

    if (head.val == head.next.val) {
        // skip all nodes with same value as head
        while (head.next != null && head.val == head.next.val) {
            head = head.next;
        }
        // skip head itself too, recurse on what's left
        return deleteDuplicates(head.next);
    } else {
        // head is unique, keep it and recurse
        head.next = deleteDuplicates(head.next);
        return head;
    }
}
```

**Dry Run (Iterative):**
```
List: 1→2→2→3→3→4
dummy→1→2→2→3→3→4
prev=dummy, curr=1

Step 1: curr=1
  next=2, 1≠2 → not duplicate
  prev moves to 1
  curr=2

Step 2: curr=2
  next=2, 2==2 → isDuplicate=true
    inner while: curr moves to second 2
  isDuplicate → prev.next=curr.next=3
  List: dummy→1→3→3→4
  curr=3

Step 3: curr=3
  next=3, 3==3 → isDuplicate=true
    inner while: curr moves to second 3
  isDuplicate → prev.next=curr.next=4
  List: dummy→1→4
  curr=4

Step 4: curr=4
  next=null → not duplicate
  prev moves to 4
  curr=null → stop

Result: 1→4 ✅
```

**Dry Run (Recursive):**
```
List: 1→2→2→3→3→4

  1≠2 → unique
  1.next = delete(2→2→3→3→4)
    delete(2):
      2==2 → duplicate!
      skip all 2s → head=second 2
      return delete(3→3→4)
        delete(3):
          3==3 → duplicate!
          skip all 3s → head=second 3
          return delete(4)
            delete(4):
              4.next=null → return 4
          return 4
        return 4
      return 4
    return 4
  1.next = 4
  return 1 → 1→4

Result: 1→4 ✅

Difference from LC 83:
  LC 83: keep ONE copy  → 1→2→3→4
```

## Summary Table

| Problem | Iterative Approach | Recursive Approach | Trick |
|---|---|---|---|
| Remove Elements | Dummy + skip on match | Recurse first, skip on way back | Don't move curr on deletion |
| Remove Duplicates I | Skip curr.next if equal | Recurse first, skip if next equal | Only move curr if no deletion |
| Remove Nth From End | Dummy + N+1 gap pointers | Recurse to end, count on way back | count[0]==n → return node.next |
| Partition List | Two dummies + connect | Recursively route to correct partition | Cut greater.next to avoid stale links |
| Odd Even List | Two pointers weaving | Save evenHead, recursive weaving | Connect odd tail to evenHead at end |
| Swap Pairs | Dummy + rewire 3 pointers | Swap 2 + recurse on rest | first.next = swapPairs(second.next) |
| Remove Duplicates II | Dummy + inner while skips all | Skip entire duplicate group + recurse | Recursion is cleaner than iterative here |

---

## The 3 Golden Rules (Never Forget)

```
1. dummy.next = head      → always attach to real list
2. Start at dummy         → so head deletion is handled cleanly
3. return dummy.next      → never return head (it might be gone!)
```

---

## Iterative vs Recursive — When to Choose

| | Iterative | Recursive |
|---|---|---|
| Remove Elements | Clean, easy to trace | Elegant 3-liner |
| Partition List | Cleaner with two dummies | Tricky — iterative preferred |
| Remove Duplicates II | Needs inner while loop | Cleaner — recursive preferred |
| Swap Pairs | Standard dummy approach | Elegant — recursive preferred |

> **Key Insight:** For deletion problems, recursive solutions naturally handle the "skip and continue" pattern very cleanly. For partition problems, iterative two-dummy approach is cleaner because recursion needs to track two tails simultaneously. 💡
