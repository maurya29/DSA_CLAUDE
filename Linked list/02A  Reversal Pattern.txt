# Reversal Pattern

---

## Core Idea

Reversing a linked list means **changing the direction of pointers**. Instead of `A → B → C`, you make it `C → B → A`.

The key insight is you only need **3 variables** to reverse any linked list:
- `prev` — the node behind current
- `curr` — the node you're currently processing
- `next` — the node ahead (saved before you break the link)

---

## The Foundation — Reverse Entire List

This is the base of EVERY reversal problem. Master this first.

**Visual:**
```
Original: 1 → 2 → 3 → 4 → null
                               ↑ prev starts here

Step 1:  prev=null, curr=1, next=2
         null ← 1   2 → 3 → 4

Step 2:  prev=1, curr=2, next=3
         null ← 1 ← 2   3 → 4

Step 3:  prev=2, curr=3, next=4
         null ← 1 ← 2 ← 3   4

Step 4:  prev=3, curr=4, next=null
         null ← 1 ← 2 ← 3 ← 4

curr = null → stop
return prev (which is 4, new head) ✅
```

**Code:**
```java
public ListNode reverse(ListNode head) {
    ListNode prev = null;
    ListNode curr = head;

    while (curr != null) {
        ListNode next = curr.next; // save next
        curr.next = prev;          // reverse the pointer
        prev = curr;               // move prev forward
        curr = next;               // move curr forward
    }

    return prev; // new head
}
```

---

## The 4 Steps Inside the Loop (Never Forget This Order)

```
1. Save next       →  ListNode next = curr.next
2. Reverse pointer →  curr.next = prev
3. Move prev       →  prev = curr
4. Move curr       →  curr = next
```

If you mess up the order, you lose the list. Always follow this sequence.

---

## How to Recognize Reversal Problems

- "Reverse the list"
- "Check if palindrome"
- "Reverse between positions i and j"
- "Reverse in k-groups"
- Anything where you need to **look backwards** or **compare from both ends**

## Variant 1 — Reverse a Sublist (Between positions left → right)

**Visual:**
```
List:  1 → 2 → 3 → 4 → 5,  left=2, right=4

Only reverse nodes 2, 3, 4

Before: 1 → [2 → 3 → 4] → 5
After:  1 → [4 → 3 → 2] → 5
```

**Trick:** Use a dummy node. Find the node just before `left`, then reverse exactly `right - left` times.

```java
public ListNode reverseBetween(ListNode head, int left, int right) {
    ListNode dummy = new ListNode(0);
    dummy.next = head;

    // Step 1: reach node just before 'left'
    ListNode prev = dummy;
    for (int i = 1; i < left; i++) {
        prev = prev.next;
    }

    // Step 2: curr is the first node to reverse
    ListNode curr = prev.next;

    // Step 3: reverse (right - left) times
    for (int i = 0; i < right - left; i++) {
        ListNode next = curr.next;
        curr.next = next.next;
        next.next = prev.next;
        prev.next = next;
    }

    return dummy.next;
}
```

**Dry Run:**
```
List: 1 → 2 → 3 → 4 → 5, left=2, right=4

prev = node 1 (just before left)
curr = node 2 (first node to reverse)

Iteration 1 (i=0):
  next = 3
  curr.next = 4       → 2 → 4
  next.next = prev.next = 2  → 3 → 2
  prev.next = 3       → 1 → 3
  List: 1 → 3 → 2 → 4 → 5

Iteration 2 (i=1):
  next = 4
  curr.next = 5       → 2 → 5
  next.next = prev.next = 3  → 4 → 3
  prev.next = 4       → 1 → 4
  List: 1 → 4 → 3 → 2 → 5 ✅
```

## Variant 2 — Reverse in K-Groups

**Visual:**
```
List: 1 → 2 → 3 → 4 → 5,  k=2

Group 1: reverse [1,2] → 2 → 1
Group 2: reverse [3,4] → 4 → 3
Group 3: [5] less than k, leave as is

Result: 2 → 1 → 4 → 3 → 5
```

```java
public ListNode reverseKGroup(ListNode head, int k) {
    // check if k nodes exist from current head
    ListNode check = head;
    int count = 0;

    while (check != null && count < k) {
        check = check.next;
        count++;
    }

    // if less than k nodes remain, return head as is
    if (count < k) return head;

    // reverse k nodes
    ListNode prev = null;
    ListNode curr = head;

    for (int i = 0; i < k; i++) {
        ListNode next = curr.next;
        curr.next = prev;
        prev = curr;
        curr = next;
    }

    // head is now the tail of reversed group
    // connect it to the result of next group
    head.next = reverseKGroup(curr, k);

    return prev; // prev is new head of this group
}
```

**Dry Run:**
```
List: 1 → 2 → 3 → 4 → 5, k=2

Call 1: reverse [1,2] → 2 → 1, recurse on 3
Call 2: reverse [3,4] → 4 → 3, recurse on 5
Call 3: only 1 node (< k), return 5

Connect:
  1.next = (4 → 3 → 5)
  3.next = 5

Final: 2 → 1 → 4 → 3 → 5 ✅
```

## Golden Template Summary

```java
// Base reverse — used inside EVERY reversal problem
private ListNode reverse(ListNode head) {
    ListNode prev = null;
    ListNode curr = head;

    while (curr != null) {
        ListNode next = curr.next;
        curr.next = prev;
        prev = curr;
        curr = next;
    }

    return prev;
}
```

---

## Key Rules to Remember

| Scenario | Approach |
|---|---|
| Reverse full list | 3 pointer technique |
| Reverse sublist | Dummy node + stop at boundary |
| Reverse k-groups | Reverse k nodes + recurse on rest |
| Palindrome check | Reverse second half + compare |
