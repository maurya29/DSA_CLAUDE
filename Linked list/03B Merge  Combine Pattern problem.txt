# Merge / Combine Pattern — Both Iterative & Recursive Solutions

---

## 🟢 Easy

### 1. Merge Two Sorted Lists — LC 21

**Intuition:** Compare heads of both lists, pick smaller one, move that pointer forward. Recursively pick smaller head and recurse on rest.

#### Iterative
```java
public ListNode mergeTwoLists(ListNode l1, ListNode l2) {
    ListNode dummy = new ListNode(0);
    ListNode curr  = dummy;

    while (l1 != null && l2 != null) {
        if (l1.val <= l2.val) {
            curr.next = l1;
            l1 = l1.next;
        } else {
            curr.next = l2;
            l2 = l2.next;
        }
        curr = curr.next;
    }

    // attach remaining list
    curr.next = (l1 != null) ? l1 : l2;

    return dummy.next;
}
```

#### Recursive
```java
public ListNode mergeTwoLists(ListNode l1, ListNode l2) {
    // base cases
    if (l1 == null) return l2;
    if (l2 == null) return l1;

    if (l1.val <= l2.val) {
        l1.next = mergeTwoLists(l1.next, l2); // l1 is smaller, recurse on l1.next
        return l1;
    } else {
        l2.next = mergeTwoLists(l1, l2.next); // l2 is smaller, recurse on l2.next
        return l2;
    }
}
```

**Dry Run (Iterative):**
```
l1: 1 → 3 → 5
l2: 2 → 4 → 6

Step 1: 1<=2 → pick 1, l1→3   dummy→1
Step 2: 3>2  → pick 2, l2→4   dummy→1→2
Step 3: 3<=4 → pick 3, l1→5   dummy→1→2→3
Step 4: 5>4  → pick 4, l2→6   dummy→1→2→3→4
Step 5: 5<=6 → pick 5, l1→null dummy→1→2→3→4→5

l1=null → attach l2
Result: 1→2→3→4→5→6 ✅
```

**Dry Run (Recursive):**
```
l1: 1→3, l2: 2→4

merge(1,2): 1<=2 → 1.next = merge(3,2)
  merge(3,2): 3>2  → 2.next = merge(3,4)
    merge(3,4): 3<=4 → 3.next = merge(null,4)
      merge(null,4): l1=null → return 4
    3.next=4, return 3 → 3→4
  2.next=3, return 2  → 2→3→4
1.next=2, return 1    → 1→2→3→4 ✅
```

### 2. Merge Sorted Array — LC 88

**Intuition:** Merge from end to avoid overwriting. Three pointers — end of each array and end of merge position. Recursively pick larger element from end and place it.

#### Iterative
```java
public void merge(int[] nums1, int m, int[] nums2, int n) {
    int p1 = m - 1;     // pointer for nums1
    int p2 = n - 1;     // pointer for nums2
    int p  = m + n - 1; // merge position (end of nums1)

    while (p1 >= 0 && p2 >= 0) {
        if (nums1[p1] >= nums2[p2]) {
            nums1[p] = nums1[p1];
            p1--;
        } else {
            nums1[p] = nums2[p2];
            p2--;
        }
        p--;
    }

    // copy remaining nums2 elements if any
    while (p2 >= 0) {
        nums1[p] = nums2[p2];
        p2--;
        p--;
    }
}
```

#### Recursive
```java
public void merge(int[] nums1, int m, int[] nums2, int n) {
    mergeHelper(nums1, m - 1, nums2, n - 1, m + n - 1);
}

private void mergeHelper(int[] nums1, int p1, int[] nums2, int p2, int p) {
    // base case: no more nums2 elements to place
    if (p2 < 0) return;

    // base case: no more nums1 elements, copy nums2
    if (p1 < 0) {
        nums1[p] = nums2[p2];
        mergeHelper(nums1, p1, nums2, p2 - 1, p - 1);
        return;
    }

    if (nums1[p1] >= nums2[p2]) {
        nums1[p] = nums1[p1];
        mergeHelper(nums1, p1 - 1, nums2, p2, p - 1);
    } else {
        nums1[p] = nums2[p2];
        mergeHelper(nums1, p1, nums2, p2 - 1, p - 1);
    }
}
```

**Dry Run (Iterative):**
```
nums1=[1,3,5,0,0,0] m=3
nums2=[2,4,6]       n=3

p1=2(5), p2=2(6), p=5
Step 1: 5<6  → nums1[5]=6, p2=1, p=4 → [1,3,5,0,0,6]
Step 2: 5>4  → nums1[4]=5, p1=1, p=3 → [1,3,5,0,5,6]
Step 3: 3<4  → nums1[3]=4, p2=0, p=2 → [1,3,5,4,5,6]
Step 4: 3>2  → nums1[2]=3, p1=0, p=1 → [1,3,3,4,5,6]
Step 5: 1<2  → nums1[1]=2, p2=-1      → [1,2,3,4,5,6]

p2<0 → stop
Result: [1,2,3,4,5,6] ✅
```

## 🟡 Medium

### 3. Sort List — LC 148

**Intuition:** Find middle → split into two halves → sort each half → merge. This is merge sort on linked list. Iterative bottom-up merge sort avoids recursion stack.

#### Iterative (Bottom-Up Merge Sort)
```java
public ListNode sortList(ListNode head) {
    if (head == null || head.next == null) return head;

    // Step 1: get length
    int length = 0;
    ListNode node = head;
    while (node != null) {
        length++;
        node = node.next;
    }

    ListNode dummy = new ListNode(0);
    dummy.next = head;

    // Step 2: bottom-up merge — size 1, 2, 4, 8...
    for (int size = 1; size < length; size *= 2) {
        ListNode curr = dummy.next;
        ListNode tail = dummy;

        while (curr != null) {
            // split two halves of current size
            ListNode left  = curr;
            ListNode right = split(left, size);
            curr           = split(right, size);

            // merge and attach to tail
            ListNode[] merged = mergeWithTail(left, right);
            tail.next = merged[0]; // head of merged
            tail      = merged[1]; // tail of merged
        }
    }

    return dummy.next;
}

// splits list after 'size' nodes, returns head of second part
private ListNode split(ListNode head, int size) {
    for (int i = 1; i < size && head != null; i++) {
        head = head.next;
    }

    if (head == null) return null;

    ListNode second = head.next;
    head.next = null; // cut
    return second;
}

// merges two lists, returns [head, tail] of merged list
private ListNode[] mergeWithTail(ListNode l1, ListNode l2) {
    ListNode dummy = new ListNode(0);
    ListNode curr  = dummy;

    while (l1 != null && l2 != null) {
        if (l1.val <= l2.val) {
            curr.next = l1;
            l1 = l1.next;
        } else {
            curr.next = l2;
            l2 = l2.next;
        }
        curr = curr.next;
    }

    curr.next = (l1 != null) ? l1 : l2;

    // find tail
    while (curr.next != null) curr = curr.next;

    return new ListNode[]{dummy.next, curr};
}
```

#### Recursive (Top-Down Merge Sort)
```java
public ListNode sortList(ListNode head) {
    // base case
    if (head == null || head.next == null) return head;

    // Step 1: find middle and split
    ListNode mid       = getMiddle(head);
    ListNode rightHalf = mid.next;
    mid.next = null;

    // Step 2: recursively sort both halves
    ListNode left  = sortList(head);
    ListNode right = sortList(rightHalf);

    // Step 3: merge sorted halves
    return merge(left, right);
}

private ListNode getMiddle(ListNode head) {
    ListNode slow = head;
    ListNode fast = head;

    while (fast.next != null && fast.next.next != null) {
        slow = slow.next;
        fast = fast.next.next;
    }

    return slow;
}

private ListNode merge(ListNode l1, ListNode l2) {
    if (l1 == null) return l2;
    if (l2 == null) return l1;

    if (l1.val <= l2.val) {
        l1.next = merge(l1.next, l2);
        return l1;
    } else {
        l2.next = merge(l1, l2.next);
        return l2;
    }
}
```

**Dry Run (Recursive):**
```
List: 4 → 2 → 1 → 3

sortList(4→2→1→3)
  mid=2, left=4→2, right=1→3

  sortList(4→2)
    mid=4, left=4, right=2
    sortList(4) → 4
    sortList(2) → 2
    merge(4,2)  → 2→4

  sortList(1→3)
    mid=1, left=1, right=3
    sortList(1) → 1
    sortList(3) → 3
    merge(1,3)  → 1→3

  merge(2→4, 1→3)
    1<2 → 1.next=merge(2→4,3)
      2<3 → 2.next=merge(4,3)
        3<4 → 3.next=merge(4,null)=4
        return 3→4
      return 2→3→4
    return 1→2→3→4

Result: 1→2→3→4 ✅
```

### 4. Merge In Between Linked Lists — LC 1669

**Intuition:** Find node just before `a` and node just after `b`. Connect them to head and tail of list2. Recursively navigate to boundary positions.

#### Iterative
```java
public ListNode mergeInBetween(ListNode list1, int a, int b, ListNode list2) {
    ListNode curr = list1;

    // Step 1: find node just before position a
    for (int i = 0; i < a - 1; i++) {
        curr = curr.next;
    }
    ListNode nodeBeforeA = curr;

    // Step 2: find node just after position b
    for (int i = 0; i < b - a + 2; i++) {
        curr = curr.next;
    }
    ListNode nodeAfterB = curr;

    // Step 3: find tail of list2
    ListNode tail2 = list2;
    while (tail2.next != null) {
        tail2 = tail2.next;
    }

    // Step 4: connect
    nodeBeforeA.next = list2;
    tail2.next       = nodeAfterB;

    return list1;
}
```

#### Recursive
```java
public ListNode mergeInBetween(ListNode list1, int a, int b, ListNode list2) {
    // find tail of list2 first
    ListNode tail2 = getTail(list2);
    return mergeHelper(list1, a, b, list2, tail2, 0);
}

private ListNode mergeHelper(ListNode node, int a, int b,
                              ListNode list2, ListNode tail2, int index) {
    if (node == null) return null;

    if (index == a - 1) {
        // connect before-a to list2
        // connect tail2 to node after b
        tail2.next = getNodeAfterB(node, b - a + 2);
        node.next  = list2;
        return node;
    }

    node.next = mergeHelper(node.next, a, b, list2, tail2, index + 1);
    return node;
}

private ListNode getNodeAfterB(ListNode node, int steps) {
    if (steps == 0) return node;
    return getNodeAfterB(node.next, steps - 1);
}

private ListNode getTail(ListNode node) {
    if (node.next == null) return node;
    return getTail(node.next);
}
```

**Dry Run (Iterative):**
```
list1: 0→1→2→3→4→5, a=2, b=3
list2: 100→200

Step 1: nodeBeforeA = node 1 (index a-1=1)
Step 2: nodeAfterB  = node 4 (index b+1=4)
Step 3: tail2 = node 200

Step 4:
  1.next   = 100
  200.next = 4

Result: 0→1→100→200→4→5 ✅
```

### 5. Flatten a Multilevel Doubly Linked List — LC 430

**Intuition:** When a node has a child, insert the flattened child list between current node and current.next. Iteratively use a stack to handle multiple levels. Recursively flatten child first then insert it.

#### Iterative (Using Stack)
```java
public Node flatten(Node head) {
    if (head == null) return null;

    Stack<Node> stack = new Stack<>();
    Node curr = head;

    while (curr != null) {
        if (curr.child != null) {
            // push next to stack if exists
            if (curr.next != null) {
                stack.push(curr.next);
            }

            // connect curr to child
            curr.next       = curr.child;
            curr.child.prev = curr;
            curr.child      = null;
        }

        // if no next but stack has saved nodes
        if (curr.next == null && !stack.isEmpty()) {
            Node saved = stack.pop();
            curr.next  = saved;
            saved.prev = curr;
        }

        curr = curr.next;
    }

    return head;
}
```

#### Recursive
```java
public Node flatten(Node head) {
    if (head == null) return null;
    flattenHelper(head);
    return head;
}

// returns the tail of the flattened list starting at head
private Node flattenHelper(Node head) {
    Node curr = head;
    Node tail = null;

    while (curr != null) {
        if (curr.child != null) {
            Node child    = curr.child;
            Node next     = curr.next;

            // connect curr to child
            curr.next  = child;
            child.prev = curr;
            curr.child = null;

            // recursively flatten child and get its tail
            Node childTail = flattenHelper(child);

            // connect child tail to next
            childTail.next = next;
            if (next != null) next.prev = childTail;

            tail = childTail;
            curr = next;
        } else {
            tail = curr;
            curr = curr.next;
        }
    }

    return tail;
}
```

**Dry Run (Iterative):**
```
List: 1↔2↔3↔4
          ↓
          7↔8

curr=1: no child → move
curr=2: no child → move
curr=3: has child(7)!
  push next(4) to stack
  3.next=7, 7.prev=3, 3.child=null
  List: 1↔2↔3↔7↔8

curr=7: no child → move
curr=8: no child, stack=[4]
  pop 4, 8.next=4, 4.prev=8
  List: 1↔2↔3↔7↔8↔4

curr=4: no child → move
curr=null → stop

Result: 1↔2↔3↔7↔8↔4 ✅
```

## 🔴 Hard

### 6. Merge K Sorted Lists — LC 23

**Intuition:** Use MinHeap to always pick smallest node among all K list heads. Divide & Conquer pairs up lists and merges recursively like merge sort.

#### Iterative (Min Heap)
```java
public ListNode mergeKLists(ListNode[] lists) {
    PriorityQueue<ListNode> minHeap = new PriorityQueue<>(
        (a, b) -> a.val - b.val
    );

    // Step 1: add all heads to heap
    for (ListNode list : lists) {
        if (list != null) minHeap.offer(list);
    }

    ListNode dummy = new ListNode(0);
    ListNode curr  = dummy;

    // Step 2: always poll smallest, push its next
    while (!minHeap.isEmpty()) {
        ListNode smallest = minHeap.poll();
        curr.next = smallest;
        curr      = curr.next;

        if (smallest.next != null) {
            minHeap.offer(smallest.next);
        }
    }

    return dummy.next;
}
```

#### Recursive (Divide & Conquer)
```java
public ListNode mergeKLists(ListNode[] lists) {
    if (lists == null || lists.length == 0) return null;
    return divideAndConquer(lists, 0, lists.length - 1);
}

private ListNode divideAndConquer(ListNode[] lists, int left, int right) {
    // base case: single list
    if (left == right) return lists[left];

    int mid = left + (right - left) / 2;

    ListNode leftList  = divideAndConquer(lists, left, mid);
    ListNode rightList = divideAndConquer(lists, mid + 1, right);

    return merge(leftList, rightList);
}

private ListNode merge(ListNode l1, ListNode l2) {
    // base cases
    if (l1 == null) return l2;
    if (l2 == null) return l1;

    if (l1.val <= l2.val) {
        l1.next = merge(l1.next, l2);
        return l1;
    } else {
        l2.next = merge(l1, l2.next);
        return l2;
    }
}
```

**Dry Run (Iterative - Min Heap):**
```
Lists: [1→4→7], [2→5→8], [3→6→9]

Heap: [1,2,3]

Step 1: poll 1, push 4 → result:1       heap:[2,3,4]
Step 2: poll 2, push 5 → result:1→2     heap:[3,4,5]
Step 3: poll 3, push 6 → result:1→2→3   heap:[4,5,6]
Step 4: poll 4, push 7 → result:1→2→3→4 heap:[5,6,7]
Step 5: poll 5, push 8 → result:...→5   heap:[6,7,8]
Step 6: poll 6, push 9 → result:...→6   heap:[7,8,9]
Step 7: poll 7, no next→ result:...→7   heap:[8,9]
Step 8: poll 8          → result:...→8   heap:[9]
Step 9: poll 9          → result:...→9   heap:[]

Result: 1→2→3→4→5→6→7→8→9 ✅
```

**Dry Run (Recursive - Divide & Conquer):**
```
Lists: [L1, L2, L3, L4]

divideAndConquer(0,3)
  mid=1
  left  = divideAndConquer(0,1)
    mid=0
    left  = L1
    right = L2
    return merge(L1,L2) = L12

  right = divideAndConquer(2,3)
    mid=2
    left  = L3
    right = L4
    return merge(L3,L4) = L34

  return merge(L12,L34) = L1234 ✅

Time:  O(N log K)
Space: O(log K) recursion stack
```

## Summary Table

| Problem | Iterative Approach | Recursive Approach | Trick |
|---|---|---|---|
| Merge Two Sorted Lists | Dummy node + compare heads | Pick smaller head + recurse on rest | Attach remaining list at end |
| Merge Sorted Array | 3 pointers from the end | Pick larger from end + recurse | Merge backwards prevents overwrite |
| Sort List | Bottom-up merge sort (size 1,2,4...) | Top-down merge sort (find mid + recurse) | Iterative avoids O(log n) stack space |
| Merge In Between | Find boundary nodes + connect | Recurse to index a-1, connect list2 | Find tail2 before connecting |
| Flatten Multilevel | Stack saves next when child found | Flatten child recursively, get its tail | Stack handles multiple levels cleanly |
| Merge K Lists | Min Heap — always poll smallest | Divide & Conquer — pair up and merge | Heap: O(N log K) time, O(K) space |

---

## Iterative vs Recursive Comparison

| | Iterative | Recursive |
|---|---|---|
| Sort List | Bottom-up, O(1) space | Top-down, O(log n) stack |
| Merge Two Lists | Dummy node loop | Clean 3-line base case |
| Merge K Lists | Min Heap | Divide & Conquer |
| Flatten Multilevel | Stack based | Returns tail of each level |

> **Key Insight:** For merge problems, recursive solutions are often **cleaner and shorter** but use extra stack space. Iterative solutions are more **space efficient** but require more careful pointer management. 💡
