## PQ1 — Frequency-ranked Top K

**Recognition:** Repeated values; need the k most frequent keys, optionally with lexical tie-breaks. Count in a HashMap; retain best candidates in a size-k min-heap.

**Invariant:** Heap contains the best k processed keys; its root is the worst retained key.

**Core reusable logic:** Top-k frequent integers: frequency map plus size-k min-heap ordered by frequency; expected O(n + u log k). Use when only top k of u distinct keys are required.

**Ordered problems:** 347, 692

### Reusable Java 21 template

The following is a reusable helper, not a LeetCode submission. Place it inside a class with `import java.util.*;` and honor its stated preconditions.

```java
static <K> PriorityQueue<K> retainTop(Map<K,Integer> counts, int k, Comparator<K> worstFirst) {
    PriorityQueue<K> heap = new PriorityQueue<>(worstFirst);
    for (K key : counts.keySet()) {
        heap.offer(key);
        if (heap.size() > k) heap.poll();
    }
    return heap;
}
```

## PQ3 — Merge multiple ordered streams

**Recognition:** K input lists are individually sorted; the smallest current head across lists is the next global element.

**Invariant:** Each live stream contributes exactly its current unconsumed head.

**Core reusable logic:** Merge k sorted linked lists: heap stores one current node per nonempty list; pop minimum, append node, offer its successor; O(N log k).

**Ordered problems:** 23, 632

### Reusable Java 21 template

The following is a reusable helper, not a LeetCode submission. Place it inside a class with `import java.util.*;` and honor its stated preconditions.

```java
record Head(int stream, int index, int value) {}
static PriorityQueue<Head> seed(List<List<Integer>> streams) {
    var heap = new PriorityQueue<Head>(Comparator.comparingInt(Head::value));
    for (int i = 0; i < streams.size(); i++)
        if (!streams.get(i).isEmpty()) heap.offer(new Head(i, 0, streams.get(i).get(0)));
    return heap;
}
static void advance(PriorityQueue<Head> heap, Head h, List<List<Integer>> streams) {
    var row = streams.get(h.stream());
    if (h.index()+1 < row.size()) heap.offer(new Head(h.stream(), h.index()+1, row.get(h.index()+1)));
}
```

## PQ4 — Best-first enumeration of sorted pair candidates

**Recognition:** Pair costs are monotone along sorted input dimensions; enumerate the next smallest frontier without materializing all pairs.

**Invariant:** Each live monotone row contributes its least unconsumed candidate; no pair is produced twice.

**Core reusable logic:** Find k smallest pair sums across two sorted arrays: seed first item from up to k rows, pop (i,j), offer (i,j+1); O(k log min(k,n)).

**Ordered problems:** 373, 786

### Reusable Java 21 template

The following is a reusable helper, not a LeetCode submission. Place it inside a class with `import java.util.*;` and honor its stated preconditions.

```java
record Pair(int row, int col) {}
static List<Pair> frontier(int rows, int limit, Comparator<Pair> cmp,
        java.util.function.IntUnaryOperator first,
        java.util.function.Function<Pair,Pair> successor) {
    var heap = new PriorityQueue<Pair>(cmp);
    for (int i=0;i<rows;i++) heap.offer(new Pair(i,first.applyAsInt(i)));
    List<Pair> result = new ArrayList<>();
    while (!heap.isEmpty() && result.size()<limit) {
        Pair p=heap.poll(); result.add(p);
        Pair next=successor.apply(p); if(next!=null) heap.offer(next);
    }
    return result;
}
```

## PQ5 — Two-heaps order statistic and lazy eviction

**Recognition:** Need online median/percentile while values arrive, or a moving window with outgoing items.

**Invariant:** Every valid lower-half value is ≤ every valid upper-half value; lower logical size equals upper or exceeds it by one. Prune stale roots before reading them.

**Ordered problems:** 295, 480

### Reusable Java 21 template

The following is a reusable helper, not a LeetCode submission. Place it inside a class with `import java.util.*;` and honor its stated preconditions.

```java
static void insert(PriorityQueue<Integer> low, PriorityQueue<Integer> high, int x) {
    if(low.isEmpty() || x<=low.peek()) low.offer(x); else high.offer(x);
    if(low.size()>high.size()+1) high.offer(low.poll());
    else if(low.size()<high.size()) low.offer(high.poll());
}
```

### 09. LeetCode 480

**Problem statement**

For every consecutive window of k elements, return its median in left-to-right order. Use the average of the middle two values for even k.

**Examples**

- [1,3,-1,-3,5,3,6,7],3 → [1,-1,-1,3,5,6]
- [1,4,2,3],2 → [2.5,3,2.5]

**Constraints**

1 ≤ k ≤ n ≤100000; values are signed 32-bit integers.

**Why this family applies**

Sliding-window medians: reuse balanced heaps, but lazily delete expired values by index/value-count map and track logical heap sizes; O(n log k).

**Exact evolution from previous solution**

From LC 295: Add delayed-deletion frequency map, explicit valid-size counters and root pruning to support removals before rebalancing; output a median for each width-k window.

**Complete Java 21 solution**

```java
import java.util.*;

class Solution {
 private final PriorityQueue<Integer> low=new PriorityQueue<>(Comparator.reverseOrder()),high=new PriorityQueue<>();
 private final Map<Integer,Integer> delayed=new HashMap<>();private int l,h;
 private void prune(PriorityQueue<Integer> q){while(!q.isEmpty()){int x=q.peek(),c=delayed.getOrDefault(x,0);if(c==0)break;q.poll();if(c==1)delayed.remove(x);else delayed.put(x,c-1);}}
 private void balance(){if(l>h+1){high.offer(low.poll());l--;h++;prune(low);}else if(l<h){low.offer(high.poll());h--;l++;prune(high);}}
 private void add(int x){if(low.isEmpty()||x<=low.peek()){low.offer(x);l++;}else{high.offer(x);h++;}balance();}
 private void remove(int x){delayed.merge(x,1,Integer::sum);if(x<=low.peek()){l--;if(x==low.peek())prune(low);}else{h--;if(x==high.peek())prune(high);}balance();}
 private void rebuild(int[] a,int start,int k){low.clear();high.clear();delayed.clear();l=h=0;for(int j=start;j<start+k;j++)add(a[j]);}
 public double[] medianSlidingWindow(int[] nums,int k){double[] ans=new double[nums.length-k+1];rebuild(nums,0,k);
  for(int i=k-1;i<nums.length;i++){if(i>=k){add(nums[i]);remove(nums[i-k]);if((long)low.size()+high.size()>2L*k)rebuild(nums,i-k+1,k);}
   ans[i-k+1]=(k%2==1)?low.peek():((long)low.peek()+high.peek())/2.0;}
  return ans;
 }
}
```

**Key logic / correctness invariant**

Every valid lower-half value is ≤ every valid upper-half value; lower logical size equals upper or exceeds it by one. Prune stale roots before reading them. Sliding-window medians: reuse balanced heaps, but lazily delete expired values by index/value-count map and track logical heap sizes; O(n log k).

**Complexity**

Amortized O(n log(k+1)); O(k) auxiliary with periodic rebuild; O(n−k+1) output.

**Compilation:** Passed isolated Java 21 compilation.

import java.util.*;

class Solution {
 public int trapRainWater(int[][] heightMap){int m=heightMap.length,n=heightMap[0].length;if(m<3||n<3)return 0;boolean[][] seen=new boolean[m][n];PriorityQueue<int[]> q=new PriorityQueue<>(Comparator.comparingInt(a->a[0]));for(int r=0;r<m;r++)for(int c=0;c<n;c++)if(r==0||r==m-1||c==0||c==n-1){q.offer(new int[]{heightMap[r][c],r,c});seen[r][c]=true;}int water=0;int[] d={-1,0,1,0,-1};while(!q.isEmpty()){int[] x=q.poll();for(int i=0;i<4;i++){int r=x[1]+d[i],c=x[2]+d[i+1];if(r<0||r>=m||c<0||c>=n||seen[r][c])continue;seen[r][c]=true;int h=heightMap[r][c];water+=Math.max(0,x[0]-h);q.offer(new int[]{Math.max(h,x[0]),r,c});}}return water;}
}
```

**Key logic / correctness invariant**

Frontier cells carry the lowest known escape level; each cell enters once, and popped levels are nondecreasing. Compute rain trapped on a 2D height map: min-heap of boundary water levels, visit neighbors and accumulate level-height; O(mn log(mn)).

**Complexity**

O(mn log(mn+1)); O(mn) auxiliary; O(1) output.

    PriorityQueue<Message> heap=new PriorityQueue<>((a,b)->Long.compare(b.timestamp(),a.timestamp()));

import java.util.*;

class Twitter {
 private record Tweet(int id,long time,Tweet next){}
 private final Map<Integer,Tweet> heads=new HashMap<>();private final Map<Integer,Set<Integer>> follows=new HashMap<>();private long clock;
 public Twitter(){}
 public void postTweet(int userId,int tweetId){heads.put(userId,new Tweet(tweetId,clock++,heads.get(userId)));}
 public List<Integer> getNewsFeed(int userId){PriorityQueue<Tweet> q=new PriorityQueue<>((a,b)->Long.compare(b.time(),a.time()));Tweet own=heads.get(userId);if(own!=null)q.offer(own);for(int u:follows.getOrDefault(userId,Collections.emptySet())){Tweet t=heads.get(u);if(t!=null)q.offer(t);}List<Integer> out=new ArrayList<>();while(!q.isEmpty()&&out.size()<10){Tweet t=q.poll();out.add(t.id());if(t.next()!=null)q.offer(t.next());}return out;}
 public void follow(int followerId,int followeeId){if(followerId!=followeeId)follows.computeIfAbsent(followerId,x->new HashSet<>()).add(followeeId);}
 public void unfollow(int followerId,int followeeId){Set<Integer> s=follows.get(followerId);if(s!=null)s.remove(followeeId);}
}
```
