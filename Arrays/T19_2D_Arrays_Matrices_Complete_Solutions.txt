### 02. LeetCode 1572

**Problem statement**

Return the sum of both diagonals of a square matrix, counting a cell belonging to both only once.

**Examples**

- [[1,2,3],[4,5,6],[7,8,9]] → 25
- [[5]] → 5

**Constraints:** 1 ≤ n ≤ 100; 1 ≤ cell ≤ 100

**Why this pattern applies:** Two diagonal sums of a square matrix; inspect coordinates where r==c or r+c==n-1, O(n²) scan or O(n) direct diagonals.

**Exact solution evolution:** Replace full row sum with coordinate predicates for the two diagonals; subtract a shared center once.

**Java 21 solution**

```java
import java.util.*;

class Solution {
    public int diagonalSum(int[][] mat){
        int n=mat.length,sum=0;
        for(int i=0;i<n;i++) sum+=mat[i][i]+mat[i][n-1-i];
        if(n%2==1) sum-=mat[n/2][n/2];
        return sum;
    }
}
```

**Key logic:** Each row supplies two diagonal positions; odd n shares its center.

**Time complexity:** O(n)  
**Auxiliary space complexity:** O(1)

### 03. LeetCode 1380

**Problem statement**

**Examples**

- [[3,7,8],[9,11,13],[15,16,17]] → [15]
- [[7]] → [7]

**Constraints:** 1 ≤ R,C ≤ 50; distinct positive values ≤ 100000

```java
import java.util.*;

class Solution {
    public List<Integer> luckyNumbers(int[][] matrix){
        int r=matrix.length,c=matrix[0].length;
        int[] min=new int[r],max=new int[c]; Arrays.fill(min,Integer.MAX_VALUE); Arrays.fill(max,Integer.MIN_VALUE);
```

### 07. LeetCode 54

**Problem statement**

Return every matrix element in clockwise spiral order starting at the top-left.

**Examples**

- [[1,2,3],[4,5,6],[7,8,9]] → [1,2,3,6,9,8,7,4,5]
- [[1,2]] → [1,2]

**Constraints:** 1 ≤ R,C ≤ 10; |cell| ≤ 100

**Why this pattern applies:** Read matrix in spiral order; four shrinking bounds and one output list, O(RC).

**Exact solution evolution:** Foundation problem — no previous solution in this algorithm family. visit four sides of each remaining rectangle while guarding narrow layers.

**Java 21 solution**

```java
import java.util.*;

class Solution {
    public List<Integer> spiralOrder(int[][] matrix){
        List<Integer> out=new ArrayList<>();
        int top=0,bottom=matrix.length-1,left=0,right=matrix[0].length-1;
        while(top<=bottom && left<=right){
            for(int j=left;j<=right;j++) out.add(matrix[top][j]); top++;
            for(int i=top;i<=bottom;i++) out.add(matrix[i][right]); right--;
            if(top<=bottom){ for(int j=right;j>=left;j--) out.add(matrix[bottom][j]); bottom--; }
            if(left<=right){ for(int i=bottom;i>=top;i--) out.add(matrix[i][left]); left++; }
        }
        return out;
    }
}
```

**Key logic:** Shrink boundaries after each side; guards prevent duplicate visits.

**Time complexity:** O(RC)  
**Auxiliary space complexity:** O(1) excluding output

### 08. LeetCode 59

**Problem statement**

Generate an n×n matrix filled with integers 1 through n² in clockwise spiral order.

**Examples**

- n=3 → [[1,2,3],[8,9,4],[7,6,5]]
- n=1 → [[1]]

**Constraints:** 1 ≤ n ≤ 20

**Why this pattern applies:** Construct n×n matrix containing 1..n² in spiral order; four bounds, write incrementing values, O(n²).

**Exact solution evolution:** Reuse the exact four-side walk; change visit action from reading cells into list to writing successive integers.

**Java 21 solution**

```java
import java.util.*;

class Solution {
    public int[][] generateMatrix(int n){
        int[][] out=new int[n][n]; int v=1;
        int top=0,bottom=n-1,left=0,right=n-1;
        while(top<=bottom && left<=right){
            for(int j=left;j<=right;j++) out[top][j]=v++; top++;
            for(int i=top;i<=bottom;i++) out[i][right]=v++; right--;
            if(top<=bottom){ for(int j=right;j>=left;j--) out[bottom][j]=v++; bottom--; }
            if(left<=right){ for(int i=bottom;i>=top;i--) out[i][left]=v++; left++; }
        }
        return out;
    }
}
```

**Key logic:** Same walk; the visit operation writes an incrementing counter.

**Time complexity:** O(n²)

```java
import java.util.*;

class Solution {
    public int[][] spiralMatrix(int m,int n,ListNode head){

        int top=0,bottom=m-1,left=0,right=n-1;
        while(top<=bottom && left<=right){
            for(int j=left;j<=right;j++) { if(head==null) return out; out[top][j]=head.val; head=head.next; }; top++;
            for(int i=top;i<=bottom;i++) { if(head==null) return out; out[i][right]=head.val; head=head.next; }; right--;
            if(top<=bottom){ for(int j=right;j>=left;j--) { if(head==null) return out; out[bottom][j]=head.val; head=head.next; }; bottom--; }
```

```java
import java.util.*;

class Solution {
    public int[] findDiagonalOrder(int[][] mat){
        int r=mat.length,c=mat[0].length,p=0; int[] out=new int[r*c];
```

**Key logic:** Derive valid row interval for each diagonal; parity chooses direction.

### 41. LeetCode 85

**Problem statement**

Return the area of the largest axis-aligned rectangle containing only ones in a binary character matrix.

**Examples**

- ["10100","10111","11111","10010"] → 6
- ["0"] → 0

**Constraints:** 1 ≤ R,C ≤ 200; characters 0 or 1

**Why this pattern applies:** Largest all-one rectangle; build cumulative heights by row and apply monotonic-stack histogram solution each row, O(RC).

**Exact solution evolution:** Foundation problem — no previous solution in this algorithm family. convert 2D rectangles ending at each row into 1D histogram maximums, reusing T12 primitive without reassigning its ID.

**Java 21 solution**

```java
import java.util.*;

class Solution {
    public int maximalRectangle(char[][] matrix){
        int n=matrix[0].length,best=0; int[] h=new int[n],stack=new int[n+1];
        for(char[] row:matrix){
            for(int j=0;j<n;j++) h[j]=row[j]=='1'?h[j]+1:0;
            int top=-1;
            for(int j=0;j<=n;j++){
                int cur=j==n?0:h[j];
                while(top>=0&&h[stack[top]]>cur){ int height=h[stack[top--]],left=top<0?-1:stack[top]; best=Math.max(best,height*(j-left-1)); }
                if(j<n) stack[++top]=j;
            }
        } return best;
    }
}
```

**Key logic:** Each row forms a histogram; pop when a shorter bar determines the right boundary. Sentinel flushes remaining positive heights.

**Time complexity:** O(RC)  
**Auxiliary space complexity:** O(C)

### 42. LeetCode 221

**Problem statement**

Return the area of the largest square consisting entirely of ones in a binary character matrix.

**Examples**

- ["10100","10111","11111","10010"] → 4
- ["0"] → 0

**Constraints:** 1 ≤ R,C ≤ 300; characters 0 or 1

**Why this pattern applies:** Largest square consisting entirely of ones; DP maximum square side ending at each cell, return maxSide², O(RC).

**Exact solution evolution:** Foundation problem — no previous solution in this algorithm family. 1+minimum(top,left,top-left) for valid cell, maximum of all sides.

**Java 21 solution**

```java
import java.util.*;

class Solution {
    public int maximalSquare(char[][] matrix){
        int n=matrix[0].length,best=0; int[] dp=new int[n+1];
        for(char[] row:matrix){ int diag=0;
            for(int j=1;j<=n;j++){ int top=dp[j]; dp[j]=row[j-1]=='1'?1+Math.min(top,Math.min(dp[j-1],diag)):0; best=Math.max(best,dp[j]); diag=top; }
        } return best*best;
    }
}
```

**Key logic:** Rolling DP: top is previous row, left is current row, diag is saved previous-row previous-column value.
