## 🟢 Easy #1 — Range Sum Query - Immutable (LC 303)

### Intuition
Build a prefix sum array once in the constructor. Any range query [L, R] is then answered in O(1) using `prefix[R+1] - prefix[L]`. No need to loop for every query.

### Loop Solution
```java
class NumArray {
    private int[] prefix;

    public NumArray(int[] nums) {
        prefix = new int[nums.length + 1];
        for (int i = 0; i < nums.length; i++)
            prefix[i + 1] = prefix[i] + nums[i];
    }

    public int sumRange(int left, int right) {
        return prefix[right + 1] - prefix[left];
    }
}
```

### Recursive Solution
```java
class NumArray {
    private int[] prefix;

    public NumArray(int[] nums) {
        prefix = new int[nums.length + 1];
        buildPrefix(nums, 0);
    }
    private void buildPrefix(int[] nums, int i) {
        if (i == nums.length) return;
        prefix[i + 1] = prefix[i] + nums[i];
        buildPrefix(nums, i + 1);
    }

    public int sumRange(int left, int right) {
        return prefix[right + 1] - prefix[left];
    }
}
```

### Dry Run
```
nums = [-2, 0, 3, -5, 2, -1]

Build prefix:
prefix = [0, -2, -2, 1, -4, -2, -3]
          ↑   ↑   ↑   ↑   ↑   ↑   ↑
         p[0] p[1] p[2] p[3] p[4] p[5] p[6]

Query sumRange(0, 2):
= prefix[3] - prefix[0] = 1 - 0 = 1 ✅  (-2+0+3=1)

Query sumRange(2, 5):
= prefix[6] - prefix[2] = -3 - (-2) = -1 ✅  (3-5+2-1=-1)

Query sumRange(0, 5):
= prefix[6] - prefix[0] = -3 - 0 = -3 ✅
```

## 🟢 Easy #2 — Find Pivot Index (LC 724)

### Intuition
Pivot index = leftSum equals rightSum. Build total sum first. Then walk through array — at each index, leftSum = prefix so far, rightSum = total - leftSum - nums[i]. Check if they match.

### Loop Solution
```java
public int pivotIndex(int[] nums) {
    int total = 0;
    for (int num : nums) total += num;

    int leftSum = 0;
    for (int i = 0; i < nums.length; i++) {
        int rightSum = total - leftSum - nums[i];
        if (leftSum == rightSum) return i;
        leftSum += nums[i];
    }
    return -1;
}
```

### Recursive Solution
```java
public int pivotIndex(int[] nums) {
    int total = 0;
    for (int num : nums) total += num;
    return helper(nums, 0, 0, total);
}
private int helper(int[] nums, int i, int leftSum, int total) {
    if (i == nums.length) return -1;
    int rightSum = total - leftSum - nums[i];
    if (leftSum == rightSum) return i;
    return helper(nums, i + 1, leftSum + nums[i], total);
}
```

### Dry Run
```
nums = [1, 7, 3, 6, 5, 6]
total = 28

i=0: leftSum=0,  rightSum=28-0-1=27   → 0≠27
i=1: leftSum=1,  rightSum=28-1-7=20   → 1≠20
i=2: leftSum=8,  rightSum=28-8-3=17   → 8≠17
i=3: leftSum=11, rightSum=28-11-6=11  → 11==11 ✅

Answer: 3
```

## 🟢 Easy #3 — Running Sum of 1D Array (LC 1480)

### Intuition
Simply build the prefix sum in-place. Each element becomes the cumulative sum of all previous elements including itself. The simplest prefix sum application.

### Loop Solution
```java
public int[] runningSum(int[] nums) {
    for (int i = 1; i < nums.length; i++)
        nums[i] += nums[i - 1];
    return nums;
}
```

### Recursive Solution
```java
public int[] runningSum(int[] nums) {
    helper(nums, 1);
    return nums;
}
private void helper(int[] nums, int i) {
    if (i == nums.length) return;
    nums[i] += nums[i - 1];
    helper(nums, i + 1);
}
```

### Dry Run
```
nums = [1, 2, 3, 4]

i=1: nums[1] = 2+1 = 3   → [1,3,3,4]
i=2: nums[2] = 3+3 = 6   → [1,3,6,4]
i=3: nums[3] = 4+6 = 10  → [1,3,6,10]

Answer: [1,3,6,10] ✅
```

## 🟡 Medium #1 — Subarray Sum Equals K (LC 560)

### Intuition
At each index, if `(currentSum - K)` has been seen before as a prefix sum, then the subarray between that earlier index and current index sums to K. Seed the map with `{0:1}` to handle subarrays starting at index 0.

### Loop Solution
```java
public int subarraySum(int[] nums, int k) {
    Map<Integer, Integer> map = new HashMap<>();
    map.put(0, 1);          // ← critical seed
    int sum = 0, count = 0;

    for (int num : nums) {
        sum += num;
        count += map.getOrDefault(sum - k, 0); // subarrays ending here
        map.merge(sum, 1, Integer::sum);
    }
    return count;
}
```

### Recursive Solution
```java
public int subarraySum(int[] nums, int k) {
    Map<Integer, Integer> map = new HashMap<>();
    map.put(0, 1);
    return helper(nums, k, 0, 0, map);
}
private int helper(int[] nums, int k, int i, int sum, Map<Integer,Integer> map) {
    if (i == nums.length) return 0;
    sum += nums[i];
    int count = map.getOrDefault(sum - k, 0);
    map.merge(sum, 1, Integer::sum);
    return count + helper(nums, k, i + 1, sum, map);
}
```

### Dry Run
```
nums = [1, 1, 1],  k = 2
map = {0:1}

i=0: sum=1, need=1-2=-1, map has -1? NO  → count=0, map={0:1,1:1}
i=1: sum=2, need=2-2=0,  map has 0?  YES → count=1, map={0:1,1:1,2:1}
i=2: sum=3, need=3-2=1,  map has 1?  YES → count=2, map={...,3:1}

Answer: 2  ([1,1] at index 0-1 and [1,1] at index 1-2) ✅
```

## 🟡 Medium #2 — Product of Array Except Self (LC 238)

### Intuition
No division allowed. Build two passes: left prefix products (everything to the left of i) and right suffix products (everything to the right of i). Result[i] = leftProduct[i] * rightProduct[i]. Do it in O(1) extra space by using the output array itself for left pass.

### Loop Solution
```java
public int[] productExceptSelf(int[] nums) {
    int n = nums.length;
    int[] result = new int[n];

    // Left pass: result[i] = product of all elements left of i
    result[0] = 1;
    for (int i = 1; i < n; i++)
        result[i] = result[i - 1] * nums[i - 1];

    // Right pass: multiply by product of all elements right of i
    int rightProduct = 1;
    for (int i = n - 1; i >= 0; i--) {
        result[i] *= rightProduct;
        rightProduct *= nums[i];
    }
    return result;
}
```

### Recursive Solution
```java
public int[] productExceptSelf(int[] nums) {
    int n = nums.length;
    int[] result = new int[n];
    result[0] = 1;
    buildLeft(nums, result, 1);   // fill left products
    buildRight(nums, result, n - 1, 1); // multiply right products
    return result;
}
private void buildLeft(int[] nums, int[] result, int i) {
    if (i == nums.length) return;
    result[i] = result[i - 1] * nums[i - 1];
    buildLeft(nums, result, i + 1);
}
private void buildRight(int[] nums, int[] result, int i, int rightProduct) {
    if (i < 0) return;
    result[i] *= rightProduct;
    buildRight(nums, result, i - 1, rightProduct * nums[i]);
}
```

### Dry Run
```
nums = [1, 2, 3, 4]

Left pass (prefix products):
result = [1, 1, 2, 6]
          ↑   ↑   ↑   ↑
         1  1*1 1*2 2*3

Right pass (suffix products):
rightProduct=1
i=3: result[3]=6*1=6,   rightProduct=1*4=4
i=2: result[2]=2*4=8,   rightProduct=4*3=12
i=1: result[1]=1*12=12, rightProduct=12*2=24
i=0: result[0]=1*24=24, rightProduct=24*1=24

Answer: [24, 12, 8, 6] ✅
```

## 🟡 Medium #3 — Subarray Sums Divisible by K (LC 974)

### Intuition
If two prefix sums have the same remainder when divided by K, the subarray between them is divisible by K. Use a frequency map of remainders. Handle negative remainders with `(sum % k + k) % k`. Seed map with `{0:1}`.

### Loop Solution
```java
public int subarraysDivByK(int[] nums, int k) {
    Map<Integer, Integer> map = new HashMap<>();
    map.put(0, 1);          // ← critical seed
    int sum = 0, count = 0;

    for (int num : nums) {
        sum += num;
        int remainder = ((sum % k) + k) % k; // handle negatives
        count += map.getOrDefault(remainder, 0);
        map.merge(remainder, 1, Integer::sum);
    }
    return count;
}
```

### Recursive Solution
```java
public int subarraysDivByK(int[] nums, int k) {
    Map<Integer, Integer> map = new HashMap<>();
    map.put(0, 1);
    return helper(nums, k, 0, 0, map);
}
private int helper(int[] nums, int k, int i, int sum, Map<Integer,Integer> map) {
    if (i == nums.length) return 0;
    sum += nums[i];
    int rem = ((sum % k) + k) % k;
    int count = map.getOrDefault(rem, 0);
    map.merge(rem, 1, Integer::sum);
    return count + helper(nums, k, i + 1, sum, map);
}
```

### Dry Run
```
nums = [4,5,0,-2,-3,1],  k = 5
map = {0:1}

i=0: sum=4,  rem=4%5=4        map has 4? NO  → count=0, map={0:1,4:1}
i=1: sum=9,  rem=9%5=4        map has 4? YES → count=1, map={0:1,4:2}
i=2: sum=9,  rem=9%5=4        map has 4? YES → count+=2=3, map={0:1,4:3}
i=3: sum=7,  rem=7%5=2        map has 2? NO  → count=3, map={...,2:1}
i=4: sum=4,  rem=4%5=4        map has 4? YES → count+=3=6, map={0:1,4:4,2:1}
i=5: sum=5,  rem=5%5=0        map has 0? YES → count+=1=7 ❌

Wait let me recount:
i=5: sum=5, rem=0, map has 0 with count 1 → count=7

Answer: 7 ✅
```

## 🔴 Hard #1 — Count of Range Sum (LC 327)

### Intuition
Build prefix sums. For each `prefix[j]`, count how many earlier `prefix[i]` satisfy `lower ≤ prefix[j] - prefix[i] ≤ upper`. Use **merge sort** on prefix array — during merge, count valid pairs efficiently. This gives O(n log n) instead of O(n²).

### Loop Solution (Merge Sort)
```java
public int countRangeSum(int[] nums, int lower, int upper) {
    int n = nums.length;
    long[] prefix = new long[n + 1];
    for (int i = 0; i < n; i++)
        prefix[i + 1] = prefix[i] + nums[i];
    return mergeCount(prefix, 0, prefix.length, lower, upper);
}

private int mergeCount(long[] prefix, int left, int right, int lower, int upper) {
    if (right - left <= 1) return 0;
    int mid = left + (right - left) / 2;
    int count = mergeCount(prefix, left, mid, lower, upper)
              + mergeCount(prefix, mid, right, lower, upper);

    // Count valid pairs across left and right halves
    int j = mid, k = mid;
    for (int i = left; i < mid; i++) {
        while (k < right && prefix[k] - prefix[i] < lower)  k++;
        while (j < right && prefix[j] - prefix[i] <= upper) j++;
        count += j - k;
    }

    // Standard merge
    long[] sorted = new long[right - left];
    int p = left, q = mid, idx = 0;
    while (p < mid && q < right)
        sorted[idx++] = prefix[p] <= prefix[q] ? prefix[p++] : prefix[q++];
    while (p < mid)  sorted[idx++] = prefix[p++];
    while (q < right) sorted[idx++] = prefix[q++];
    System.arraycopy(sorted, 0, prefix, left, sorted.length);

    return count;
}
```

### Recursive Solution
```java
// The mergeCount above IS the recursive solution.
// Below is a helper wrapper showing the structure clearly:
public int countRangeSum(int[] nums, int lower, int upper) {
    long[] prefix = buildPrefix(nums, new long[nums.length + 1], 0);
    return mergeCount(prefix, 0, prefix.length, lower, upper);
}
private long[] buildPrefix(int[] nums, long[] prefix, int i) {
    if (i == nums.length) return prefix;
    prefix[i + 1] = prefix[i] + nums[i];
    return buildPrefix(nums, prefix, i + 1);
}
// mergeCount same as above
```

### Dry Run
```
nums = [-2, 5, -1],  lower = -2,  upper = 2

prefix = [0, -2, 3, 2]

All pairs (i < j), check if lower ≤ prefix[j]-prefix[i] ≤ upper:
(i=0,j=1): -2-0 = -2  ✅ in [-2,2]
(i=0,j=2):  3-0 =  3  ❌
(i=0,j=3):  2-0 =  2  ✅ in [-2,2]
(i=1,j=2):  3-(-2)=5  ❌
(i=1,j=3):  2-(-2)=4  ❌
(i=2,j=3):  2-3 = -1  ✅ in [-2,2]

Answer: 3 ✅
```

## 🔴 Hard #2 — Range Sum Query 2D - Immutable (LC 304)

### Intuition
Build a 2D prefix sum where `prefix[i][j]` = sum of rectangle from `(0,0)` to `(i-1,j-1)`. Use inclusion-exclusion to answer any rectangle query in O(1). The formula adds back the doubly-subtracted top-left corner.

### Loop Solution
```java
class NumMatrix {
    private int[][] prefix;

    public NumMatrix(int[][] matrix) {
        int m = matrix.length, n = matrix[0].length;
        prefix = new int[m + 1][n + 1];
        for (int i = 1; i <= m; i++)
            for (int j = 1; j <= n; j++)
                prefix[i][j] = matrix[i-1][j-1]
                             + prefix[i-1][j]
                             + prefix[i][j-1]
                             - prefix[i-1][j-1]; // remove double count
    }

    public int sumRegion(int r1, int c1, int r2, int c2) {
        return prefix[r2+1][c2+1]
             - prefix[r1][c2+1]
             - prefix[r2+1][c1]
             + prefix[r1][c1];     // add back double-subtracted corner
    }
}
```

### Recursive Solution
```java
class NumMatrix {
    private int[][] prefix;

    public NumMatrix(int[][] matrix) {
        int m = matrix.length, n = matrix[0].length;
        prefix = new int[m + 1][n + 1];
        buildPrefix(matrix, 1, 1, m, n);
    }
    private void buildPrefix(int[][] matrix, int i, int j, int m, int n) {
        if (i > m) return;
        if (j > n) { buildPrefix(matrix, i + 1, 1, m, n); return; }
        prefix[i][j] = matrix[i-1][j-1]
                     + prefix[i-1][j]
                     + prefix[i][j-1]
                     - prefix[i-1][j-1];
        buildPrefix(matrix, i, j + 1, m, n);
    }

    public int sumRegion(int r1, int c1, int r2, int c2) {
        return prefix[r2+1][c2+1]
             - prefix[r1][c2+1]
             - prefix[r2+1][c1]
             + prefix[r1][c1];
    }
}
```
