### Basic Java 21 template

```java
class Node { Node[] next = new Node[26]; int pass, end; }
Node root = new Node();
for (char ch : word.toCharArray()) {
    int c = ch - 'a';
    if (root.next[c] == null) root.next[c] = new Node();
    root = root.next[c]; root.pass++;
}
root.end++; // for deletion: first verify existence, then decrement path counts
```

**Core invariant:** Follow one edge per letter; only the final node marks a complete word.

### 208 · Question 01/27

#### Problem statement

Implement a dictionary supporting insertion, exact word search and checking whether any stored word starts with a given prefix.

#### Examples

- insert("apple"); search("apple") → true; search("app") → false; startsWith("app") → true
- insert("app"); search("app") → true

#### Constraints

Lowercase English letters; word/prefix length 1–2000; at most 30,000 calls.

#### Why this approach

Exact word and prefix queries over a dynamic lowercase dictionary; fixed-26-child nodes, terminal flag.

#### Solution progression

Foundation of a new algorithm family. walk or create one node per character; terminal distinguishes words from prefixes.

#### Complete Java 21 solution

```java
class Trie {
    static class Node { Node[] next = new Node[26]; boolean end; }
    private final Node root = new Node();
    public Trie() {}
    public void insert(String word) {
        Node p = root;
        for (char c : word.toCharArray()) {
            int i = c - 'a';
            if (p.next[i] == null) p.next[i] = new Node();
            p = p.next[i];
        }
        p.end = true;
    }
    private Node walk(String s) {
        Node p = root;
        for (char c : s.toCharArray()) {
            p = p.next[c - 'a'];
            if (p == null) return null;
        }
        return p;
    }
    public boolean search(String word) { Node p = walk(word); return p != null && p.end; }
    public boolean startsWith(String prefix) { return walk(prefix) != null; }
}
```

#### Key logic

Follow one edge per letter; only the final node marks a complete word.

#### Complexity

- **Time:** O(L) per operation
- **Space:** O(S) nodes for S inserted characters

**Local validation:** PASS

### 1804 · Question 02/27

#### Problem statement

Implement a multiset dictionary with insert, countWordsEqualTo, countWordsStartingWith and erase (one occurrence). Erase is called only for an existing word.

#### Examples

- insert("apple") twice; countWordsEqualTo("apple") → 2; erase("apple"); countWordsEqualTo("apple") → 1
- insert("app"); countWordsStartingWith("app") → 2

#### Constraints

Lowercase letters; length 1–2000; at most 30,000 operations.

#### Why this approach

Dictionary with repeated inserts, prefix counts, and erasure; node passCount/endCount with safe decrement.

#### Solution progression

Extend terminal boolean into terminal and prefix multiplicities; add erase path with decrement after confirmed existence.

#### Complete Java 21 solution

```java
class Trie {
    static class Node { Node[] next = new Node[26]; int pass, end; }
    private final Node root = new Node();
    public Trie() {}
    public void insert(String word) {
        Node p = root;
        for (char c : word.toCharArray()) {
            int i = c - 'a';
            if (p.next[i] == null) p.next[i] = new Node();
            p = p.next[i]; p.pass++;
        }
        p.end++;
    }
    private Node walk(String s) {
        Node p = root;
        for (char c : s.toCharArray()) { p = p.next[c-'a']; if (p == null) return null; }
        return p;
    }
    public int countWordsEqualTo(String word) { Node p = walk(word); return p == null ? 0 : p.end; }
    public int countWordsStartingWith(String prefix) { Node p = walk(prefix); return p == null ? 0 : p.pass; }
    public void erase(String word) {
        if (countWordsEqualTo(word) == 0) return;
        Node p = root;
```

## TR18 — Implicit decimal trie and lexicographic rank

**NEW ALGORITHM FAMILY**

**Recognition:** Lexicographic order over integers corresponds to preorder over digit prefixes.

**Questions:** 386, 440

### Basic Java 21 template

```java
long steps(long prefix, long next, long n) {
    long count = 0;
    while (prefix <= n) {
        count += Math.min(n + 1, next) - prefix;
        prefix *= 10; next *= 10;
    }
    return count;
}
// Visit implicit trie for enumeration, or skip steps(prefix,prefix+1,n) for kth.
```

**Core invariant:** Preorder implicit digit trie: descend by multiplying by ten, otherwise climb until a valid next sibling exists.

### 336 · Question 27/27

#### Problem statement

Given distinct words (possibly including the empty string), return all ordered pairs of distinct indices whose concatenation is a palindrome. The problem requests linear time in total word length apart from output.

#### Examples

- ["abcd","dcba","lls","s","sssll"] → [[0,1],[1,0],[3,2],[2,4]]
- ["a",""] → [[0,1],[1,0]]

#### Constraints

1–5000 distinct lowercase words; length 0–300.

#### Why this approach

Find all ordered word pairs forming a palindrome; reverse-word trie stores terminals and remaining palindrome-prefix candidates, check suffix/prefix palindromes during traversal.

#### Solution progression

Foundation of a new algorithm family. trie paths on reversed words with palindrome metadata; report both completed-word and remaining-palindrome cases, not merely suffix equality.

#### Complete Java 21 solution

```java
import java.util.*;
class Solution {
    static class Node {Node[] next=new Node[26];int end=-1;List<Integer> pal=new ArrayList<>();}
    // flags[0][len] means prefix of length len is palindrome;
    // flags[1][start] means suffix beginning at start is palindrome.
    private boolean[][] flags(String s){
        int n=s.length();boolean[][] f=new boolean[2][n+1];f[0][0]=true;f[1][n]=true;
        int[] odd=new int[n],even=new int[n];
        for(int i=0,l=0,r=-1;i<n;i++){
            int k=i>r?1:Math.min(odd[l+r-i],r-i+1);
            while(i-k>=0&&i+k<n&&s.charAt(i-k)==s.charAt(i+k))k++;
            odd[i]=k;int a=i-k+1,b=i+k-1;if(a==0)f[0][b+1]=true;if(b==n-1)f[1][a]=true;
            if(b>r){l=a;r=b;}
        }
        for(int i=0,l=0,r=-1;i<n;i++){
            int k=i>r?0:Math.min(even[l+r-i+1],r-i+1);
            while(i-k-1>=0&&i+k<n&&s.charAt(i-k-1)==s.charAt(i+k))k++;
            even[i]=k;int a=i-k,b=i+k-1;if(k>0){if(a==0)f[0][b+1]=true;if(b==n-1)f[1][a]=true;}
            if(b>r){l=a;r=b;}
        }
        return f;
    }
    public List<List<Integer>> palindromePairs(String[] words){
        Node root=new Node();boolean[][][] all=new boolean[words.length][][];
        for(int i=0;i<words.length;i++){
            String s=words[i];all[i]=flags(s);Node p=root;
            for(int j=s.length()-1;j>=0;j--){if(all[i][0][j+1])p.pal.add(i);int c=s.charAt(j)-'a';if(p.next[c]==null)p.next[c]=new Node();p=p.next[c];}
            p.end=i;p.pal.add(i);
        }
        List<List<Integer>> ans=new ArrayList<>();
        for(int i=0;i<words.length;i++){
            String s=words[i];Node p=root;
            for(int j=0;j<s.length()&&p!=null;j++){if(p.end>=0&&p.end!=i&&all[i][1][j])ans.add(List.of(i,p.end));p=p.next[s.charAt(j)-'a'];}
            if(p!=null)for(int j:p.pal)if(j!=i)ans.add(List.of(i,j));
        }
        return ans;
    }
}
```

#### Key logic

Use Manacher odd/even radii to precompute palindrome prefix/suffix flags in linear time. Reverse trie stores terminal and indices whose remaining original prefix is palindromic. Query checks suffix flags at earlier terminals and candidate list after exhaustion.

#### Complexity

- **Time:** O(S+n+K) for fixed alphabet, K output pairs
- **Space:** O(S+n+K) including output

**Local validation:** PASS
