### LeetCode 55

class Solution {
    public boolean canJump(int[] nums) {
        int farthest = 0;
        for (int i = 0; i < nums.length; i++) {
            if (i > farthest) return false;
            farthest = Math.max(farthest, i + nums[i]);
            if (farthest >= nums.length - 1) return true;
        }
        return true;
    }
}

class Solution {
    public int canCompleteCircuit(int[] gas, int[] cost) {
        int total = 0, tank = 0, start = 0;
        for (int i = 0; i < gas.length; i++) {
            int net = gas[i] - cost[i];
            total += net;

import java.util.Arrays;
class Solution {
    public int findContentChildren(int[] g, int[] s) {
        Arrays.sort(g);
        Arrays.sort(s);

import java.util.Arrays;
class Solution {
    public int numRescueBoats(int[] people, int limit) {

import java.util.Arrays;

import java.util.Arrays;
class Solution {
    public int maximumBags(int[] capacity, int[] rocks, int additionalRocks) {

import java.util.PriorityQueue;
class Solution {
    public String longestDiverseString(int a, int b, int c) {
        PriorityQueue<int[]> pq = new PriorityQueue<>((x, y) -> Integer.compare(y[0], x[0]));
        if (a > 0) pq.offer(new int[]{a, 'a'});
        if (b > 0) pq.offer(new int[]{b, 'b'});
        if (c > 0) pq.offer(new int[]{c, 'c'});
        StringBuilder sb = new StringBuilder();
        while (!pq.isEmpty()) {
            int[] first = pq.poll();
            int n = sb.length();
            if (n >= 2 && sb.charAt(n - 1) == first[1] && sb.charAt(n - 2) == first[1]) {
                if (pq.isEmpty()) break;
                int[] second = pq.poll();
                sb.append((char)second[1]);
                if (--second[0] > 0) pq.offer(second);
                pq.offer(first);
            } else {
                sb.append((char)first[1]);
                if (--first[0] > 0) pq.offer(first);
            }
        }
        return sb.toString();
    }
}

1. **Input:** `nums = [1,2,3,3,4,4,5,6], k = 4`  
   **Output:** `true`  
   **Explanation:** Groups [1,2,3,4] and [3,4,5,6].

2. **Input:** `nums = [3,3,2,2,1,1], k = 3`  
   **Output:** `true`  
   **Explanation:** Two copies of [1,2,3].

3. **Input:** `nums = [1,2,3,4], k = 3`  
   **Output:** `false`  
   **Explanation:** Total card count is not divisible by 3.

**Constraints:**

1 ≤ nums.length ≤ 10^5; 1 ≤ nums[i] ≤ 10^9; 1 ≤ k ≤ nums.length.

**Why This Subpattern Applies:**

To form fixed-length groups of consecutive integers, the smallest remaining value must start a group; consume its necessary successors.

Foundation of this subpattern.

**Java Solution:**

```java
import java.util.TreeMap;
class Solution {
    public boolean isPossibleDivide(int[] nums, int k) {
        if (nums.length % k != 0) return false;
        TreeMap<Integer, Integer> count = new TreeMap<>();
        for (int x : nums) count.merge(x, 1, Integer::sum);
        while (!count.isEmpty()) {
            int start = count.firstKey();
            int copies = count.get(start);
            for (int i = 0; i < k; i++) {
                int value = start + i;
                int have = count.getOrDefault(value, 0);
                if (have < copies) return false;
                if (have == copies) count.remove(value);
                else count.put(value, have - copies);
            }
        }
        return true;
    }
}
```

**Key Logic:**

Split cards into groups of fixed size k with consecutive values: ordered frequencies, repeatedly start at smallest unassigned value; O(n log n) with TreeMap.

**Time Complexity:**

**O(n log n + nk) worst-case for TreeMap lookups and k-value passes; more tightly O(n log n) because each processed key is removed.** The dominant work is the scan, sorting, ordered-map operations, or bounded heap operations shown in the code.

class Solution {
    public int minCost(String colors, int[] neededTime) {
        int cost = 0, max = 0;
        for (int i = 0; i < colors.length(); i++) {
            if (i > 0 && colors.charAt(i) != colors.charAt(i - 1)) max = 0;
            cost += Math.min(max, neededTime[i]);

import java.util.Arrays;
class Solution {
    public int eliminateMaximum(int[] dist, int[] speed) {
        int n = dist.length;
        int[] deadlines = new int[n];
        for (int i = 0; i < n; i++)
            deadlines[i] = (dist[i] - 1) / speed[i] + 1;
        Arrays.sort(deadlines);
        for (int minute = 0; minute < n; minute++)
            if (deadlines[minute] <= minute) return minute;
        return n;
    }
}
