## GR1 — Undirected graph DFS and reachability

**NEW ALGORITHM FAMILY**

**Recognition:** Edges are bidirectional; explore each vertex once with a visited set.

**Core logic:** Mark a state before adding it to the frontier; a single traversal discovers its entire reachable component. Undirected input needs both edge directions, while supplied directed adjacency must not be symmetrized.

**Locked questions:** 1971, 841, 133

### Reusable Java 21 template

```java
List<Integer>[] adj = new List[n];
for (int i=0;i<n;i++) adj[i]=new ArrayList<>();
for (int[] e: edges) { adj[e[0]].add(e[1]); adj[e[1]].add(e[0]); }
boolean[] seen = new boolean[n];
ArrayDeque<Integer> stack = new ArrayDeque<>();
stack.push(source); seen[source]=true;
while (!stack.isEmpty()) {
    int u=stack.pop();
    for (int v:adj[u]) if (!seen[v]) {seen[v]=true; stack.push(v);}
}
```

### 1971

*Registry position: 01/42*

**Problem statement**

Given n vertices numbered 0 through n−1 and undirected edges, determine whether source can reach destination by following any sequence of edges. A vertex reaches itself.

**Examples**

- n=3, edges=[[0,1],[1,2]], source=0, destination=2 → true
- n=3, edges=[[0,1]], source=0, destination=2 → false

**Constraints**

1≤n≤200000; 0≤edges.length≤200000; valid endpoints; no duplicate edges or self-loops.

**Why this algorithm applies**

Undirected existence of path; adjacency-list DFS/BFS in O(V+E). Build both directions. Mark on enqueue so each vertex enters the queue once. Reaching the destination proves a path.

**Exact change from the previous solution**

Foundation of this subpattern.

**Java 21 solution**

```java
import java.util.*;

class Solution {
    public boolean validPath(int n,int[][] edges,int source,int destination) {
        List<Integer>[] g=new List[n];
        for(int i=0;i<n;i++) g[i]=new ArrayList<>();
        for(int[] e:edges) {
            g[e[0]].add(e[1]);
            g[e[1]].add(e[0]);
        }
        boolean[] seen=new boolean[n];
        Queue<Integer> q=new ArrayDeque<>();
        q.add(source);
        seen[source]=true;
        while(!q.isEmpty()) {
            int u=q.remove();
            if(u==destination)return true;
            for(int v:g[u])if(!seen[v]) {
                seen[v]=true;
                q.add(v);
            }
        }
        return false;
    }
}
```

**Key logic**

Build both directions. Mark on enqueue so each vertex enters the queue once. Reaching the destination proves a path.

**Complexity**

O(V+E) time and space.

### 133

*Registry position: 03/42*

**Problem statement**

Given a reference to a node of a connected undirected graph, return a deep copy with new node objects and identical values and adjacency. Return null for an empty graph.

**Examples**

- adjacency=[[2],[1]] → [[2],[1]] with distinct objects
- adjacency=[] → null

**Constraints**

0–100 nodes; unique node values 1–100; no duplicate edges or self-loops. Node is provided by LeetCode.

**Why this algorithm applies**

Graph deep copy; DFS/BFS old-to-new node map, create clone before exploring its neighbors to close cycles. Map each original object to its clone before traversing neighbors; then add cloned neighbor references. This preserves cycles and sharing.

**Exact change from the previous solution**

From 841: Replace boolean visited with identity-to-clone map; add copied edges while traversing existing neighbor references.

**Java 21 solution**

```java
import java.util.*;

class Solution {
    public Node cloneGraph(Node node) {
        if(node==null)return null;
        Map<Node,Node> copies=new IdentityHashMap<>();
        Queue<Node> q=new ArrayDeque<>();
        copies.put(node,new Node(node.val));
        q.add(node);
        while(!q.isEmpty()) {
            Node u=q.remove();
            for(Node v:u.neighbors) {
                if(!copies.containsKey(v)) {
                    copies.put(v,new Node(v.val));
                    q.add(v);
                }
                copies.get(u).neighbors.add(copies.get(v));
            }
        }
        return copies.get(node);
    }
}
```

**Key logic**

Map each original object to its clone before traversing neighbors; then add cloned neighbor references. This preserves cycles and sharing.

**Complexity**

O(V+E) time; O(V) auxiliary space, O(V+E) output.

### 797

Given a directed acyclic graph as adjacency lists, return every path from vertex 0 to vertex n−1. Paths may be returned in any order.

**Examples**

**Constraints**

**Why this algorithm applies**

Enumerate start-to-end paths in a DAG; DFS with append/recurse/undo, copy complete paths. Maintain the current path; copy it at the target and undo each appended vertex when returning. Global visited would incorrectly discard distinct paths.

**Exact change from the previous solution**

Foundation of this subpattern.

**Java 21 solution**

```java
import java.util.*;

class Solution {
    public List<List<Integer>> allPathsSourceTarget(int[][] graph) {
        List<List<Integer>> ans=new ArrayList<>();
        List<Integer> path=new ArrayList<>();
        path.add(0);
        dfs(0,graph,path,ans);
        return ans;
    }
    private void dfs(int u,int[][] g,List<Integer> path,List<List<Integer>> ans) {
        if(u==g.length-1) {
            ans.add(new ArrayList<>(path));
            return;
        }
        for(int v:g[u]) {
            path.add(v);
            dfs(v,g,path,ans);
            path.remove(path.size()-1);
        }
    }
}
```

**Key logic**

### 785

**Exact change from the previous solution**

```java
import java.util.*;

class Solution {
    public boolean isBipartite(int[][] graph) {
        int[] color=new int[graph.length];
        Queue<Integer> q=new ArrayDeque<>();
        for(int s=0;s<graph.length;s++)if(color[s]==0) {
            color[s]=1;
            q.add(s);
            while(!q.isEmpty()) {
                int u=q.remove();
                for(int v:graph[u]) {
                    if(color[v]==0) {
                        color[v]=-color[u];
                        q.add(v);
                    }
                    else if(color[v]==color[u])return false;
                }
            }
        }
        return true;
    }
}
```

## GR4 — Course ordering with Kahn topological sorting

**NEW ALGORITHM FAMILY**

**Recognition:** Directed dependencies require predecessor-before-successor order; remove zero-indegree vertices.

**Core logic:** Indegree is the number of unresolved prerequisites. Process zero-indegree vertices and decrement successors; a partial topological order signals a cycle.

**Locked questions:** 207, 210, 2115

### Reusable Java 21 template

```java
int[] indegree = new int[n];
for (int u=0;u<n;u++) for(int v:adj[u]) indegree[v]++;
ArrayDeque<Integer> q = new ArrayDeque<>();
for(int u=0;u<n;u++) if(indegree[u]==0) q.add(u);
int processed=0;
while(!q.isEmpty()) {
    int u=q.poll(); processed++;
    for(int v:adj[u]) if(--indegree[v]==0) q.add(v);
} // processed == n iff acyclic.
```

```java
import java.util.*;

class Solution {
    public List<String> findAllRecipes(String[] recipes,List<List<String>> ingredients,String[] supplies) {
        Map<String,List<Integer>> depend=new HashMap<>();
        int[] missing=new int[recipes.length];
        for(int i=0;i<recipes.length;i++) {
            missing[i]=ingredients.get(i).size();
            for(String s:ingredients.get(i))depend.computeIfAbsent(s,k->new ArrayList<>()).add(i);
        }
        Queue<String> q=new ArrayDeque<>(Arrays.asList(supplies));
        List<String> ans=new ArrayList<>();
        while(!q.isEmpty())for(int i:depend.getOrDefault(q.remove(),Collections.emptyList()))if(--missing[i]==0) {
            ans.add(recipes[i]);
            q.add(recipes[i]);
        }
        return ans;
    }
}
```

### 802

**Exact change from the previous solution**

```java
import java.util.*;

class Solution {
    public List<Integer> eventualSafeNodes(int[][] graph) {
        int n=graph.length;
        List<Integer>[] rev=new List[n];
        int[] out=new int[n];
        for(int i=0;i<n;i++)rev[i]=new ArrayList<>();
        Queue<Integer> q=new ArrayDeque<>();
        for(int u=0;u<n;u++) {
            out[u]=graph[u].length;
            if(out[u]==0)q.add(u);
            for(int v:graph[u])rev[v].add(u);
        }
        while(!q.isEmpty())for(int p:rev[q.remove()])if(--out[p]==0)q.add(p);
        List<Integer> ans=new ArrayList<>();
        for(int i=0;i<n;i++)if(out[i]==0)ans.add(i);
        return ans;
    }
}
```

### 2360

*Registry position: 11/42*

**Problem statement**

Each vertex has at most one outgoing edge, given by edges[i], with −1 indicating no successor. Return the length of the longest directed cycle, or −1 if none exists.

**Examples**

- edges=[3,3,4,2,3] → 3
- edges=[1,2,-1] → -1

**Constraints**

2≤n≤100000; −1≤edges[i]<n; edges[i]≠i.

**Why this algorithm applies**

Longest cycle in a functional directed graph; identify a back-reference inside the current traversal and compute depth difference. Stamp each visited vertex with a walk ID and position. Re-entering a vertex of the current walk yields cycle length equal to the position difference.

**Exact change from the previous solution**

Foundation of this subpattern.

**Java 21 solution**

```java
import java.util.*;

class Solution {
    public int longestCycle(int[] edges) {
        int n=edges.length,ans=-1;
        int[] walk=new int[n],depth=new int[n];
        for(int s=0;s<n;s++)if(walk[s]==0) {
            int u=s,d=0,id=s+1;
            while(u!=-1&&walk[u]==0) {
                walk[u]=id;
                depth[u]=d++;
                u=edges[u];
            }
            if(u!=-1&&walk[u]==id)ans=Math.max(ans,d-depth[u]);
        }
        return ans;
    }
}
```

**Key logic**

**Complexity**

```java
                }
            }
        }

    }
}
```

```java
import java.util.*;

class Solution {
    record Edge(int v,double p) {
    }
    record State(int u,double p) {
    }
    public double maxProbability(int n,int[][] edges,double[] succProb,int start_node,int end_node) {
        List<Edge>[] g=new List[n];
        for(int i=0;i<n;i++)g[i]=new ArrayList<>();
        for(int i=0;i<edges.length;i++) {
            int u=edges[i][0],v=edges[i][1];

            g[v].add(new Edge(u,succProb[i]));

                    pq.add(new State(e.v(),np));
                }
            }
        }

    }
```

### 2101

*Registry position: 41/42*

**Problem statement**

Each bomb has a center (x,y) and blast radius r. Detonating one bomb triggers any bomb whose center is within its radius, recursively. Choose exactly one initial bomb and return the maximum total number detonated.

**Examples**

- bombs=[[2,1,3],[6,1,4]] → 2
- bombs=[[1,1,1],[10,10,1]] → 1

**Constraints**

1≤n≤100; 1≤x,y,r≤10^5.

**Why this algorithm applies**

Bomb detonation can trigger others in a directed chain; create edges with squared-distance comparison and DFS/BFS from every start. Build directed edges using squared distances and long arithmetic; reachability can be asymmetric because radii differ. Run traversal from each possible start and take the maximum closure size.

**Exact change from the previous solution**

Foundation of this subpattern.

**Java 21 solution**

```java
import java.util.*;

class Solution {
    public int maximumDetonation(int[][] bombs) {
        int n=bombs.length;
        List<Integer>[] g=new List[n];
        for(int i=0;i<n;i++)g[i]=new ArrayList<>();
        for(int i=0;i<n;i++)for(int j=0;j<n;j++)if(i!=j) {
            long dx=(long)bombs[i][0]-bombs[j][0],dy=(long)bombs[i][1]-bombs[j][1],r=bombs[i][2];
            if(dx*dx+dy*dy<=r*r)g[i].add(j);
        }
        int ans=0;
        for(int s=0;s<n;s++) {
            boolean[] seen=new boolean[n];
            Queue<Integer> q=new ArrayDeque<>();
            q.add(s);
            seen[s]=true;
            int count=1;
            while(!q.isEmpty())for(int v:g[q.remove()])if(!seen[v]) {
                seen[v]=true;
                q.add(v);
                count++;
            }
            ans=Math.max(ans,count);
            if(ans==n)return n;
        }
        return ans;
    }
}
```

**Key logic**

Build directed edges using squared distances and long arithmetic; reachability can be asymmetric because radii differ. Run traversal from each possible start and take the maximum closure size.

**Complexity**

O(n²+n(V+E)) time, O(V+E) space, worst-case O(n³) time and O(n²) space.

### 1786

*Registry position: 42/42*

**Problem statement**

Given a connected undirected positively weighted graph on vertices 1 through n, let dist(u) be the shortest distance from u to n. Count paths from 1 to n for which dist strictly decreases at every edge. Return the count modulo 1,000,000,007.

**Examples**

- n=4, edges=[[1,2,1],[1,3,1],[2,4,1],[3,4,1]] → 2
- n=2, edges=[[1,2,7]] → 1

**Constraints**

1≤n≤20000; n−1≤edges.length≤40000; positive weights≤10^5; connected, distinct edges.

**Why this algorithm applies**

Count source-to-target paths whose distance-to-target strictly decreases at each step; Dijkstra from target, then sorted-distance DP. Run Dijkstra from n. Sort vertices by increasing distance, set ways[n]=1, and sum ways of neighbors with strictly smaller distance. Strict decrease creates a DAG even if the original graph contains cycles.

**Exact change from the previous solution**

Foundation of this subpattern.

**Java 21 solution**

```java
import java.util.*;

class Solution {
    public int countRestrictedPaths(int n,int[][] edges) {
        final int MOD=1_000_000_007;
        List<int[]>[] g=new List[n+1];
        for(int i=1;i<=n;i++)g[i]=new ArrayList<>();
        for(int[] e:edges) {
            g[e[0]].add(new int[]{e[1],e[2]});
            g[e[1]].add(new int[]{e[0],e[2]});
        }
        long[] dist=new long[n+1];
        Arrays.fill(dist,Long.MAX_VALUE);
        dist[n]=0;
        PriorityQueue<long[]> pq=new PriorityQueue<>(Comparator.comparingLong(a->a[0]));
        pq.add(new long[]{0,n});
        while(!pq.isEmpty()) {
            long[] s=pq.remove();
            long d=s[0];
            int u=(int)s[1];
            if(d!=dist[u])continue;
            for(int[] e:g[u]) {
                int v=e[0];
                long nd=d+e[1];
                if(nd<dist[v]) {
                    dist[v]=nd;
                    pq.add(new long[]{nd,v});
                }
            }
        }
        Integer[] order=new Integer[n];
        for(int i=0;i<n;i++)order[i]=i+1;
        Arrays.sort(order,Comparator.comparingLong(u->dist[u]));
        int[] ways=new int[n+1];
        ways[n]=1;
        for(int u:order)if(u!=n)for(int[] e:g[u])if(dist[e[0]]<dist[u])ways[u]=(ways[u]+ways[e[0]])%MOD;
        return ways[1];
    }
}
```

**Key logic**

Run Dijkstra from n. Sort vertices by increasing distance, set ways[n]=1, and sum ways of neighbors with strictly smaller distance. Strict decrease creates a DAG even if the original graph contains cycles.

**Complexity**

O((V+E) log(E+1)+V log(V+1)) time; O(V+E) space.
