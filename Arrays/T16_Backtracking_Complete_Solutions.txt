## BT1 — Subset enumeration, duplicate-safe subsequences

**NEW ALGORITHM FAMILY**

**Recognition:** Pick any subset or increasing-by-index subsequence; DFS choices advance an index.

**Invariant:** Path contains only chosen indices before start; later choices cannot reuse an index.

**Core logic:** DFS starting at `start`; emit path at each node. Preserve the invariant when branching, and undo mutable choices before exploring siblings.

**Question sequence:** 78 → 90 → 491

### Basic starter template

```java
void dfs(int start, int[] a, List<Integer> path) {
    // Optionally emit path when the problem's length condition holds.
    for (int i = start; i < a.length; i++) {
        if (!eligible(a[i], path)) continue; // optional constraint
        path.add(a[i]);
        dfs(i + 1, a, path);
        path.remove(path.size() - 1);
    }
}
```

### LC 78 — Question 01/35

**Problem statement:** Given distinct integers nums, return every subset, including the empty subset. The order of subsets is unrestricted.

**Examples:**

- [1,2] → [[],[1],[1,2],[2]]
- [0] → [[],[0]]

**Constraints:** 1 ≤ n ≤ 10; -10 ≤ nums[i] ≤ 10; distinct values.

**Why this pattern applies:** Pick any subset or increasing-by-index subsequence; DFS choices advance an index. DFS starting at `start`; emit path at each node.

**Connection:** This is the foundation problem of a NEW ALGORITHM FAMILY. BASE: append current path, then choose any later index, recurse, undo.

**Java 21 solution:**

```java
import java.util.*;

class Solution {
    public List<List<Integer>> subsets(int[] nums) {
        var out=new ArrayList<List<Integer>>();
        dfs(nums,0,new ArrayList<>(),out);
        return out;
    }
    void dfs(int[] a,int s,List<Integer> p,List<List<Integer>> out) {
        out.add(new ArrayList<>(p));
        for(int i=s;i<a.length;i++) {
            p.add(a[i]);
            dfs(a,i+1,p,out);
            p.remove(p.size()-1);
        }
    }
}
```

**Key logic:** Emit a copy at every node; advance the index and remove the last choice after recursion.

**Complexity:** O(n·2^n) time including copies; O(n) auxiliary space.

### LC 90 — Question 02/35

**Problem statement:** Given integers possibly containing duplicates, return all distinct subsets, including empty. Order is unrestricted.

**Examples:**

- [1,2,2] → [[],[1],[1,2],[1,2,2],[2],[2,2]]
- [0] → [[],[0]]

**Constraints:** 1 ≤ n ≤ 10; -10 ≤ nums[i] ≤ 10.

**Why this pattern applies:** Pick any subset or increasing-by-index subsequence; DFS choices advance an index. Sort first and skip equal values at the *same DFS depth*.

**Connection:** Keep choose/recurse/undo; sort and add `i>start && a[i]==a[i-1]` pruning.

**Java 21 solution:**

```java
import java.util.*;

class Solution {
    public List<List<Integer>> subsetsWithDup(int[] a) {
        Arrays.sort(a);
        var out=new ArrayList<List<Integer>>();
        dfs(a,0,new ArrayList<>(),out);

            dfs(a,i+1,p,out);
            p.remove(p.size()-1);
        }
    }
}
```

**Key logic:** Sort; skip identical siblings, not repeated values chosen at different depths.

**Complexity:** O(n·2^n) time; O(n) auxiliary space.

### LC 491 — Question 03/35

**Problem statement:** Return all distinct nondecreasing subsequences of nums with at least two elements. Preserve original index order; equal adjacent selected values are allowed.

**Examples:**

- [4,6,7,7] → [[4,6],[4,6,7],[4,6,7,7],[4,7],[4,7,7],[6,7],[6,7,7],[7,7]]
- [4,3,2] → []

**Constraints:** 1 ≤ n ≤ 15; -100 ≤ nums[i] ≤ 100.

**Why this pattern applies:** Pick any subset or increasing-by-index subsequence; DFS choices advance an index. Retain index-increasing DFS; enforce nondecreasing chosen values and use per-depth `HashSet` for duplicates without sorting input.

**Connection:** Replace sorted adjacent-equal skip with depth-local seen set; require `a[i]>=last`; emit only length≥2.

**Java 21 solution:**

```java
import java.util.*;

class Solution {
    public List<List<Integer>> findSubsequences(int[] a) {
        var out=new ArrayList<List<Integer>>();
        dfs(a,0,new ArrayList<>(),out);
        return out;
    }
    void dfs(int[] a,int s,List<Integer> p,List<List<Integer>> out) {
        if(p.size()>=2)out.add(new ArrayList<>(p));
        Set<Integer> seen=new HashSet<>();
        for(int i=s;i<a.length;i++) {
            if(!p.isEmpty()&&a[i]<p.get(p.size()-1)||!seen.add(a[i]))continue;
            p.add(a[i]);
            dfs(a,i+1,p,out);
            p.remove(p.size()-1);
        }
    }
}
```

**Key logic:** Do not sort; a set at each depth prevents duplicate sibling choices; compare with path tail.

**Complexity:** O(n·2^n) time; O(n²) auxiliary upper bound for active sets.

## BT2 — Fixed-length combinations and target pruning

**NEW ALGORITHM FAMILY**

**Recognition:** Choose k different candidates without regard to order; recurse with a strictly increasing next index.

**Invariant:** Path has k_initial − slots elements; next candidate exceeds every chosen number.

**Core logic:** DFS next number, slots left, prune when too few candidates remain. Preserve the invariant when branching, and undo mutable choices before exploring siblings.

```java
void choose(int next, int slots, int upper, List<Integer> path) {

        path.add(x);

        path.remove(path.size() - 1);
```

## BT3 — Target-sum combinations with candidate reuse policy

**NEW ALGORITHM FAMILY**

**Recognition:** Find all unordered selections reaching target; sort candidates and prune when remaining value is too small.

**Invariant:** Path sum plus remaining target equals original target; candidate indices never decrease.

**Core logic:** Sort; DFS remaining sum; recurse using same index to allow reuse. Preserve the invariant when branching, and undo mutable choices before exploring siblings.

**Question sequence:** 39 → 40

### Basic starter template

```java
void choose(int start, int remain, int[] a, List<Integer> path) {

    for (int i = start; i < a.length && a[i] <= remain; i++) {
        path.add(a[i]);
        choose(i, remain - a[i], a, path); // i+1 for single-use variant
        path.remove(path.size() - 1);
    }
}
```

## BT4 — Permutation generation and multiplicity control

**NEW ALGORITHM FAMILY**

**Recognition:** Order matters; at each depth choose an unused value, not merely a later index.

**Invariant:** Used flags or remaining frequencies exactly describe occurrences not yet placed.

**Core logic:** DFS with used[] and path; record when path length reaches n. Preserve the invariant when branching, and undo mutable choices before exploring siblings.

**Question sequence:** 46 → 47 → 1079

### Basic starter template

```java
void permute(int[] a, boolean[] used, List<Integer> path) {
    if (path.size() == a.length) { /* record */ return; }
    for (int i = 0; i < a.length; i++) {
        if (used[i]) continue;
        used[i] = true; path.add(a[i]);
        permute(a, used, path);
        path.remove(path.size() - 1); used[i] = false;
    }
}
```

### LC 1079 — Question 10/35

**Problem statement:** Given uppercase letter tiles, count distinct nonempty strings obtainable using each tile at most once. Different orders count separately.

**Examples:**

- AAB → 8
- V → 1

**Constraints:** 1 ≤ tiles.length ≤ 7; uppercase English letters.

**Why this pattern applies:** Order matters; at each depth choose an unused value, not merely a later index. Count character frequencies, choose each distinct remaining character, count each prefix without materializing sequences.

**Connection:** Replace sorted indices/used[] and path-list output with frequency decrements and a counter; count every nonempty DFS branch.

**Java 21 solution:**

```java
import java.util.*;

class Solution {
    public int numTilePossibilities(String tiles) {
        int[] f=new int[26];
        for(char c:tiles.toCharArray())f[c-'A']++;
        return dfs(f);
    }
    int dfs(int[] f) {
        int ans=0;
        for(int i=0;i<26;i++) {
            if(f[i]==0)continue;
            f[i]--;
            ans+=1+dfs(f);
            f[i]++;
        }
        return ans;
    }
}
```

**Key logic:** Use a frequency table; each available letter creates one new sequence and all its extensions.

**Complexity:** O(26·n!) time worst case; O(n+26) auxiliary space.

### LC 784 — Question 12/35

**Problem statement:** Return every string formed by independently changing each letter to lowercase or uppercase; digits stay unchanged.

**Examples:**

- a1b2 → [a1b2,a1B2,A1b2,A1B2]
- 3z4 → [3z4,3Z4]

**Java 21 solution:**

```java
import java.util.*;

class Solution {
    public List<String> letterCasePermutation(String s) {
        var out=new ArrayList<String>();
        dfs(s,0,new StringBuilder(),out);
        return out;
    }
    void dfs(String s,int i,StringBuilder p,List<String> out) {
        if(i==s.length()) {
            out.add(p.toString());
            return;
        }
        char c=s.charAt(i);
        p.append(Character.toLowerCase(c));
        dfs(s,i+1,p,out);
        p.setLength(p.length()-1);
        if(Character.isLetter(c)) {
```

```java
        Arrays.fill(col,0);

        for(int r=0;r<9;r++)for(int c=0;c<9;c++)if(b[r][c]!='.') {
```

```java
import java.util.*;

class Solution {
    public boolean judgePoint24(int[] cards) {
        var a=new ArrayList<Double>();
        for(int x:cards)a.add((double)x);
        return dfs(a);
    }
    boolean dfs(List<Double> a) {
        int n=a.size();
        if(n==1)return Math.abs(a.get(0)-24)<1e-6;
        for(int i=0;i<n;i++)for(int j=0;j<n;j++) {
            if(i==j)continue;
            double x=a.get(i),y=a.get(j);
            var next=new ArrayList<Double>();
            for(int k=0;k<n;k++)if(k!=i&&k!=j)next.add(a.get(k));
            for(int op=0;op<4;op++) {
                if((op==0||op==2)&&i>j)continue;
                if(op==3&&Math.abs(y)<1e-9)continue;
                double v=switch(op) {
                    case 0->x+y;
                    case 1->x-y;
                    case 2->x*y;
                    default->x/y;
                }
                ;
                next.add(v);
                if(dfs(next))return true;
                next.remove(next.size()-1);
            }
        }
        return false;
    }
}
```

**Key logic:** Pick an ordered pair, reduce it to one arithmetic result, and recurse; guard division near zero and compare with epsilon.

### LC 306 — Question 34/35

**Problem statement:** Determine whether a digit string can be split into at least three nonnegative integer tokens so each token after the first two equals their preceding two-token sum. Multi-digit tokens cannot start with zero.

**Examples:**

- 112358 → true
- 1023 → false

**Constraints:** 1 ≤ length ≤ 35; digits only.

**Why this pattern applies:** Choose initial number boundaries and require all subsequent digits to match the previous-two-number sum. Enumerate first two number lengths; use safe string/long addition and validate exact successive sums without leading zeros.

**Connection:** This is the foundation problem of a NEW ALGORITHM FAMILY. BASE: choose initial tokens; thereafter next token is forced by arithmetic, so backtrack only initial cuts.

**Java 21 solution:**

```java
import java.util.*;
import java.math.BigInteger;

class Solution {
    public boolean isAdditiveNumber(String s) {
        int n=s.length();
        for(int i=1;i<n-1;i++) {
            if(i>1&&s.charAt(0)=='0')break;
            for(int j=i+1;j<n;j++) {
                if(j>i+1&&s.charAt(i)=='0')break;
                BigInteger a=new BigInteger(s.substring(0,i)),b=new BigInteger(s.substring(i,j));
                int p=j;
                while(p<n) {
                    BigInteger c=a.add(b);
                    String t=c.toString();
                    if(!s.startsWith(t,p))break;
                    p+=t.length();
                    a=b;
                    b=c;
                }
                if(p==n)return true;
            }
        }
        return false;
    }
}
```

**Key logic:** Enumerate first two cuts; use BigInteger to avoid overflow, then match forced decimal sum at current position.

**Complexity:** O(n³) arithmetic/character-work estimate with linear decimal addition; BigInteger decimal conversion can add overhead. O(n) live auxiliary digit storage.

**Local verification:** Compiled with Java 21 and passed two example-based assertions/checks (some collection tests check counts rather than full contents).

### LC 842 — Question 35/35

**Problem statement:** Split a digit string into a Fibonacci-like list of at least three nonnegative integers, each subsequent value equal to the sum of the previous two. Every value must fit signed 32-bit nonnegative range, no multi-digit leading zeros. Return any valid list or empty if impossible.

**Examples:**

- 11235813 → [1,1,2,3,5,8,13]
- 0123 → []

**Constraints:** 1 ≤ length ≤ 200; digits only; each result value in 0..2^31−1.

**Why this pattern applies:** Choose initial number boundaries and require all subsequent digits to match the previous-two-number sum. Retain two initial token choices and forced-sum matching, but cap each token at signed 32-bit integer and build result list.

**Connection:** Replace boolean-only validation with recorded int sequence, int overflow checks, and first-found list return.

**Java 21 solution:**

```java
import java.util.*;

class Solution {
    public List<Integer> splitIntoFibonacci(String s) {
        int n=s.length();
        long a=0;
        for(int i=1;i<n-1&&i<=10;i++) {
            if(i>1&&s.charAt(0)=='0')break;
            a=a*10+s.charAt(i-1)-'0';
            if(a>Integer.MAX_VALUE)break;
            long b=0;
            for(int j=i+1;j<n&&j-i<=10;j++) {
                if(j>i+1&&s.charAt(i)=='0')break;
                b=b*10+s.charAt(j-1)-'0';
                if(b>Integer.MAX_VALUE)break;
                var out=new ArrayList<Integer>();
                out.add((int)a);
                out.add((int)b);
                long x=a,y=b;
                int p=j;
                while(p<n) {
                    long z=x+y;
                    if(z>Integer.MAX_VALUE)break;
                    String t=Long.toString(z);
                    if(!s.startsWith(t,p))break;
                    out.add((int)z);
                    p+=t.length();
                    x=y;
                    y=z;
                }
                if(p==n)return out;
            }
        }
        return new ArrayList<>();
    }
}
```

**Key logic:** Limit initial operands to ten digits and Integer.MAX_VALUE; compute sums as long, match exact decimal text and return first complete sequence.

**Complexity:** O(n·min(n,10)^2) time; O(n) auxiliary space including candidate list.
