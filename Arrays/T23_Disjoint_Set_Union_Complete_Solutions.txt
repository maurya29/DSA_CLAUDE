## Shared DSU foundation

Path compression by halving shortens find paths; union by size attaches the smaller tree to the larger. Only roots carry valid size metadata. A failed union leaves the partition unchanged.

```java
static class DSU  {
    int[] p,s;
    int count;
    DSU(int n) {
        p=new int[n];
        s=new int[n];
        count=n;
        for(int i=0;i<n;i++) {
            p[i]=i;
            s[i]=1;
        }
    }
    int find(int x) {
        while(x!=p[x]) {
            p[x]=p[p[x]];
            x=p[x];
        }
        return x;
    }
    boolean union(int a,int b) {
        a=find(a);
        b=find(b);
        if(a==b)return false;
        if(s[a]<s[b]) {
            int t=a;
            a=b;
            b=t;
        }
        p[b]=a;
        s[a]+=s[b];
        count--;
        return true;
    }
}
```

## Subpattern DS1: Connectivity and component statistics

**When to Apply:**

Repeated undirected connectivity or component-size queries: union each edge and examine final roots.

The invariant is that DSU roots represent precisely the equivalence classes created by eligible edges; family-specific metadata or processing order controls which edges are eligible and how the answer is extracted.

**Basic Java Code Snippet:**

```java
int components(int n,int[][] edges) {
    DSU d=new DSU(n);
    for(int[] e:edges)d.union(e[0],e[1]);
    return d.count;
}
```

**Core Logic:**

Adjacency matrix connected components; union pairs i<j when linked, count roots. O(n² α(n)).

**Why This Subpattern Applies:**

Repeated undirected connectivity or component-size queries: union each edge and examine final roots. Each component contributes its size times the number of vertices in later components.

**Connection to Previous Solution:**

Replace count-of-components answer with root sizes and sum size × remaining; use long.

**Java Solution:**

```java
import java.util.*;

class Solution  {
    public long countPairs(int n,int[][] edges) {
```

## Subpattern DS2: Redundant directed/undirected edge detection

**When to Apply:**

An edge can be rejected when endpoints already share a root; directed trees also require indegree constraints.

The invariant is that DSU roots represent precisely the equivalence classes created by eligible edges; family-specific metadata or processing order controls which edges are eligible and how the answer is extracted.

**Basic Java Code Snippet:**

```java
int[] redundant(int n,int[][] edges) {
    DSU d=new DSU(n);
    for(int[] e:edges)if(!d.union(e[0],e[1]))return e;
    return null;
}
```

**Core Logic:**

Find extra undirected edge; first edge whose endpoints already share root closes a cycle. O(nα(n)).

### LeetCode 685

**Question:**

A rooted directed tree on labels 1 through n has one extra directed edge added. Return an edge whose removal restores a rooted tree (one root, every other vertex has exactly one parent and is reachable from the root). Break ties by latest input edge.

**Examples:**

- [[1,2],[1,3],[2,3]] → [2,3]
- [[1,2],[2,3],[3,4],[4,1],[1,5]] → [4,1]

**Constraints:**

3 ≤ n ≤ 1000; n directed edges; distinct endpoints; input is a rooted tree plus one edge.

**Why This Subpattern Applies:**

An edge can be rejected when endpoints already share a root; directed trees also require indegree constraints. Skip the later incoming edge of a two-parent vertex.

**Connection to Previous Solution:**

Add indegree/parent-candidate detection and conditional skip; return correct edge based on whether cycle remains.

**Java Solution:**

```java
import java.util.*;

class Solution  {
    public int[] findRedundantDirectedConnection(int[][] edges) {
        int n=edges.length;
        int[] incoming=new int[n+1];
        Arrays.fill(incoming,-1);
        int a=-1,b=-1;
        for(int i=0;i<n;i++) {
            int v=edges[i][1];
            if(incoming[v]>=0) {
                a=incoming[v];
                b=i;
            }
            else incoming[v]=i;
        }
        DSU d=new DSU(n+1);
        for(int i=0;i<n;i++) {
            if(i==b)continue;
            int[] e=edges[i];
            if(!d.union(e[0],e[1]))return edges[a<0?i:a];
        }
        return edges[b];
    }
    static class DSU  {
        int[] p,s;
        int count;
        DSU(int n) {
            p=new int[n];
            s=new int[n];
            count=n;
            for(int i=0;i<n;i++) {
                p[i]=i;
                s[i]=1;
            }
        }
        int find(int x) {
            while(x!=p[x]) {
                p[x]=p[p[x]];
                x=p[x];
            }
            return x;
        }
        boolean union(int a,int b) {
            a=find(a);
            b=find(b);
            if(a==b)return false;
            if(s[a]<s[b]) {
                int t=a;
                a=b;
                b=t;
            }
            p[b]=a;
            s[a]+=s[b];
            count--;
            return true;
        }
    }
}
```

**Key Logic:**

Skip the later incoming edge of a two-parent vertex. If a cycle survives, remove its earlier incoming edge; otherwise remove the skipped edge. Without two parents, remove the cycle-closing edge.

**Time Complexity:**

O(n α(n)). Includes initialization, the indicated traversal or sorting, and amortized union/find operations.

**Space Complexity:**

O(n). DSU arrays store parent and size; additional structures are included in the stated bound.

## Subpattern DS3: Unify objects by shared identity

**When to Apply:**

Different records refer to one entity when a matching key or permitted relation implies equivalence.

The invariant is that DSU roots represent precisely the equivalence classes created by eligible edges; family-specific metadata or processing order controls which edges are eligible and how the answer is extracted.

**Basic Java Code Snippet:**

```java
DSU group(String[][] keys) {
    DSU d=new DSU(keys.length);
    Map<String,Integer> owner=new HashMap<>();
    for(int i=0;i<keys.length;i++)for(String k:keys[i]) {
        Integer j=owner.putIfAbsent(k,i);
        if(j!=null)d.union(i,j);
    }
    return d;
}
```

**Core Logic:**

Merge accounts by shared emails; map email→first account index, union account indices, gather emails by root. O(E α(n)+E log E).

**Questions Covered:** 721, 839, 1202

### LeetCode 721

**Question:**

Each account contains a name followed by email addresses. Accounts sharing any email belong to the same person, transitively; identical names alone do not establish identity. Merge accounts, returning each name followed by its distinct emails in sorted order. Account order is arbitrary.

**Examples:**

- [["A","x@m","y@m"],["A","y@m","z@m"]] → [["A","x@m","y@m","z@m"]]
- [["A","x@m"],["A","y@m"]] → unchanged

**Constraints:**

1 ≤ accounts.length ≤ 1000; 2–10 strings per account; string lengths 1–30; same person has same name.

**Why This Subpattern Applies:**

Different records refer to one entity when a matching key or permitted relation implies equivalence. Email ownership creates union edges; grouping unique email keys by final root avoids duplicates..

**Connection to Previous Solution:**

Foundation of this subpattern.

**Java Solution:**

```java
import java.util.*;

class Solution  {
    public List<List<String>> accountsMerge(List<List<String>> accounts) {
        int n=accounts.size();
        DSU d=new DSU(n);
        Map<String,Integer> owner=new HashMap<>();
        for(int i=0;i<n;i++)for(int j=1;j<accounts.get(i).size();j++) {
            Integer p=owner.putIfAbsent(accounts.get(i).get(j),i);
            if(p!=null)d.union(i,p);
        }
        Map<Integer,List<String>> groups=new HashMap<>();
        for(var e:owner.entrySet())groups.computeIfAbsent(d.find(e.getValue()),k->new ArrayList<>()).add(e.getKey());
        List<List<String>> ans=new ArrayList<>();
        for(var e:groups.entrySet()) {
            List<String> list=e.getValue();
            Collections.sort(list);
            list.add(0,accounts.get(e.getKey()).get(0));
            ans.add(list);
        }
        return ans;
    }
    static class DSU  {
        int[] p,s;
        int count;
        DSU(int n) {
            p=new int[n];
            s=new int[n];
            count=n;
            for(int i=0;i<n;i++) {
                p[i]=i;
                s[i]=1;
            }
        }
        int find(int x) {
            while(x!=p[x]) {
                p[x]=p[p[x]];
                x=p[x];
            }
            return x;
        }
        boolean union(int a,int b) {
            a=find(a);
            b=find(b);
            if(a==b)return false;
            if(s[a]<s[b]) {
                int t=a;
                a=b;
                b=t;
            }
            p[b]=a;
            s[a]+=s[b];
            count--;
            return true;
        }
    }
}
```

### LeetCode 839

**Question:**

All strings are anagrams of one another. Two strings are similar if equal or if swapping exactly two positions in one makes it equal to the other. Similarity groups are connected components under this relation. Return their count.

**Examples:**

- ["tars","rats","arts","star"] → 2
- ["omv","ovm"] → 1

**Constraints:**

1 ≤ number of strings, length ≤ 300; lowercase; all strings are anagrams.

**Why This Subpattern Applies:**

Different records refer to one entity when a matching key or permitted relation implies equivalence. Stop at a third mismatch; two mismatches must cross-match.

**Connection to Previous Solution:**

Replace email-key unions with O(n²) predicate-driven similarity checks; retain DSU grouping.

**Java Solution:**

```java
import java.util.*;

class Solution  {
    public int numSimilarGroups(String[] strs) {
        DSU d=new DSU(strs.length);
        for(int i=0;i<strs.length;i++)for(int j=i+1;j<strs.length;j++)if(d.find(i)!=d.find(j)&&similar(strs[i],strs[j]))d.union(i,j);
        return d.count;
    }
    boolean similar(String a,String b) {
        int x=-1,y=-1;
        for(int i=0;i<a.length();i++)if(a.charAt(i)!=b.charAt(i)) {
            if(x<0)x=i;
            else if(y<0)y=i;
            else return false;
        }
        return x<0||(y>=0&&a.charAt(x)==b.charAt(y)&&a.charAt(y)==b.charAt(x));
    }

        int[] p,s;
        int count;
        DSU(int n) {
            p=new int[n];
            s=new int[n];
            count=n;
            for(int i=0;i<n;i++) {
                p[i]=i;
                s[i]=1;
            }
        }
        int find(int x) {
            while(x!=p[x]) {
                p[x]=p[p[x]];
                x=p[x];
            }
            return x;
        }
        boolean union(int a,int b) {
            a=find(a);
            b=find(b);
            if(a==b)return false;
            if(s[a]<s[b]) {
                int t=a;
                a=b;
                b=t;
```

```java
        DSU d=new DSU(n);
        for(int[] e:allowedSwaps)d.union(e[0],e[1]);
        Map<Long,Integer> counts=new HashMap<>();
        for(int i=0;i<n;i++)counts.merge(key(d.find(i),source[i]),1,Integer::sum);
        int ans=0;
        for(int i=0;i<n;i++) {
            long k=key(d.find(i),target[i]);
            int c=counts.getOrDefault(k,0);
            if(c==0)ans++;
            else counts.put(k,c-1);
        }
        return ans;
    }
    long key(int root,int value) {
        return ((long)root<<32)|(value&0xffffffffL);
    }
    static class DSU  {
        int[] p,s;
        int count;
        DSU(int n) {
            p=new int[n];
            s=new int[n];
            count=n;
            for(int i=0;i<n;i++) {
                p[i]=i;
                s[i]=1;
            }
        }
        int find(int x) {
            while(x!=p[x]) {
                p[x]=p[p[x]];
                x=p[x];
            }
            return x;
        }
        boolean union(int a,int b) {
            a=find(a);
            b=find(b);
            if(a==b)return false;
            if(s[a]<s[b]) {
                int t=a;
                a=b;
                b=t;
            }
            p[b]=a;
            s[a]+=s[b];
            count--;
            return true;
        }
    }
}
```

**Key Logic:**

Each component can permute freely. Match target occurrences against available source multiplicities, using a collision-free packed root/value key.

**Time Complexity:**

O((n+m) α(n)) expected. Includes initialization, the indicated traversal or sorting, and amortized union/find operations.

**Space Complexity:**

O(n). DSU arrays store parent and size; additional structures are included in the stated bound.

### LeetCode 924

**Question:**

Given a symmetric adjacency matrix graph and distinct initially infected vertices initial, infection spreads along edges until no new vertex is infected. Remove exactly one vertex from the initial infection list (not from the graph). Return the removed vertex minimizing final infections; ties choose the smallest index.

**Examples:**

- graph=[[1,1,0],[1,1,0],[0,0,1]], initial=[0,1] → 0
- graph=[[1,1,0],[1,1,0],[0,0,1]], initial=[0,2] → 0

**Constraints:**

2 ≤ n ≤ 300; binary symmetric matrix with diagonal 1; 1 ≤ initial.length ≤ n; distinct valid indices.

**Why This Subpattern Applies:**

One initially infected vertex can infect its whole connected component; saving a component requires exactly one initial infection. Only a component with exactly one initial infection can be saved by removing that infection.

**Connection to Previous Solution:**

Foundation of this subpattern.

**Java Solution:**

```java
import java.util.*;

class Solution  {
    public int minMalwareSpread(int[][] graph,int[] initial) {
        int n=graph.length;
        DSU d=new DSU(n);
        for(int i=0;i<n;i++)for(int j=i+1;j<n;j++)if(graph[i][j]==1)d.union(i,j);
        int[] infected=new int[n];
        for(int x:initial)infected[d.find(x)]++;
        int ans=n,best=-1;
        for(int x:initial) {
            int r=d.find(x),saved=infected[r]==1?d.s[r]:0;
            if(saved>best||(saved==best&&x<ans)) {
                best=saved;
                ans=x;
            }
        }
        return ans;
    }
    static class DSU  {
        int[] p,s;
        int count;
        DSU(int n) {
            p=new int[n];
            s=new int[n];
            count=n;
            for(int i=0;i<n;i++) {
                p[i]=i;
                s[i]=1;
            }
        }
        int find(int x) {
            while(x!=p[x]) {
                p[x]=p[p[x]];
                x=p[x];
            }
            return x;
        }
        boolean union(int a,int b) {
            a=find(a);
            b=find(b);
            if(a==b)return false;

                int t=a;
                a=b;
                b=t;
            }
            p[b]=a;
            s[a]+=s[b];

            return true;
        }
    }
}
```
