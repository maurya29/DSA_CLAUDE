## 🟢 Easy #1 — Two Sum II (LC 167)

### Intuition
Array is sorted, so use opposite-end pointers. If sum is too small → move left up. If too large → move right down. Guaranteed one solution exists.

### Loop Solution
```java
public int[] twoSum(int[] numbers, int target) {
    int left = 0, right = numbers.length - 1;
    while (left < right) {
        int sum = numbers[left] + numbers[right];
        if (sum == target)       return new int[]{left + 1, right + 1};
        else if (sum < target)   left++;
        else                     right--;
    }
    return new int[]{-1, -1}; // never reached
}
```

### Recursive Solution
```java
public int[] twoSum(int[] numbers, int target) {
    return helper(numbers, target, 0, numbers.length - 1);
}
private int[] helper(int[] nums, int target, int left, int right) {
    if (left >= right) return new int[]{-1, -1};
    int sum = nums[left] + nums[right];
    if (sum == target)      return new int[]{left + 1, right + 1};
    else if (sum < target)  return helper(nums, target, left + 1, right);
    else                    return helper(nums, target, left, right - 1);
}
```

### Dry Run
```
numbers = [2, 7, 11, 15],  target = 9

Step 1: L=0, R=3 → 2+15=17 > 9  → R--
Step 2: L=0, R=2 → 2+11=13 > 9  → R--
Step 3: L=0, R=1 → 2+7=9 == 9   → return [1,2] ✅
```

## 🟢 Easy #2 — Reverse String (LC 344)

### Intuition
Classic opposite-end swap. Left and right pointers move toward each other, swapping characters until they meet in the middle.

### Loop Solution
```java
public void reverseString(char[] s) {
    int left = 0, right = s.length - 1;
    while (left < right) {
        char temp  = s[left];
        s[left]    = s[right];
        s[right]   = temp;
        left++;
        right--;
    }
}
```

### Recursive Solution
```java
public void reverseString(char[] s) {
    reverse(s, 0, s.length - 1);
}
private void reverse(char[] s, int left, int right) {
    if (left >= right) return;          // base case
    char temp = s[left];
    s[left]   = s[right];
    s[right]  = temp;
    reverse(s, left + 1, right - 1);   // recurse inward
}
```

### Dry Run
```
s = ['h','e','l','l','o']

Step 1: L=0,R=4 → swap h,o → ['o','e','l','l','h']
Step 2: L=1,R=3 → swap e,l → ['o','l','l','e','h']
Step 3: L=2,R=2 → L==R → STOP

Result: ['o','l','l','e','h'] ✅
```

## 🟢 Easy #3 — Remove Duplicates from Sorted Array (LC 26)

### Intuition
`slow` pointer marks the last unique element written. `fast` scans ahead — whenever it finds a new unique value, it writes it at `slow+1` and advances slow.

### Loop Solution
```java
public int removeDuplicates(int[] nums) {
    if (nums.length == 0) return 0;
    int slow = 0;
    for (int fast = 1; fast < nums.length; fast++) {
        if (nums[fast] != nums[slow]) {
            slow++;
            nums[slow] = nums[fast];
        }
    }
    return slow + 1; // new length
}
```

### Recursive Solution
```java
public int removeDuplicates(int[] nums) {
    return helper(nums, 0, 1);
}
private int helper(int[] nums, int slow, int fast) {
    if (fast == nums.length) return slow + 1;
    if (nums[fast] != nums[slow]) {
        slow++;
        nums[slow] = nums[fast];
    }
    return helper(nums, slow, fast + 1);
}
```

### Dry Run
```
nums = [1,1,2,3,3]

slow=0, fast=1: nums[1]==nums[0] (1==1) → skip
slow=0, fast=2: nums[2]!=nums[0] (2!=1) → slow=1, nums[1]=2 → [1,2,2,3,3]
slow=1, fast=3: nums[3]!=nums[1] (3!=2) → slow=2, nums[2]=3 → [1,2,3,3,3]
slow=2, fast=4: nums[4]==nums[2] (3==3) → skip

Return slow+1 = 3  ✅  (array = [1,2,3,...])
```

## 🟡 Medium #1 — 3Sum (LC 15)

### Intuition
Sort the array. Fix one element `i`, then run classic two-pointer pair sum on the rest. Skip duplicates at both the `i` level and the `left/right` level to avoid repeated triplets.

### Loop Solution
```java
public List<List<Integer>> threeSum(int[] nums) {
    Arrays.sort(nums);
    List<List<Integer>> result = new ArrayList<>();

    for (int i = 0; i < nums.length - 2; i++) {
        if (i > 0 && nums[i] == nums[i - 1]) continue; // skip dup at i

        int left = i + 1, right = nums.length - 1;
        while (left < right) {
            int sum = nums[i] + nums[left] + nums[right];
            if (sum == 0) {
                result.add(Arrays.asList(nums[i], nums[left], nums[right]));
                while (left < right && nums[left]  == nums[left  + 1]) left++;
                while (left < right && nums[right] == nums[right - 1]) right--;
                left++; right--;
            } else if (sum < 0) left++;
            else                right--;
        }
    }
    return result;
}
```

### Recursive Solution
```java
// Recursive over i; inner two-pointer stays iterative (standard approach)
public List<List<Integer>> threeSum(int[] nums) {
    Arrays.sort(nums);
    List<List<Integer>> result = new ArrayList<>();
    findTriplets(nums, 0, result);
    return result;
}
private void findTriplets(int[] nums, int i, List<List<Integer>> result) {
    if (i >= nums.length - 2) return;
    if (i > 0 && nums[i] == nums[i - 1]) {
        findTriplets(nums, i + 1, result);
        return;
    }
    int left = i + 1, right = nums.length - 1;
    while (left < right) {
        int sum = nums[i] + nums[left] + nums[right];
        if (sum == 0) {
            result.add(Arrays.asList(nums[i], nums[left], nums[right]));
            while (left < right && nums[left]  == nums[left  + 1]) left++;
            while (left < right && nums[right] == nums[right - 1]) right--;
            left++; right--;
        } else if (sum < 0) left++;
        else                right--;
    }
    findTriplets(nums, i + 1, result);
}
```

### Dry Run
```
nums = [-4,-1,-1,0,1,2]  (after sort)

i=0 (-4): L=1,R=5 → -4+(-1)+2=-3 < 0 → L++
          L=2,R=5 → -4+(-1)+2=-3 < 0 → L++
          L=3,R=5 → -4+0+2=-2   < 0 → L++
          L=4,R=5 → -4+1+2=-1   < 0 → L++
          L==R → done for i=0

i=1 (-1): L=2,R=5 → -1+(-1)+2=0 ✅ → add [-1,-1,2]
           skip dups → L=3,R=4
          L=3,R=4 → -1+0+1=0  ✅ → add [-1,0,1]
           L=4,R=3 → stop

i=2 (-1): nums[2]==nums[1] → SKIP

i=3 (0):  L=4,R=5 → 0+1+2=3 > 0 → R--
          L==R → done

Result: [[-1,-1,2],[-1,0,1]] ✅
```

## 🟡 Medium #2 — Container With Most Water (LC 11)

### Intuition
Two pointers at both ends. Area = `min(height[L], height[R]) * (R - L)`. Always move the pointer with the **shorter** height — keeping the taller one gives a chance for larger area.

### Loop Solution
```java
public int maxArea(int[] height) {
    int left = 0, right = height.length - 1;
    int maxWater = 0;
    while (left < right) {
        int h     = Math.min(height[left], height[right]);
        int water = h * (right - left);
        maxWater  = Math.max(maxWater, water);
        if (height[left] < height[right]) left++;
        else                              right--;
    }
    return maxWater;
}
```

### Recursive Solution
```java
public int maxArea(int[] height) {
    return helper(height, 0, height.length - 1, 0);
}
private int helper(int[] h, int left, int right, int maxWater) {
    if (left >= right) return maxWater;
    int water = Math.min(h[left], h[right]) * (right - left);
    maxWater  = Math.max(maxWater, water);
    if (h[left] < h[right]) return helper(h, left + 1, right, maxWater);
    else                    return helper(h, left, right - 1, maxWater);
}
```

### Dry Run
```
height = [1,8,6,2,5,4,8,3,7]

L=0,R=8 → min(1,7)*8  = 8   → move L (1<7)
L=1,R=8 → min(8,7)*7  = 49  → move R (7<8)
L=1,R=7 → min(8,3)*6  = 18  → move R (3<8)
L=1,R=6 → min(8,8)*5  = 40  → move R (equal)
L=1,R=5 → min(8,4)*4  = 16  → move R (4<8)
L=1,R=4 → min(8,5)*3  = 15  → move R (5<8)
L=1,R=3 → min(8,2)*2  = 4   → move R (2<8)
L=1,R=2 → min(8,6)*1  = 6   → move R (6<8)
L==R → STOP

maxWater = 49 ✅
```

## 🟡 Medium #3 — Sort Colors (LC 75)

### Intuition
Dutch National Flag algorithm. Three pointers: `low` (boundary of 0s), `mid` (current), `high` (boundary of 2s). Swap 0s to front and 2s to back in a single pass.

### Loop Solution
```java
public void sortColors(int[] nums) {
    int low = 0, mid = 0, high = nums.length - 1;
    while (mid <= high) {
        if (nums[mid] == 0) {
            swap(nums, low, mid);
            low++; mid++;
        } else if (nums[mid] == 1) {
            mid++;                   // 1 is already in place
        } else {                     // nums[mid] == 2
            swap(nums, mid, high);
            high--;                  // don't mid++ — recheck swapped val
        }
    }
}
private void swap(int[] nums, int i, int j) {
    int temp = nums[i]; nums[i] = nums[j]; nums[j] = temp;
}
```

### Recursive Solution
```java
public void sortColors(int[] nums) {
    helper(nums, 0, 0, nums.length - 1);
}
private void helper(int[] nums, int low, int mid, int high) {
    if (mid > high) return;
    if (nums[mid] == 0) {
        swap(nums, low, mid);
        helper(nums, low + 1, mid + 1, high);
    } else if (nums[mid] == 1) {
        helper(nums, low, mid + 1, high);
    } else {
        swap(nums, mid, high);
        helper(nums, low, mid, high - 1);
    }
}
```

### Dry Run
```
nums = [2,0,2,1,1,0]
low=0, mid=0, high=5

mid=0: nums[0]=2 → swap(0,5) → [0,0,2,1,1,2], high=4
mid=0: nums[0]=0 → swap(0,0) → [0,0,2,1,1,2], low=1,mid=1
mid=1: nums[1]=0 → swap(1,1) → [0,0,2,1,1,2], low=2,mid=2
mid=2: nums[2]=2 → swap(2,4) → [0,0,1,1,2,2], high=3
mid=2: nums[2]=1 → mid=3
mid=3: nums[3]=1 → mid=4
mid=4 > high=3 → STOP

Result: [0,0,1,1,2,2] ✅
```

## 🔴 Hard #1 — Trapping Rain Water (LC 42)

### Intuition
Water at any position = `min(maxLeft, maxRight) - height[i]`. Use two pointers: whichever side has the smaller max, process that side — because the smaller side determines the water level.

### Loop Solution
```java
public int trap(int[] height) {
    int left = 0, right = height.length - 1;
    int maxLeft = 0, maxRight = 0;
    int totalWater = 0;

    while (left < right) {
        if (height[left] <= height[right]) {
            if (height[left] >= maxLeft) maxLeft = height[left];
            else totalWater += maxLeft - height[left];
            left++;
        } else {
            if (height[right] >= maxRight) maxRight = height[right];
            else totalWater += maxRight - height[right];
            right--;
        }
    }
    return totalWater;
}
```

### Recursive Solution
```java
public int trap(int[] height) {
    return helper(height, 0, height.length - 1, 0, 0, 0);
}
private int helper(int[] h, int l, int r, int maxL, int maxR, int water) {
    if (l >= r) return water;
    if (h[l] <= h[r]) {
        maxL = Math.max(maxL, h[l]);
        return helper(h, l + 1, r, maxL, maxR, water + maxL - h[l]);
    } else {
        maxR = Math.max(maxR, h[r]);
        return helper(h, l, r - 1, maxL, maxR, water + maxR - h[r]);
    }
}
```

### Dry Run
```
height = [0,1,0,2,1,0,1,3,1,0,1,2]
L=0,R=11, maxL=0, maxR=0

h[L]=0 <= h[R]=2 → maxL=max(0,0)=0 → water+=0-0=0  → L=1
h[L]=1 <= h[R]=2 → maxL=max(0,1)=1 → water+=1-1=0  → L=2
h[L]=0 <= h[R]=2 → maxL=max(1,0)=1 → water+=1-0=1  → L=3
h[L]=2 <= h[R]=2 → maxL=max(1,2)=2 → water+=2-2=0  → L=4
h[L]=1 <= h[R]=2 → maxL=max(2,1)=2 → water+=2-1=1  → L=5
h[L]=0 <= h[R]=2 → maxL=max(2,0)=2 → water+=2-0=2  → L=6
...continuing...

Total = 6 ✅
```

## 🔴 Hard #2 — 4Sum (LC 18)

### Intuition
Extend 3Sum by adding one more outer loop. Fix two elements `i` and `j`, then run two-pointer on the remaining range. Skip duplicates at all four levels.

### Loop Solution
```java
public List<List<Integer>> fourSum(int[] nums, int target) {
    Arrays.sort(nums);
    List<List<Integer>> result = new ArrayList<>();
    int n = nums.length;

    for (int i = 0; i < n - 3; i++) {
        if (i > 0 && nums[i] == nums[i - 1]) continue;

        for (int j = i + 1; j < n - 2; j++) {
            if (j > i + 1 && nums[j] == nums[j - 1]) continue;

            int left = j + 1, right = n - 1;
            while (left < right) {
                long sum = (long) nums[i] + nums[j] + nums[left] + nums[right];
                if (sum == target) {
                    result.add(Arrays.asList(nums[i],nums[j],nums[left],nums[right]));
                    while (left < right && nums[left]  == nums[left  + 1]) left++;
                    while (left < right && nums[right] == nums[right - 1]) right--;
                    left++; right--;
                } else if (sum < target) left++;
                else                     right--;
            }
        }
    }
    return result;
}
```

### Recursive Solution
```java
public List<List<Integer>> fourSum(int[] nums, int target) {
    Arrays.sort(nums);
    List<List<Integer>> result = new ArrayList<>();
    solve(nums, target, 0, result);
    return result;
}
private void solve(int[] nums, int target, int i, List<List<Integer>> result) {
    if (i >= nums.length - 3) return;
    if (i > 0 && nums[i] == nums[i - 1]) { solve(nums, target, i+1, result); return; }
    solveJ(nums, target, i, i + 1, result);
    solve(nums, target, i + 1, result);
}
private void solveJ(int[] nums, int target, int i, int j, List<List<Integer>> result) {
    if (j >= nums.length - 2) return;
    if (j > i + 1 && nums[j] == nums[j - 1]) { solveJ(nums, target, i, j+1, result); return; }
    int left = j + 1, right = nums.length - 1;
    while (left < right) {
        long sum = (long) nums[i] + nums[j] + nums[left] + nums[right];
        if (sum == target) {
            result.add(Arrays.asList(nums[i], nums[j], nums[left], nums[right]));
            while (left < right && nums[left]  == nums[left  + 1]) left++;
            while (left < right && nums[right] == nums[right - 1]) right--;
            left++; right--;
        } else if (sum < target) left++;
        else right--;
    }
    solveJ(nums, target, i, j + 1, result);
}
```

### Dry Run
```
nums=[-2,-1,0,0,1,2], target=0 (after sort)

i=0(-2), j=1(-1): L=2,R=5 → -2-1+0+2=-1 < 0 → L++
                  L=3,R=5 → -2-1+0+2=-1 < 0 → L++
                  L=4,R=5 → -2-1+1+2=0  ✅ → add[-2,-1,1,2]

i=0(-2), j=2(0):  L=3,R=5 → -2+0+0+2=0  ✅ → add[-2,0,0,2]
                  L=4,R=4 → STOP

i=0(-2), j=3(0):  nums[3]==nums[2] → SKIP

i=0(-2), j=4(1):  L=5,R=5 → STOP (L==R)

i=1(-1), j=2(0):  L=3,R=5 → -1+0+0+2=1 > 0 → R--
                  L=3,R=4 → -1+0+0+1=0  ✅ → add[-1,0,0,1]

...

Result: [[-2,-1,1,2],[-2,0,0,2],[-1,0,0,1]] ✅
```

## 📊 Summary Table

| Problem | Key Technique | Trick |
|---|---|---|
| Two Sum II | Opposite ends converge | Move pointer whose side makes sum wrong |
| Reverse String | Opposite ends swap | Stop at `left < right` not `<=` |
| Remove Duplicates | Slow/fast write pointer | `slow` = last valid index |
| 3Sum | Fix `i` + two pointers | Sort first, skip dups at `i`, `L`, `R` |
| Container With Most Water | Opposite ends, max area | Move the **shorter** height pointer |
| Sort Colors | 3-pointer DNF | Don't `mid++` after swapping with `high` |
| Trapping Rain Water | Two pointers + running max | Process the side with **smaller max** |
| 4Sum | Fix `i`,`j` + two pointers | Use `long` cast to avoid integer overflow |
