### 31. LeetCode 1626

**Problem**

Select a team maximizing sum of scores. A conflict occurs when a strictly younger player has a strictly higher score than an older player. Equal ages never conflict.

**Examples**

- scores=[1,3,5,10,15], ages=[1,2,3,4,5] → 34
- scores=[4,5,6,5], ages=[2,1,2,1] → 16

**Constraints**

1 ≤ n ≤ 1000; scores ≤ 10^6; ages ≤ 1000; all positive

**Why this approach / key logic**

Sort by age then score so compatible teams are nondecreasing in score. dp[i] is best team ending at player i; extend any compatible predecessor.

**Locked strategy:** Sort by age then score; weighted nondecreasing-score subsequence O(n²) or Fenwick max compression.

**Evolution from previous solution:** BASE: choose best compatible prior chain plus current score.

**Java 21 solution**

```java
import java.util.*;

class Solution {
    public int bestTeamScore(int[] scores,int[] ages) {
        int n=scores.length;
        int[][] p=new int[n][2];
        for(int i=0;i<n;i++)p[i]=new int[] {
            ages[i],scores[i]
        }
        ;
        Arrays.sort(p,Comparator.<int[]>comparingInt(a->a[0]).thenComparingInt(a->a[1]));
        int[] dp=new int[n];
        int ans=0;
        for(int i=0;i<n;i++) {
            dp[i]=p[i][1];
            for(int j=0;j<i;j++)if(p[j][1]<=p[i][1])dp[i]=Math.max(dp[i],dp[j]+p[i][1]);
            ans=Math.max(ans,dp[i]);
        }
        return ans;
    }
}
```

**Complexity:** O(n²) time, O(n) space.

### 32. LeetCode 368

**Problem**

Return any largest subset of distinct positive integers in which every pair has one member divisible by the other.

**Examples**

- [1,2,3] → [1,2] or [1,3]
- [1,2,4,8] → [1,2,4,8]

**Constraints**

1 ≤ n ≤ 1000; 1 ≤ nums[i] ≤ 2×10^9; distinct values

**Why this approach / key logic**

Sort ascending. Divisibility is transitive, so extending a divisible chain guarantees pairwise compatibility. Store predecessor indices to reconstruct it.

**Locked strategy:** Sort numeric values, dp length plus predecessor index, reconstruct maximum divisible chain.

**Evolution from previous solution:** Replace age/score compatibility with later%earlier==0, score with chain length, and add reconstruction pointers.

**Java 21 solution**

```java
import java.util.*;

class Solution {
    public List<Integer> largestDivisibleSubset(int[] nums) {
        Arrays.sort(nums);
        int n=nums.length;
        int[] dp=new int[n],prev=new int[n];
        Arrays.fill(dp,1);
        Arrays.fill(prev,-1);
        int best=0;
        for(int i=0;i<n;i++) {
            for(int j=0;j<i;j++)if(nums[i]%nums[j]==0&&dp[j]+1>dp[i]) {
                dp[i]=dp[j]+1;
                prev[i]=j;
            }
            if(dp[i]>dp[best])best=i;
        }
        List<Integer> ans=new ArrayList<>();
        for(int i=best;i!=-1;i=prev[i])ans.add(nums[i]);
        Collections.reverse(ans);
        return ans;
    }
}
```

**Complexity:** O(n²) time, O(n) space.

### 33. LeetCode 1143

**Problem**

Return the maximum length of a sequence obtainable from both strings by deleting zero or more characters without changing order.

**Examples**

- abcde, ace → 3
- abc, def → 0

**Constraints**

1 ≤ string lengths ≤ 1000; lowercase English letters

**Why this approach / key logic**

dp[j] holds the preceding row before update. Preserve its old diagonal; match adds one, mismatch takes max of top and left.

**Locked strategy:** 2D LCS or one-row DP using diagonal preserved previous-row state.

**Evolution from previous solution:** BASE: equal tokens extend diagonal; unequal tokens discard one side.

**Java 21 solution**

```java
import java.util.*;

class Solution {
    public int longestCommonSubsequence(String a,String b) {
        if(a.length()<b.length())return longestCommonSubsequence(b,a);
        int[] dp=new int[b.length()+1];
        for(int i=1;i<=a.length();i++) {
            int diag=0;
            for(int j=1;j<=b.length();j++) {
                int old=dp[j];
                dp[j]=a.charAt(i-1)==b.charAt(j-1)?diag+1:Math.max(dp[j],dp[j-1]);
                diag=old;
            }
        }
        return dp[b.length()];
    }
}
```

**Complexity:** O(mn) time, O(min(m,n)) space.

### 35. LeetCode 583

**Problem**

Delete one character from either string per operation. Return the fewest operations needed to make them equal.

**Examples**

- sea, eat → 2
- leetcode, etco → 4

**Constraints**

1 ≤ lengths ≤ 500; lowercase letters

**Why this approach / key logic**

The common remainder must be a common subsequence. Keep the longest possible remainder and delete everything else.

**Locked strategy:** Find LCS and calculate len(a)+len(b)-2*LCS.

**Evolution from previous solution:** Keep LCS table; replace output length with deletions computed from LCS.

**Java 21 solution**

```java
import java.util.*;

class Solution {
    public int minDistance(String a,String b) {
        if(a.length()<b.length())return minDistance(b,a);
        int[] dp=new int[b.length()+1];
        for(int i=0;i<a.length();i++) {
            char c=a.charAt(i);
            int diag=0;
            for(int j=1;j<=b.length();j++) {
                int old=dp[j];
                dp[j]=c==b.charAt(j-1)?diag+1:Math.max(dp[j],dp[j-1]);
                diag=old;
            }
        }
        return a.length()+b.length()-2*dp[b.length()];
    }
}
```

**Complexity:** O(mn) time, O(min(m,n)) space.

### 36. LeetCode 1092

**Problem**

Return any shortest string containing both input strings as subsequences.

**Examples**

- abac, cab → cabac
- aaa, aaa → aaa

**Constraints**

1 ≤ lengths ≤ 1000; lowercase letters

**Why this approach / key logic**

Keep full LCS table for traceback. Matching endpoints are emitted once; otherwise follow the larger LCS predecessor and emit the discarded endpoint. Reverse at end.

**Locked strategy:** Build LCS table, backtrack and emit common characters once and unmatched chars from either input.

**Evolution from previous solution:** Retain LCS recurrence; replace scalar answer with traceback and sequence reconstruction.

**Java 21 solution**

```java
import java.util.*;

class Solution {
    public String shortestCommonSupersequence(String a,String b) {
        int m=a.length(),n=b.length();
        int[][] dp=new int[m+1][n+1];
        for(int i=1;i<=m;i++)for(int j=1;j<=n;j++)dp[i][j]=a.charAt(i-1)==b.charAt(j-1)?1+dp[i-1][j-1]:Math.max(dp[i-1][j],dp[i][j-1]);
        StringBuilder sb=new StringBuilder();
        int i=m,j=n;
        while(i>0&&j>0) {
            if(a.charAt(i-1)==b.charAt(j-1)) {
                sb.append(a.charAt(--i));
                j--;
            }
            else if(dp[i-1][j]>=dp[i][j-1])sb.append(a.charAt(--i));
            else sb.append(b.charAt(--j));
        }
        while(i>0)sb.append(a.charAt(--i));
        while(j>0)sb.append(b.charAt(--j));
        return sb.reverse().toString();
    }
}
```

**Complexity:** O(mn) time, O(mn) space.

### 37. LeetCode 72

**Problem**

Convert one string into another using single-character insertion, deletion or replacement, each costing one. Return minimum operations.

**Examples**

- horse, ros → 3
- intention, execution → 5
- empty, abc → 3

**Constraints**

0 ≤ lengths ≤ 500; lowercase letters

**Why this approach / key logic**

Prefix edit distance uses diagonal for match/replacement, top for deletion, left for insertion. Empty prefix costs its opposite length.

**Locked strategy:** Levenshtein edit-distance 2D or two-row DP.

**Evolution from previous solution:** BASE: prefix alignment with three paid edits.

**Java 21 solution**

```java
import java.util.*;

class Solution {
    public int minDistance(String a,String b) {
        if(a.length()<b.length())return minDistance(b,a);
        int[] dp=new int[b.length()+1];
        for(int j=0;j<dp.length;j++)dp[j]=j;
        for(int i=1;i<=a.length();i++) {
            int diag=dp[0];
            dp[0]=i;
            for(int j=1;j<dp.length;j++) {
                int old=dp[j];
                dp[j]=a.charAt(i-1)==b.charAt(j-1)?diag:1+Math.min(diag,Math.min(dp[j],dp[j-1]));
                diag=old;
            }
        }
        return dp[b.length()];
    }
}
```

**Complexity:** O(mn) time, O(min(m,n)) space.

### 38. LeetCode 712

**Problem**

Delete characters from either string until equal; each deletion costs its character ASCII value. Return minimum total cost.

**Examples**

- sea, eat → 231
- delete, leet → 403

**Constraints**

1 ≤ lengths ≤ 1000; lowercase letters

**Why this approach / key logic**

Initialize empty-prefix costs as ASCII sums. Matching characters cost zero; mismatches choose one of two weighted deletions.

**Locked strategy:** 2D min-cost DP with delete-from-left/right and zero-cost matching.

**Evolution from previous solution:** Remove substitution branch; replace unit operation costs with character ASCII deletion weights.

**Java 21 solution**

```java
import java.util.*;

class Solution {
    public int minimumDeleteSum(String a,String b) {
        if(a.length()<b.length())return minimumDeleteSum(b,a);
        int[] dp=new int[b.length()+1];
        for(int j=1;j<dp.length;j++)dp[j]=dp[j-1]+b.charAt(j-1);
        for(int i=1;i<=a.length();i++) {
            char x=a.charAt(i-1);
            int diag=dp[0];
            dp[0]+=x;
            for(int j=1;j<dp.length;j++) {
                char y=b.charAt(j-1);
                int old=dp[j];
                dp[j]=x==y?diag:Math.min(old+x,dp[j-1]+y);
                diag=old;
            }
        }
        return dp[b.length()];
    }
}
```

**Complexity:** O(mn) time, O(min(m,n)) space.

### 39. LeetCode 97

**Problem**

Determine whether target can be formed by interleaving all characters of two strings while preserving each source order.

**Examples**

- aabcc, dbbca, aadbbcbcac → true
- aabcc, dbbca, aadbbbaccc → false
- empty, empty, empty → true

**Constraints**

0 ≤ source lengths ≤ 100; 0 ≤ target length ≤ 200; lowercase letters

**Why this approach / key logic**

Reject unequal total length. State (i,j) reaches target prefix i+j from either source when its next character matches.

**Locked strategy:** Boolean prefix DP where a state is valid if the next target char matches either input source.

**Evolution from previous solution:** Replace min-cost edit state with boolean reachability and enforce exact combined target prefix.

**Java 21 solution**

```java
import java.util.*;

class Solution {
    public boolean isInterleave(String a,String b,String c) {
        if(a.length()+b.length()!=c.length())return false;
        if(a.length()<b.length())return isInterleave(b,a,c);
        int n=b.length();
        boolean[] dp=new boolean[n+1];
        dp[0]=true;
        for(int i=0;i<=a.length();i++)for(int j=0;j<=n;j++) {
            if(i==0&&j==0)continue;
            char t=c.charAt(i+j-1);
            dp[j]=(i>0&&dp[j]&&a.charAt(i-1)==t)||(j>0&&dp[j-1]&&b.charAt(j-1)==t);
        }
        return dp[n];
    }
}
```

**Complexity:** O(mn+m+n) time, O(min(m,n)+1) space.

### 40. LeetCode 44

**Problem**

Match the entire text against a pattern where ? matches exactly one character and * matches any sequence including empty.

**Examples**

- aa, a → false
- aa, * → true
- cb, ?a → false

**Constraints**

0 ≤ text and pattern lengths ≤ 2000; lowercase letters and pattern symbols ? and *

**Why this approach / key logic**

For star, left state consumes no text and top state consumes one more character. Literal or question mark uses diagonal.

**Locked strategy:** 2D boolean DP: ? or literal consumes one char, * consumes zero or more.

**Evolution from previous solution:** BASE: wildcard pattern states with zero-length and growing consumption.

**Java 21 solution**

```java
import java.util.*;

class Solution {
    public boolean isMatch(String s,String p) {
        int n=p.length();
        boolean[] dp=new boolean[n+1];
        dp[0]=true;
        for(int j=1;j<=n;j++)dp[j]=dp[j-1]&&p.charAt(j-1)=='*';
        for(int i=1;i<=s.length();i++) {
            boolean diag=dp[0];
            dp[0]=false;
            for(int j=1;j<=n;j++) {
                boolean old=dp[j];
                char x=p.charAt(j-1);
                dp[j]=x=='*'?(old||dp[j-1]):diag&&(x=='?'||x==s.charAt(i-1));
                diag=old;
            }
        }
        return dp[n];
    }
}
```

**Complexity:** O(mn+m+n) time, O(n+1) space, n=pattern length.

### 41. LeetCode 10

**Problem**

Match entire text against regex with . matching any one character and * matching zero or more repetitions of its preceding atom.

**Examples**

- aa, a → false
- aa, a* → true
- ab, .* → true

**Constraints**

1 ≤ text and pattern lengths ≤ 20; lowercase letters, . and *; each * has a valid preceding atom

**Why this approach / key logic**

A starred atom either disappears (two pattern positions back) or consumes matching text while retaining the same pattern prefix.

**Locked strategy:** 2D boolean DP: x* removes last two pattern symbols or consumes matching text while staying on quantifier.

**Evolution from previous solution:** Replace free-standing * transition with 0+ repeats tied to preceding pattern atom; initialize empty-text states accordingly.

**Java 21 solution**

```java
import java.util.*;

class Solution {
    public boolean isMatch(String s,String p) {
        int n=p.length();
        boolean[] dp=new boolean[n+1];
        dp[0]=true;
        for(int j=2;j<=n;j++)if(p.charAt(j-1)=='*')dp[j]=dp[j-2];
        for(int i=1;i<=s.length();i++) {
            boolean diag=dp[0];
            dp[0]=false;
            for(int j=1;j<=n;j++) {
                boolean old=dp[j];
                char x=p.charAt(j-1),c=s.charAt(i-1);
                if(x=='*') {
                    char a=p.charAt(j-2);
                    dp[j]=dp[j-2]||((a=='.'||a==c)&&old);
                }
                else dp[j]=diag&&(x=='.'||x==c);
                diag=old;
            }
        }
        return dp[n];
    }
}
```

**Complexity:** O(mn) time, O(n) space.

### 42. LeetCode 139

**Problem**

Determine whether a string can be segmented into one or more dictionary words. Words may be reused.

**Examples**

- leetcode, [leet,code] → true
- catsandog, [cats,dog,sand,and,cat] → false

**Constraints**

1 ≤ text length ≤ 300; 1 ≤ dictionary size ≤ 1000; word length 1–20; lowercase, unique words

**Why this approach / key logic**

A reachable prefix ending at i can extend by any matching dictionary word. Bound tested suffix lengths by longest dictionary word. Java substring copies characters.

**Locked strategy:** Boolean prefix dp; dictionary HashSet and bounded word lengths for optimization.

**Evolution from previous solution:** BASE: test possible final word and earlier segmentable prefix.

**Java 21 solution**

```java
import java.util.*;

class Solution {
    public boolean wordBreak(String s,List<String> wordDict) {
        Set<String> set=new HashSet<>(wordDict);
        int L=0;
        for(String w:set)L=Math.max(L,w.length());
        boolean[] dp=new boolean[s.length()+1];
        dp[0]=true;
        for(int i=1;i<=s.length();i++)for(int j=Math.max(0,i-L);j<i;j++)if(dp[j]&&set.contains(s.substring(j,i))) {
            dp[i]=true;
            break;
        }
        return dp[s.length()];
    }
}
```

**Complexity:** O(nL²+D) time, O(n+D) space, L=max word length, D=total dictionary characters.

### 43. LeetCode 140

**Problem**

Return all sentences formed by inserting spaces into text so that every segment belongs to the dictionary; words can be reused.

**Examples**

- catsanddog, [cat,cats,and,sand,dog] → [cats and dog,cat sand dog]
- catsandog, [cats,dog,sand,and,cat] → []

**Constraints**

1 ≤ text length ≤ 20; dictionary size 1–1000; word length 1–10; lowercase unique words; output bounded by judge

**Why this approach / key logic**

Compute suffix feasibility first. DFS from each feasible start returns memoized sentences; concatenate each matching word with all feasible suffix sentences. Empty suffix is one valid completion.

**Locked strategy:** Memoized DFS per start index returning full sentences, with boolean feasibility pruning; output-sensitive exponential worst-case.

**Evolution from previous solution:** Replace boolean existence with cached lists of complete suffix sentences; preserve dictionary prefix checks.

**Java 21 solution**

```java
import java.util.*;

class Solution {
    public List<String> wordBreak(String s,List<String> wordDict) {
        Set<String> set=new HashSet<>(wordDict);
        int L=0,n=s.length();
        for(String w:set)L=Math.max(L,w.length());
        boolean[] ok=new boolean[n+1];
        ok[n]=true;
        for(int i=n-1;i>=0;i--)for(int j=i+1;j<=Math.min(n,i+L);j++)if(ok[j]&&set.contains(s.substring(i,j))) {
            ok[i]=true;
            break;
        }
        return dfs(s,0,L,set,ok,new HashMap<>());
    }
    private List<String> dfs(String s,int i,int L,Set<String> set,boolean[] ok,Map<Integer,List<String>> memo) {
        if(i==s.length())return List.of("");
        if(!ok[i])return List.of();
        if(memo.containsKey(i))return memo.get(i);
        List<String> ans=new ArrayList<>();
        for(int j=i+1;j<=Math.min(s.length(),i+L);j++) {
            if(!ok[j])continue;
            String w=s.substring(i,j);
            if(set.contains(w))for(String tail:dfs(s,j,L,set,ok,memo))ans.add(tail.isEmpty()?w:w+" "+tail);
        }
        memo.put(i,ans);
        return ans;
    }
}
```

**Complexity:** O(nL²+D+C) time, O(n+D+C) space, C=total characters stored/generated across memoized sentences.

```java
                else r=mid;
            }
            long reward=(long)rides[i][1]-rides[i][0]+rides[i][2];
            dp[i]=Math.max(dp[i+1],reward+dp[l]);
        }
        return dp[0];
    }
}
```

**Complexity:** O(r log r) time, O(r) space, r=rides.length.

### 58. LeetCode 1751

**Problem**

Attend at most k events, each with inclusive start/end days and value. No overlapping attendance; maximize value.

**Examples**

- [[1,2,4],[3,4,3],[2,3,1]], k=2 → 7
- [[1,2,4],[3,4,3],[2,3,10]], k=2 → 10

**Constraints**

1 ≤ k ≤ n; 1 ≤ n×k ≤ 10^6; 1 ≤ start ≤ end ≤ 10^9; 1 ≤ value ≤ 10^6

**Why this approach / key logic**

Precompute next event with start strictly greater than current end. Roll selection-budget layers; take consumes one budget, skip keeps current budget.

**Locked strategy:** Sort events and precompute next strictly later start; DP by event index and remaining k selections.

**Evolution from previous solution:** Add selection-budget dimension; change nonoverlap condition from >= end to > end (inclusive dates).

**Java 21 solution**

```java
import java.util.*;

class Solution {
    public int maxValue(int[][] events,int k) {
        Arrays.sort(events,Comparator.comparingInt(a->a[0]));
        int n=events.length;
        int[] next=new int[n];
        for(int i=0;i<n;i++) {
            int l=i+1,r=n;
            while(l<r) {
                int m=(l+r)/2;
                if(events[m][0]<=events[i][1])l=m+1;
                else r=m;
            }
            next[i]=l;
        }
        int[] dp=new int[n+1];
        for(int c=1;c<=k;c++) {
            int[] cur=new int[n+1];
            for(int i=n-1;i>=0;i--)cur[i]=Math.max(cur[i+1],events[i][2]+dp[next[i]]);
            dp=cur;
        }
        return dp[0];
    }
}
```

**Complexity:** O(n log n+nk) time, O(n) space.

### 59. LeetCode 1031

**Problem**

Find maximum combined sum of two nonoverlapping contiguous subarrays of lengths firstLen and secondLen, in either order.

**Examples**

- [0,6,5,2,2,5,1,9,4], lengths 1,2 → 20
- [3,8,1,3,2,1,8,9,0], lengths 3,2 → 29

**Constraints**

2 ≤ n ≤ 1000; 0 ≤ nums[i] ≤ 1000; positive lengths whose sum ≤ n

**Why this approach / key logic**

Use prefix sums. For each second-window end, update best first window ending before it starts. Run both length orders.

**Locked strategy:** Prefix sums plus best prefix window of one length; scan opposite ordering of lengths.

**Evolution from previous solution:** BASE: combine one chosen window with best nonoverlapping candidate of other length.

**Java 21 solution**

```java
import java.util.*;

class Solution {
    public int maxSumTwoNoOverlap(int[] nums,int firstLen,int secondLen) {
        int[] p=new int[nums.length+1];
        for(int i=0;i<nums.length;i++)p[i+1]=p[i]+nums[i];
        return Math.max(scan(p,firstLen,secondLen),scan(p,secondLen,firstLen));
    }
    private int scan(int[] p,int a,int b) {
        int best=0,ans=0;
        for(int end=a+b;end<p.length;end++) {
            int split=end-b;
            best=Math.max(best,p[split]-p[split-a]);
            ans=Math.max(ans,best+p[end]-p[split]);
        }
        return ans;
    }
}
```

**Complexity:** O(n) time, O(n) space.

### 60. LeetCode 689

**Problem**

Choose three disjoint contiguous subarrays of length k maximizing total sum. Return their zero-based start indices in ascending order; break ties by lexicographically smallest triple.

**Examples**

- [1,2,1,2,6,7,5,1], k=2 → [0,3,5]
- [1,2,1,2,1,2,1,2,1], k=2 → [0,2,4]

**Constraints**

1 ≤ n ≤ 20000; 1 ≤ nums[i] < 2^16; 1 ≤ k ≤ floor(n/3)

**Why this approach / key logic**

Precompute window sums and best window indices on each side. Left scan keeps earliest tie using strict >; right scan uses >= while moving backward. Scan middle ascending and update only for strictly better total.

**Locked strategy:** Precompute k-window sums and best left/right window indices, combine middle; enforce lexicographic tie order.

**Evolution from previous solution:** Generalize two-window combination to three ordered windows, add index reconstruction and tie policy.

**Java 21 solution**

```java
import java.util.*;

class Solution {
    public int[] maxSumOfThreeSubarrays(int[] nums,int k) {
        int m=nums.length-k+1;
        int[] w=new int[m],left=new int[m],right=new int[m];
        int sum=0;
        for(int i=0;i<nums.length;i++) {
            sum+=nums[i];
            if(i>=k)sum-=nums[i-k];
            if(i>=k-1)w[i-k+1]=sum;
        }
        for(int i=1;i<m;i++)left[i]=w[i]>w[left[i-1]]?i:left[i-1];
        right[m-1]=m-1;
        for(int i=m-2;i>=0;i--)right[i]=w[i]>=w[right[i+1]]?i:right[i+1];
        int best=-1;
        int[] ans=new int[3];
        for(int j=k;j+k<m;j++) {
            int i=left[j-k],r=right[j+k],total=w[i]+w[j]+w[r];
            if(total>best) {
                best=total;
                ans=new int[] {
                    i,j,r
                }
                ;
            }
        }
        return ans;
    }
}
```

**Complexity:** O(n) time, O(n) space.
