# 🌳 Pattern 4 — BFS / Level Order Variations

---

## 1. Core Idea

> **BFS on Trees = Process nodes level by level using a Queue.**
> Every BFS variation is just the same Queue skeleton with a small twist inside the loop.
> Master the base template, then learn what changes per variant.

```
The BFS Contract:
┌─────────────────────────────────────────────────────┐
│  1. Push root into Queue                            │
│  2. While queue not empty:                          │
│     a. Snapshot level size = queue.size()           │
│     b. Process exactly 'size' nodes (one level)     │
│     c. Push their children for next level           │
│  3. Do something with each level's data             │
└─────────────────────────────────────────────────────┘

KEY INSIGHT: int size = queue.size() taken BEFORE
the inner loop is what separates one level from the next.
Without this → you lose level boundary information.
```

---

## 🧠 How to Recognize These Problems

| Clue in Problem | BFS Variant |
|---|---|
| "level by level", "level order" | Standard BFS |
| "right side view", "left side view" | First or last node per level |
| "zigzag", "spiral order" | Alternate direction per level |
| "bottom-up level order" | BFS + reverse result |
| "average of each level" | Sum / count per level |
| "largest value in each row" | Max per level |
| "connect next right pointers" | BFS linking nodes in same level |
| "minimum depth" | BFS — stop at first leaf found |
| "cousins in binary tree" | Track depth + parent per node |
| "vertical order" | BFS + column tracking |

## 📌 Variant 1 — Standard Level Order

```
Process each level, collect into sublists

Queue start: [1]

Level 0: poll(1)        → [1]         add 2,3
Level 1: poll(2),poll(3)→ [2,3]       add 4,5,6,7
Level 2: poll(4..7)     → [4,5,6,7]   add 8
Level 3: poll(8)        → [8]

Result: [[1],[2,3],[4,5,6,7],[8]]
```

---

## 📌 Variant 2 — Right Side View

```
Idea: Last node polled at each level = visible from right

Level 0: nodes=[1]       → last = 1
Level 1: nodes=[2,3]     → last = 3
Level 2: nodes=[4,5,6,7] → last = 7
Level 3: nodes=[8]       → last = 8

Right view = [1, 3, 7, 8]

Trick: inside inner loop, check if i == size-1
       that's your rightmost node
```

---

## 📌 Variant 3 — Zigzag Level Order

```
Alternate: Left→Right, then Right→Left each level

Level 0 (L→R): [1]         addLast(1)
Level 1 (R→L): [2,3]       addFirst(2), addFirst(3) → [3,2]
Level 2 (L→R): [4,5,6,7]   addLast each → [4,5,6,7]
Level 3 (R→L): [8]         addFirst(8) → [8]

Result: [[1],[3,2],[4,5,6,7],[8]]

Use LinkedList for O(1) addFirst and addLast
```

## 📌 Variant 4 — Level Averages / Maximum per Level

```
While processing each level → track sum or max

Level 0: sum=1,  count=1 → avg=1.0,  max=1
Level 1: sum=5,  count=2 → avg=2.5,  max=3
Level 2: sum=22, count=4 → avg=5.5,  max=7
Level 3: sum=8,  count=1 → avg=8.0,  max=8

Averages: [1.0, 2.5, 5.5, 8.0]
Maximums: [1, 3, 7, 8]

Same loop — just accumulate differently inside
```

## 📌 Variant 5 — Minimum Depth

```
Key insight: BFS naturally finds shortest path first
Stop the moment you hit the FIRST LEAF node

        1
       / \
      2   3
     /
    4

DFS would explore all paths.
BFS stops immediately at first leaf!

Level 0: poll(1) → not leaf (has children)
Level 1: poll(2) → not leaf, poll(3) → LEAF! 
         → return depth=2 immediately ✅

DFS would wrongly return 3 (via 1→2→4) as minimum
if you don't handle the single-child case carefully.
BFS handles this naturally.
```

## 📌 Variant 6 — Connect Next Right Pointers

```
Populate next pointers to link nodes on same level

Before:             After:
    1                   1 → null
   / \                 / \
  2   3               2 → 3 → null
 / \ / \             / \ / \
4  5 6  7           4→5→6→7 → null

BFS approach: within each level's inner loop,
link node[i] to node[i+1]

Inner loop trick:
  TreeNode prev = null
  for each node in level:
    if prev != null: prev.next = node
    prev = node
  prev.next = null  (end of level)
```

---

## 📌 Variant 7 — Vertical Order Traversal (BFS style)

```
Assign column index: root=0, left=-1, right=+1

        1(col=0)
       /        \
    2(col=-1)   3(col=1)
   /    \
4(col=-2) 5(col=0)

Use TreeMap<col, List<val>> to group by column
BFS with [node, col] pairs in queue

col -2: [4]
col -1: [2]
col  0: [1, 5]
col  1: [3]

Result: [[4],[2],[1,5],[3]]
```

---

## 📌 Variant 8 — Cousins Check (Same Level, Different Parent)

```
Nodes are cousins if:
  - same depth
  - different parents

For nodes x and y:
Track (node, parent, depth) in BFS queue

        1
       / \
      2   3
     / \   \
    4   5   6

Are 4 and 6 cousins?
  4: depth=2, parent=2
  6: depth=2, parent=3
  Same depth ✅, different parent ✅ → YES, cousins ✅

Are 4 and 5 cousins?
  4: depth=2, parent=2
  5: depth=2, parent=2
  Same parent ❌ → NOT cousins
```

## 🏆 Golden Template in Java

```java
// ════════════════════════════════════════════════
// BASE TEMPLATE — All BFS variations extend this
// ════════════════════════════════════════════════
List<List<Integer>> bfs(TreeNode root) {
    List<List<Integer>> result = new ArrayList<>();
    if (root == null) return result;

    Queue<TreeNode> queue = new LinkedList<>();
    queue.offer(root);

    while (!queue.isEmpty()) {
        int size = queue.size();              // ← LEVEL BOUNDARY KEY
        List<Integer> level = new ArrayList<>();

        for (int i = 0; i < size; i++) {
            TreeNode node = queue.poll();

            // ↓↓ THIS IS WHERE EACH VARIANT DIFFERS ↓↓
            level.add(node.val);              // standard: just add

            if (node.left  != null) queue.offer(node.left);
            if (node.right != null) queue.offer(node.right);
        }

        result.add(level);                    // standard: add level
    }
    return result;
}

// ════════════════════════════════════════════════
// VARIANT: RIGHT SIDE VIEW
// ════════════════════════════════════════════════
// Change: only add node when i == size - 1
if (i == size - 1) result.add(node.val);

// ════════════════════════════════════════════════
// VARIANT: ZIGZAG
// ════════════════════════════════════════════════
// Change: use LinkedList level + alternate addFirst/addLast
LinkedList<Integer> level = new LinkedList<>();
if (leftToRight) level.addLast(node.val);
else             level.addFirst(node.val);
leftToRight = !leftToRight; // flip after each level

// ════════════════════════════════════════════════
// VARIANT: BOTTOM-UP LEVEL ORDER
// ════════════════════════════════════════════════
// Change: use LinkedList result + addFirst each level
LinkedList<List<Integer>> result = new LinkedList<>();
result.addFirst(level); // instead of result.add(level)

// ════════════════════════════════════════════════
// VARIANT: LEVEL AVERAGE
// ════════════════════════════════════════════════
// Change: accumulate sum, divide by size after inner loop
double sum = 0;
sum += node.val;          // inside loop
result.add(sum / size);   // after inner loop

// ════════════════════════════════════════════════
// VARIANT: MINIMUM DEPTH
// ════════════════════════════════════════════════
// Change: return depth when first leaf is found
int depth = 0;
depth++;                  // before inner loop
if (node.left == null && node.right == null) return depth;

// ════════════════════════════════════════════════
// VARIANT: CONNECT NEXT POINTERS
// ════════════════════════════════════════════════
// Change: link nodes within same level
Node prev = null;
if (prev != null) prev.next = node;
prev = node;
// after inner loop: prev.next = null (already null by default)
```

## 📋 Key Rules to Remember

| Rule | Why It Matters |
|---|---|
| **`int size = queue.size()` before inner loop** | This is the ONLY way to separate levels in BFS |
| **Queue = FIFO** | Children added in left→right order come out left→right |
| **LinkedList for addFirst** | O(1) front insertion for zigzag and bottom-up |
| **BFS finds shortest path first** | Use for minimum depth — stop at first leaf |
| **Push children only if non-null** | Prevents NullPointerException in inner loop |
| **Track (node + metadata) in queue** | For vertical order, cousins — pair node with col/parent/depth |
| **Right view = last node per level** | `i == size - 1` inside inner loop |
| **Left view = first node per level** | `i == 0` inside inner loop |
| **Zigzag = flip direction flag per level** | After each level's inner loop completes |
| **BFS space = O(W)** | W = max width of tree — can be O(N) for complete trees |
