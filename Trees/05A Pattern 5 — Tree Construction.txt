# 🌳 Pattern 5 — Tree Construction (Build from Traversals)

---

## 1. Core Idea

> **Given traversal sequences → reconstruct the unique binary tree.**
> Every construction problem relies on one key insight:
> **Preorder/Postorder tells you the ROOT. Inorder tells you LEFT vs RIGHT split.**
> These two pieces of information together uniquely define any binary tree.

```
The Construction Contract:
┌─────────────────────────────────────────────────────────┐
│  PREORDER:  [ROOT | left subtree | right subtree]       │
│  INORDER:   [left subtree | ROOT | right subtree]       │
│  POSTORDER: [left subtree | right subtree | ROOT]       │
│                                                         │
│  KEY INSIGHT:                                           │
│  1. Find ROOT from preorder (first) or postorder (last) │
│  2. Find ROOT in inorder → splits left and right        │
│  3. Recurse on each half                                │
└─────────────────────────────────────────────────────────┘
```

### Why you need TWO traversals:
```
Inorder alone:    [4, 2, 5, 1, 3]  → Could be many trees
Preorder alone:   [1, 2, 4, 5, 3]  → Could be many trees

TOGETHER → Exactly ONE unique tree:

        1
       / \
      2   3
     / \
    4   5

Preorder first element (1) = ROOT
Find 1 in inorder → left=[4,2,5], right=[3]
Recurse on each side ✅
```

---

## 🧠 How to Recognize These Problems

| Clue in Problem | Pattern |
|---|---|
| "given inorder + preorder, build tree" | Classic construction |
| "given inorder + postorder, build tree" | Postorder variant |
| "given preorder + postorder, build tree" | Harder — not unique without inorder |
| "build BST from preorder" | BST property replaces inorder |
| "sorted array → balanced BST" | Binary search mid as root |
| "sorted linked list → balanced BST" | Slow-fast pointer to find mid |
| "build tree from string/level order" | Deserialization problems |
| "clone / copy a tree" | DFS construction |

## 📌 Variant 1 — Build from Preorder + Inorder

```
Preorder: [3, 9, 20, 15, 7]
           ↑
         ROOT = 3 (always first in preorder)

Find 3 in Inorder: [9, | 3 | 15, 20, 7]
                   LEFT=1  ROOT  RIGHT=3 elements

Left subtree:
  Preorder slice: [9]        → root=9, no children
  Inorder slice:  [9]

Right subtree:
  Preorder slice: [20, 15, 7] → root=20
  Inorder slice:  [15, 20, 7]
    Find 20 in [15, 20, 7] → left=[15], right=[7]
    → node(20).left=15, node(20).right=7

Final tree:
        3
       / \
      9  20
         / \
        15   7  ✅
```

---

## 📌 Variant 2 — Build from Postorder + Inorder

```
Postorder: [9, 15, 7, 20, 3]
                           ↑
                    ROOT = 3 (always LAST in postorder)

Find 3 in Inorder: [9 | 3 | 15, 20, 7]
                   LEFT=1  ROOT  RIGHT=3

Left subtree:
  Postorder slice: [9]         → root=9
  Inorder slice:   [9]

Right subtree:
  Postorder slice: [15, 7, 20] → root=20 (last element)
  Inorder slice:   [15, 20, 7]
    Find 20 → left=[15], right=[7]
    → node(20).left=15, node(20).right=7

Same tree reconstructed ✅
```

## 📌 Variant 3 — Sorted Array → Balanced BST

```
Sorted array: [-10, -3, 0, 5, 9]

Key insight: Take MIDDLE element as root
             → guarantees balanced tree

mid = index 2 → val = 0 (root)
Left half:  [-10, -3] → mid=1 → root=-3
  Left of -3: [-10]   → root=-10
Right half: [5, 9]    → mid=1 → root=9
  Left of 9: [5]      → root=5

Result:
        0
       / \
     -3   9
     /   /
   -10  5  ✅
```

---

## 📌 Variant 4 — Build BST from Preorder

```
Preorder: [8, 5, 1, 7, 10, 12]

Key insight: BST property replaces inorder!
No need for inorder array — use valid range [min, max]

Insert elements one by one respecting bounds:

8  → root (range: -∞ to +∞)
5  → 5 < 8 → left of 8 (range: -∞ to 8)
1  → 1 < 5 → left of 5 (range: -∞ to 5)
7  → 7 > 5, 7 < 8 → right of 5 (range: 5 to 8)
10 → 10 > 8 → right of 8 (range: 8 to +∞)
12 → 12 > 10 → right of 10

Result:
        8
       / \
      5  10
     / \   \
    1   7  12  ✅
```

---

## 📌 Variant 5 — Sorted Linked List → Balanced BST

```
List: 1 → 2 → 3 → 4 → 5

Key insight: Can't random access like array.
Use slow/fast pointers to find middle.

slow=1, fast=1
Move: slow=2, fast=3
Move: slow=3, fast=5  ← fast.next=null, stop

mid = slow = 3 → ROOT

Left list:  1 → 2       → recurse (mid=2, root=2, left=[1])
Right list: 4 → 5       → recurse (mid=4, root=4, right=[5])

Result:
        3
       / \
      2   4
     /     \
    1       5  ✅
```

---

## 📌 Variant 6 — Preorder + Postorder → Build Tree

```
Preorder:  [1, 2, 4, 5, 3, 6, 7]
Postorder: [4, 5, 2, 6, 7, 3, 1]

ROOT = preorder[0] = 1
Left child root = preorder[1] = 2
Find 2 in postorder → index 2
Everything in postorder[0..2] = left subtree [4,5,2] (size=3)

Left preorder:  [2, 4, 5]
Left postorder: [4, 5, 2]

Right preorder:  [3, 6, 7]
Right postorder: [6, 7, 3]

Result:
        1
       / \
      2   3
     / \ / \
    4  5 6  7  ✅

⚠️ NOTE: Without inorder, result may NOT be unique
   (single-child nodes are ambiguous — could be left or right)
```

## 🏆 Golden Templates in Java

### ✅ Template 1 — Preorder + Inorder
```java
class Solution {
    int preIdx = 0;
    Map<Integer, Integer> inorderMap = new HashMap<>();

    public TreeNode buildTree(int[] preorder, int[] inorder) {
        // KEY OPTIMIZATION: HashMap for O(1) inorder index lookup
        for (int i = 0; i < inorder.length; i++)
            inorderMap.put(inorder[i], i);

        return build(preorder, 0, inorder.length - 1);
    }

    private TreeNode build(int[] preorder, int left, int right) {
        if (left > right) return null;             // Base case: no elements

        int rootVal = preorder[preIdx++];           // Next preorder = current root
        TreeNode root = new TreeNode(rootVal);

        int mid = inorderMap.get(rootVal);         // Split point in inorder

        // IMPORTANT: build LEFT before RIGHT (preorder consumes left→right)
        root.left  = build(preorder, left, mid - 1);
        root.right = build(preorder, mid + 1, right);

        return root;
    }
}
```

---

### ✅ Template 2 — Postorder + Inorder
```java
class Solution {
    int postIdx;
    Map<Integer, Integer> inorderMap = new HashMap<>();

    public TreeNode buildTree(int[] inorder, int[] postorder) {
        postIdx = postorder.length - 1;            // Start from end of postorder
        for (int i = 0; i < inorder.length; i++)
            inorderMap.put(inorder[i], i);

        return build(postorder, 0, inorder.length - 1);
    }

    private TreeNode build(int[] postorder, int left, int right) {
        if (left > right) return null;

        int rootVal = postorder[postIdx--];        // Next postorder (from end) = root
        TreeNode root = new TreeNode(rootVal);

        int mid = inorderMap.get(rootVal);

        // IMPORTANT: build RIGHT before LEFT (postorder reads right→left from end)
        root.right = build(postorder, mid + 1, right);
        root.left  = build(postorder, left, mid - 1);

        return root;
    }
}
```

### ✅ Template 3 — Sorted Array → Balanced BST
```java
class Solution {
    public TreeNode sortedArrayToBST(int[] nums) {
        return build(nums, 0, nums.length - 1);
    }

    private TreeNode build(int[] nums, int left, int right) {
        if (left > right) return null;

        int mid = left + (right - left) / 2;       // Middle = root (balanced!)
        TreeNode root = new TreeNode(nums[mid]);

        root.left  = build(nums, left, mid - 1);
        root.right = build(nums, mid + 1, right);

        return root;
    }
}
```

### ✅ Template 4 — Build BST from Preorder (bounds trick)
```java
class Solution {
    int idx = 0;

    public TreeNode bstFromPreorder(int[] preorder) {
        return build(preorder, Integer.MIN_VALUE, Integer.MAX_VALUE);
    }

    private TreeNode build(int[] preorder, int min, int max) {
        if (idx == preorder.length) return null;
        int val = preorder[idx];

        // Current value out of valid range → doesn't belong in this subtree
        if (val < min || val > max) return null;

        idx++;
        TreeNode root = new TreeNode(val);
        root.left  = build(preorder, min, val);    // Left: must be < val
        root.right = build(preorder, val, max);    // Right: must be > val
        return root;
    }
}
```

### ✅ Template 5 — Sorted Linked List → Balanced BST
```java
class Solution {
    public TreeNode sortedListToBST(ListNode head) {
        if (head == null) return null;
        if (head.next == null) return new TreeNode(head.val);

        // Find middle using slow/fast pointers
        ListNode prev = null, slow = head, fast = head;
        while (fast != null && fast.next != null) {
            prev = slow;
            slow = slow.next;
            fast = fast.next.next;
        }

        // Cut list at middle
        if (prev != null) prev.next = null;        // Left list ends before mid

        TreeNode root = new TreeNode(slow.val);    // Mid = root
        root.left  = sortedListToBST(head);        // Left half (head to prev)
        root.right = sortedListToBST(slow.next);   // Right half (after mid)

        return root;
    }
}
```

## 📋 Key Rules to Remember

| Rule | Why It Matters |
|---|---|
| **Preorder first = root** | Always consume preorder from left to right |
| **Postorder last = root** | Always consume postorder from right to left |
| **Inorder split = left/right boundary** | Index of root in inorder divides subtrees |
| **Build LEFT before RIGHT in preorder** | preIdx must advance left subtree first |
| **Build RIGHT before LEFT in postorder** | postIdx (from end) must process right first |
| **HashMap inorder index = O(1) lookup** | Without it, search is O(N) per node = O(N²) total |
| **Mid = left+(right-left)/2** | Avoids overflow vs (left+right)/2 |
| **BST construction needs only preorder** | BST property replaces inorder entirely |
| **Slow/fast pointer finds linked list mid** | Can't random-access list like array |
| **Preorder+Postorder not always unique** | Single-child subtrees are ambiguous |
