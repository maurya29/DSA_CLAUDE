# 🟢 LC 112 — Path Sum

## Intuition
Subtract current node's value from target as we go down. At a leaf node, check if remaining equals zero. If any path reaches a leaf with remaining==0, return true. Short-circuit as soon as one valid path is found.

### Tree used:
```
            5
           / \
          4   8
         /   / \
        11  13   4
       /  \       \
      7    2       1

target = 22
Path 5→4→11→2 = 22 ✅
```

---

### ✅ Recursive Solution
```java
class Solution {
    public boolean hasPathSum(TreeNode root, int targetSum) {
        if (root == null) return false;

        targetSum -= root.val;                    // Subtract current node

        // At leaf: check if target is exactly met
        if (root.left == null && root.right == null)
            return targetSum == 0;

        // Check either subtree
        return hasPathSum(root.left,  targetSum) ||
               hasPathSum(root.right, targetSum);
    }
}
```

### 🔍 Recursive Dry Run (target=22)
```
hasPathSum(5, 22)  → remaining=17
  hasPathSum(4, 17) → remaining=13
    hasPathSum(11, 13) → remaining=2
      hasPathSum(7, 2) → remaining=-5
        leaf, -5≠0 → false
      hasPathSum(2, 2) → remaining=0
        leaf, 0==0 → TRUE ✅ (short-circuit, stop here)
```

---

### ✅ Iterative Solution (Stack — DFS)
```java
class Solution {
    public boolean hasPathSum(TreeNode root, int targetSum) {
        if (root == null) return false;

        // Stack stores [node, remainingSum]
        Stack<TreeNode> nodeStack = new Stack<>();
        Stack<Integer>  sumStack  = new Stack<>();
        nodeStack.push(root);
        sumStack.push(targetSum - root.val);

        while (!nodeStack.isEmpty()) {
            TreeNode node = nodeStack.pop();
            int remaining = sumStack.pop();

            // Leaf check
            if (node.left == null && node.right == null && remaining == 0)
                return true;

            if (node.right != null) {
                nodeStack.push(node.right);
                sumStack.push(remaining - node.right.val);
            }
            if (node.left != null) {
                nodeStack.push(node.left);
                sumStack.push(remaining - node.left.val);
            }
        }
        return false;
    }
}
```

```

  nodeStack:[8,4]  sumStack:[9,13]

Pop(4,13): not leaf, push left(11,13-11=2)
  nodeStack:[8,11]  sumStack:[9,2]

Pop(11,2): not leaf, push right(2,2-2=0), left(7,2-7=-5)
  nodeStack:[8,2,7]  sumStack:[9,0,-5]

Pop(7,-5): leaf, -5≠0 → skip
Pop(2, 0): leaf,  0==0 → return TRUE ✅
```

### ⚡ When to prefer which?
| | Recursive | Iterative |
|---|---|---|
| Simplicity | ✅ 5 lines | More verbose |
| Short-circuit | Both stop at first valid path | Both stop early |
| Stack overflow | On very deep trees | ✅ Safe |

# 🟢 LC 257 — Binary Tree Paths

## Intuition
DFS from root carrying the current path string. At each leaf, add the completed path to result. For non-leaf nodes, append `"->"` and the child's value before recursing. No explicit backtracking needed when building strings (immutable strings in Java create new objects).

### Tree used:
```
        1
       / \
      2   3
       \
        5

Expected: ["1->2->5", "1->3"]
```

---

### ✅ Recursive Solution
```java
class Solution {
    public List<String> binaryTreePaths(TreeNode root) {
        List<String> result = new ArrayList<>();
        dfs(root, "", result);
        return result;
    }

    private void dfs(TreeNode node, String path, List<String> result) {
        if (node == null) return;

        path += node.val;                              // Append current node

        if (node.left == null && node.right == null) {
            result.add(path);                          // Leaf: add complete path
            return;
        }

        path += "->";                                  // Append arrow for non-leaf

        dfs(node.left,  path, result);                 // Explore left
        dfs(node.right, path, result);                 // Explore right
        // No backtrack needed — String is immutable in Java ✅
    }
}
```

### 🔍 Recursive Dry Run
```

  path = "1"
  not leaf → path = "1->"
  dfs(2, "1->")
    path = "1->2"
    not leaf → path = "1->2->"
    dfs(null, ...) → return
    dfs(5, "1->2->")
      path = "1->2->5"
      LEAF → add "1->2->5" ✅
  dfs(3, "1->")
    path = "1->3"
    LEAF → add "1->3" ✅

Result: ["1->2->5", "1->3"] ✅
```

---

### ✅ Iterative Solution (Stack with path tracking)
```java
class Solution {
    public List<String> binaryTreePaths(TreeNode root) {
        List<String> result = new ArrayList<>();
        if (root == null) return result;

        Stack<TreeNode> nodeStack = new Stack<>();
        Stack<String>   pathStack = new Stack<>();
        nodeStack.push(root);
        pathStack.push(String.valueOf(root.val));

        while (!nodeStack.isEmpty()) {
            TreeNode node = nodeStack.pop();
            String   path = pathStack.pop();

            // Leaf: save completed path
            if (node.left == null && node.right == null) {
                result.add(path);
            }

            // Push children with extended path
            if (node.right != null) {
                nodeStack.push(node.right);
                pathStack.push(path + "->" + node.right.val);
            }
            if (node.left != null) {
                nodeStack.push(node.left);
                pathStack.push(path + "->" + node.left.val);
            }
        }
        return result;
    }
}
```

### ✅ Recursive Solution with StringBuilder (More Efficient)
```java
class Solution {
    public List<String> binaryTreePaths(TreeNode root) {
        List<String> result = new ArrayList<>();
        dfs(root, new StringBuilder(), result);
        return result;
    }

    private void dfs(TreeNode node, StringBuilder sb, List<String> result) {
        if (node == null) return;

        int len = sb.length();                    // Save length for backtracking
        sb.append(node.val);

        if (node.left == null && node.right == null) {
            result.add(sb.toString());
        } else {
            sb.append("->");
            dfs(node.left,  sb, result);
            dfs(node.right, sb, result);
        }

        sb.setLength(len);                        // BACKTRACK to saved length
    }
}
```

# 🟢 LC 1022 — Sum of Root to Leaf Binary Numbers

## Intuition
Each root-to-leaf path represents a binary number. Build the number top-down: at each node, shift current number left by 1 (multiply by 2) and add current node's value (0 or 1). At leaf, add completed binary number to total sum.

### Tree used:
```
        1
       / \
      0   1
     / \   \
    0   1   1

Paths:
1→0→0 = 100₂ = 4
1→0→1 = 101₂ = 5
1→1→1 = 111₂ = 7
Sum = 4+5+7 = 22 ✅
```

---

### ✅ Recursive Solution
```java
class Solution {
    public int sumRootToLeaf(TreeNode root) {
        return dfs(root, 0);
    }

    private int dfs(TreeNode node, int currentNum) {
        if (node == null) return 0;

        // Shift left by 1 bit and add current node value (0 or 1)
        currentNum = (currentNum << 1) | node.val;

        // At leaf: return the complete binary number
        if (node.left == null && node.right == null)
            return currentNum;

        // Sum from both subtrees
        return dfs(node.left,  currentNum) +
               dfs(node.right, currentNum);
    }
}
```

      LEAF → return 4
    dfs(1, 2)

# 🟡 LC 113 — Path Sum II (All Paths)

## Intuition
DFS with explicit backtracking. Add node to path list before recursing, remove it after. When we reach a leaf with remaining sum == 0, make a copy of current path and add to result. The copy is critical — the path list is mutated during backtracking.

### Tree used:
```
            5
           / \
          4   8
         /   / \
        11  13   4
       /  \     / \
      7    2   5   1

target=22
Expected: [[5,4,11,2], [5,8,4,5]]
```

---

### ✅ Recursive Solution (Backtracking)
```java
class Solution {
    public List<List<Integer>> pathSum(TreeNode root, int targetSum) {
        List<List<Integer>> result = new ArrayList<>();
        dfs(root, targetSum, new ArrayList<>(), result);
        return result;
    }

    private void dfs(TreeNode node, int remaining,
                     List<Integer> path, List<List<Integer>> result) {
        if (node == null) return;

        path.add(node.val);                            // CHOOSE: add to path
        remaining -= node.val;

        // At leaf with target met → save copy of path
        if (node.left == null && node.right == null && remaining == 0) {
            result.add(new ArrayList<>(path));         // Copy! not reference
        } else {
            dfs(node.left,  remaining, path, result);  // Explore left
            dfs(node.right, remaining, path, result);  // Explore right
        }

        path.remove(path.size() - 1);                 // UNCHOOSE: backtrack
    }
}
```

### ✅ Iterative Solution (Stack with path snapshot)
```java
class Solution {
    public List<List<Integer>> pathSum(TreeNode root, int targetSum) {
        List<List<Integer>> result = new ArrayList<>();
        if (root == null) return result;

        // Stack stores [node, remainingSum, pathSoFar]
        Stack<TreeNode>       nodeStack = new Stack<>();
        Stack<Integer>        sumStack  = new Stack<>();
        Stack<List<Integer>>  pathStack = new Stack<>();

        nodeStack.push(root);
        sumStack.push(targetSum - root.val);
        pathStack.push(new ArrayList<>(Arrays.asList(root.val)));

        while (!nodeStack.isEmpty()) {
            TreeNode      node      = nodeStack.pop();
            int           remaining = sumStack.pop();
            List<Integer> path      = pathStack.pop();

            // Leaf with target met
            if (node.left == null && node.right == null && remaining == 0) {
                result.add(path);
            }

            // Push children with extended path (create new list each time)
            if (node.right != null) {
                List<Integer> rightPath = new ArrayList<>(path);
                rightPath.add(node.right.val);
                nodeStack.push(node.right);
                sumStack.push(remaining - node.right.val);
                pathStack.push(rightPath);
            }
            if (node.left != null) {
                List<Integer> leftPath = new ArrayList<>(path);
                leftPath.add(node.left.val);
                nodeStack.push(node.left);
                sumStack.push(remaining - node.left.val);
                pathStack.push(leftPath);
            }
        }
        return result;
    }
}
```

# 🟡 LC 129 — Sum Root to Leaf Numbers

## Intuition
Each root-to-leaf path represents a multi-digit decimal number. Build it top-down: `currentNum = parentNum * 10 + node.val`. At each leaf, return the completed number. Sum up all leaf numbers as we unwind recursion.

### Tree used:
```
        1
       / \
      2   3

Paths: 1→2=12, 1→3=13
Sum = 12+13 = 25 ✅
```

---

### ✅ Recursive Solution
```java
class Solution {
    public int sumNumbers(TreeNode root) {
        return dfs(root, 0);
    }

    private int dfs(TreeNode node, int currentNum) {
        if (node == null) return 0;

        currentNum = currentNum * 10 + node.val;       // Build number digit by digit

        // At leaf: return completed number
        if (node.left == null && node.right == null)
            return currentNum;

        // Sum from both subtrees
        return dfs(node.left,  currentNum) +
               dfs(node.right, currentNum);
    }
}
```

# 🟡 LC 1457 — Pseudo-Palindromic Paths in a Binary Tree

## Intuition
A path is pseudo-palindromic if we can rearrange its digits to form a palindrome — meaning at most ONE digit appears an odd number of times. Use XOR bitmask: toggle bit `i` when digit `i` is seen. At leaf, check if mask is 0 (all even) or a power of 2 (exactly one odd). Since mask is an int (passed by value in Java), no explicit backtracking needed.

### Tree used:
```
        2
       / \
      3   1
     / \   \
    3   1   1

Paths:
2→3→3: digits {2:odd,3:even} → mask=100₂ → power of 2 ✅
2→3→1: digits {2:odd,3:odd,1:odd} → mask=111₂ → NOT power of 2 ❌
2→1→1: digits {2:odd,1:even} → mask=100₂ → power of 2 ✅

Answer = 2
```

---

### ✅ Recursive Solution
```java
class Solution {
    int count = 0;

    public int pseudoPalindromicPaths(TreeNode root) {
        dfs(root, 0);
        return count;
    }

    private void dfs(TreeNode node, int mask) {
        if (node == null) return;

        mask ^= (1 << node.val);                      // Toggle bit for this digit

        if (node.left == null && node.right == null) {
            // Palindrome check: mask==0 (all even) OR exactly one bit set
            if (mask == 0 || (mask & (mask - 1)) == 0)
                count++;
            return;
        }

        dfs(node.left,  mask);                        // mask is int → no backtrack needed
        dfs(node.right, mask);
    }
}
```

### ✅ Iterative Solution (Stack with mask)
```java
class Solution {
    public int pseudoPalindromicPaths(TreeNode root) {
        if (root == null) return 0;

        int count = 0;
        Stack<TreeNode> nodeStack = new Stack<>();
        Stack<Integer>  maskStack = new Stack<>();
        nodeStack.push(root);
        maskStack.push(1 << root.val);                 // Initial mask for root

        while (!nodeStack.isEmpty()) {
            TreeNode node = nodeStack.pop();
            int      mask = maskStack.pop();

            if (node.left == null && node.right == null) {
                // Check pseudo-palindrome condition
                if (mask == 0 || (mask & (mask - 1)) == 0)
                    count++;
            }

            if (node.right != null) {
                nodeStack.push(node.right);
                maskStack.push(mask ^ (1 << node.right.val)); // Toggle right child's bit
            }
            if (node.left != null) {
                nodeStack.push(node.left);
                maskStack.push(mask ^ (1 << node.left.val));  // Toggle left child's bit
            }
        }
        return count;
    }
}
```

# 🔴 LC 2385 — Amount of Time for Binary Tree to Be Infected

## Intuition
Two-phase approach. Phase 1: Convert tree to undirected graph (adjacency list) using BFS/DFS — this lets infection spread upward through parent links. Phase 2: BFS from the infected node through the graph — the number of BFS levels to infect all nodes is the answer (time = levels - 1).

### Tree used:
```
        1
       / \
      5   3
       \   \
        4   10
       / \
      9   2

start=3, infect from node 3

Graph (undirected):
1: [5, 3]
5: [1, 4]
3: [1, 10]
4: [5, 9, 2]
10: [3]
9: [4]
2: [4]

BFS from 3:
  Level 0: [3]         time=0
  Level 1: [1, 10]     time=1
  Level 2: [5]         time=2
  Level 3: [4]         time=3
  Level 4: [9, 2]      time=4

Answer = 4 ✅
```

### ✅ Solution (Convert to Graph + BFS)
```java
class Solution {
    public int amountOfTime(TreeNode root, int start) {
        // Phase 1: Build undirected adjacency graph from tree
        Map<Integer, List<Integer>> graph = new HashMap<>();
        buildGraph(root, -1, graph);

        // Phase 2: BFS from start node
        Queue<Integer> queue = new LinkedList<>();
        Set<Integer>   visited = new HashSet<>();
        queue.offer(start);
        visited.add(start);
        int time = -1;                              // Start at -1, first level = 0

        while (!queue.isEmpty()) {
            int size = queue.size();
            time++;                                 // Each BFS level = 1 minute

            for (int i = 0; i < size; i++) {
                int node = queue.poll();
                for (int neighbor : graph.getOrDefault(node, new ArrayList<>())) {
                    if (!visited.contains(neighbor)) {
                        visited.add(neighbor);
                        queue.offer(neighbor);
                    }
                }
            }
        }
        return time;
    }

    private void buildGraph(TreeNode node, int parent,
                            Map<Integer, List<Integer>> graph) {
        if (node == null) return;

        graph.computeIfAbsent(node.val, k -> new ArrayList<>());

        if (parent != -1) {
            graph.get(node.val).add(parent);        // Child → Parent edge
            graph.get(parent).add(node.val);        // Parent → Child edge
        }

        buildGraph(node.left,  node.val, graph);
        buildGraph(node.right, node.val, graph);
    }
}
```

### ✅ Recursive Solution (Single DFS — more elegant)
```java
class Solution {
    int maxTime = 0;

    public int amountOfTime(TreeNode root, int start) {
        dfs(root, start);
        return maxTime;
    }

    // Returns distance from current subtree to start node
    // Positive = start is in THIS subtree, return depth of subtree
    // Negative = start is NOT here, return -(subtree height) to signal distance
    private int dfs(TreeNode node, int start) {
        if (node == null) return 0;

        int leftDist  = dfs(node.left,  start);
        int rightDist = dfs(node.right, start);

        if (node.val == start) {
            // Start found: max depth of subtrees = time to infect downward
            int subtreeDepth = Math.max(Math.abs(leftDist), Math.abs(rightDist));
            maxTime = Math.max(maxTime, subtreeDepth);
            return -1;                              // Signal "start is 1 level up from here"
        }

        if (leftDist < 0 || rightDist < 0) {
            // Start is somewhere in one of the subtrees
            int distToStart = Math.abs(Math.min(leftDist, rightDist)); // Distance to start
            int otherHeight = Math.max(leftDist, rightDist);           // Other subtree's height

            // Time = distance to start + height of other side
            maxTime = Math.max(maxTime, distToStart + otherHeight);

            return -(distToStart + 1);             // Propagate distance upward
        }

        // Start not in this subtree → return height
        return Math.max(leftDist, rightDist) + 1;
    }
}
```

## 💡 3 Golden Rules for Path Problems

> **Rule 1 (Root-to-Leaf):** Always check `left==null && right==null` explicitly for leaves — don't recurse into null children and check there. That gives wrong leaf detection for single-child nodes.
>
> **Rule 2 (Backtracking):** Add to path → recurse → remove from path. The copy (`new ArrayList<>(path)`) at the answer point is mandatory — without it you store a reference that gets mutated by future backtracking.
>
> **Rule 3 (Any-Path Tree DP):** `Math.max(childGain, 0)` is the key that enables ignoring negative subtrees. Update global answer using BOTH directions (`left + node + right`), but return to parent using only ONE direction (`node + max(left, right)`) — a path cannot branch at two different ancestors.
