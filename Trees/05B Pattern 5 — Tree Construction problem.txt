# 🟢 LC 108 — Convert Sorted Array to Binary Search Tree

## Intuition
Always pick the middle element as root — this guarantees equal distribution of nodes on both sides, creating a height-balanced BST. Recurse on left and right halves for subtrees.

### Array used:
```
nums = [-10, -3, 0, 5, 9]
         0    1  2  3  4

mid = 2 → val=0 → ROOT
Left:  [-10,-3] → mid=1 → -3 → left child=-10
Right: [5,9]    → mid=3 → 9  → left child=5
```

---

### ✅ Recursive Solution
```java
class Solution {
    public TreeNode sortedArrayToBST(int[] nums) {
        return build(nums, 0, nums.length - 1);
    }

    private TreeNode build(int[] nums, int left, int right) {
        if (left > right) return null;             // Base case: no elements

        int mid = left + (right - left) / 2;       // Middle index = root
        TreeNode root = new TreeNode(nums[mid]);

        root.left  = build(nums, left, mid - 1);   // Left half
        root.right = build(nums, mid + 1, right);  // Right half

        return root;
    }
}
```

### ✅ Iterative Solution (Stack-based)
```java
class Solution {
    public TreeNode sortedArrayToBST(int[] nums) {
        if (nums == null || nums.length == 0) return null;

        // Stack stores [node, leftBound, rightBound]
        Stack<int[]> boundsStack = new Stack<>();
        Stack<TreeNode> nodeStack = new Stack<>();

        int mid = 0 + (nums.length - 1) / 2;
        TreeNode root = new TreeNode(nums[mid]);

        boundsStack.push(new int[]{0, mid - 1, 0});     // left half, isLeft=1
        boundsStack.push(new int[]{mid + 1, nums.length - 1, 1}); // right half
        nodeStack.push(root);  // corresponds to left child pending
        nodeStack.push(root);  // corresponds to right child pending

        // Simpler iterative: use queue of tasks
        Queue<int[]> taskQueue = new LinkedList<>();
        // Each task: [nodeRef_via_index, left, right, isLeftChild]
        // Easier: just simulate with explicit stack

        // Restart with cleaner approach
        record Task(TreeNode parent, int left, int right, boolean isLeft) {}
        Deque<Task> stack = new ArrayDeque<>();

        int rootMid = (nums.length - 1) / 2;
        root = new TreeNode(nums[rootMid]);
        stack.push(new Task(root, 0, rootMid - 1, true));
        stack.push(new Task(root, rootMid + 1, nums.length - 1, false));

        while (!stack.isEmpty()) {
            Task task = stack.pop();
            if (task.left > task.right) continue;      // No elements

            int m = task.left + (task.right - task.left) / 2;
            TreeNode node = new TreeNode(nums[m]);

            if (task.isLeft) task.parent.left  = node;
            else             task.parent.right = node;

            stack.push(new Task(node, task.left,  m - 1, true));
            stack.push(new Task(node, m + 1, task.right, false));
        }
        return root;
    }
}
```

### ⚡ When to prefer which?
| | Recursive | Iterative |
|---|---|---|
| Code clarity | ✅ Much cleaner | Verbose |
| Interview | ✅ Write first | Only if asked |
| Risk | Stack overflow on huge array | ✅ Safe |

# 🟢 LC 617 — Merge Two Binary Trees

## Intuition
DFS simultaneously on both trees. If both nodes exist → create new node with sum. If only one exists → return that node (entire subtree is preserved). If both null → return null.

### Trees used:
```
Tree 1:          Tree 2:          Merged:
    1                2                3
   / \              / \              / \
  3   2            1   3            4   5
 /                  \   \          / \   \
5                    4   7        5   4   7
```

---

### ✅ Recursive Solution
```java
class Solution {
    public TreeNode mergeTrees(TreeNode root1, TreeNode root2) {
        // If either is null, return the other (preserve entire subtree)
        if (root1 == null) return root2;
        if (root2 == null) return root1;

        // Both exist: sum values, recurse on children
        root1.val += root2.val;                         // Merge into root1

        root1.left  = mergeTrees(root1.left,  root2.left);
        root1.right = mergeTrees(root1.right, root2.right);

        return root1;
    }
}
```

### 🔍 Recursive Dry Run
```

  both exist → root1.val = 1+2 = 3
  left:  mergeTrees(3, 1)
    both exist → root1.val = 3+1 = 4
    left:  mergeTrees(5, null) → return node(5)
    right: mergeTrees(null, 4) → return node(4)
    return node(4) [4.left=5, 4.right=4... ]
    
    Wait: node(3 becomes 4).left = node(5)
          node(3 becomes 4).right = node(4 from tree2)
    return node(4) with left=5, right=4
  right: mergeTrees(2, 3)
    both exist → root1.val = 2+3 = 5
    left:  mergeTrees(null, null) → null
    right: mergeTrees(null, 7)   → node(7)
    return node(5) with right=7
```

### ✅ Iterative Solution (Queue — BFS style)
```java
class Solution {
    public TreeNode mergeTrees(TreeNode root1, TreeNode root2) {
        if (root1 == null) return root2;
        if (root2 == null) return root1;

        Queue<TreeNode[]> queue = new LinkedList<>();
        queue.offer(new TreeNode[]{root1, root2});

        while (!queue.isEmpty()) {
            TreeNode[] pair = queue.poll();
            TreeNode n1 = pair[0], n2 = pair[1];

            // n1 is never null here (we only add valid pairs)
            n1.val += n2.val;                          // Merge values

            // Handle left children
            if (n1.left != null && n2.left != null) {
                queue.offer(new TreeNode[]{n1.left, n2.left}); // Both exist → queue
            } else if (n1.left == null) {
                n1.left = n2.left;                     // Take n2's left subtree
            }

            // Handle right children
            if (n1.right != null && n2.right != null) {
                queue.offer(new TreeNode[]{n1.right, n2.right});
            } else if (n1.right == null) {
                n1.right = n2.right;                   // Take n2's right subtree
            }
        }
        return root1;
    }
}
```

### 🔍 Iterative Dry Run
```

Poll (1,2): n1.val=3
  left:  n1.left=3, n2.left=1   → both exist → queue (3,1)
  right: n1.right=2, n2.right=3 → both exist → queue (2,3)
Queue: [(3,1),(2,3)]

Poll (3,1): n1.val=4
  left:  n1.left=5, n2.left=null  → n2.left null → skip
  right: n1.right=null, n2.right=4 → n1.right=null → n1.right=node(4)
Queue: [(2,3)]

  left:  both null → skip
  right: n1.right=null, n2.right=7 → n1.right=node(7)

Result:
    3
   / \
  4   5
 / \   \
5   4   7  ✅
```

# 🟢 LC 606 — Construct String from Binary Tree

## Intuition
Preorder DFS (root → left → right). Add parentheses around each subtree. Omit empty right subtree parentheses (unnecessary). Never omit empty left subtree when right exists — that would create ambiguity.

### Tree used:
```
        1
       / \
      2   3
     /
    4

Expected: "1(2(4))(3)"

Rules:
- root with no children: just "val"
- omit right "()" if right is null
- CANNOT omit left "()" if right exists (ambiguous)
```

---

### ✅ Recursive Solution
```java
class Solution {
    public String tree2str(TreeNode root) {
        if (root == null) return "";

        String result = String.valueOf(root.val);  // Start with root value

        // Add left subtree (always add if right exists too)
        if (root.left != null || root.right != null) {
            result += "(" + tree2str(root.left) + ")";
        }

        // Add right subtree (omit if null — no ambiguity without it)
        if (root.right != null) {
            result += "(" + tree2str(root.right) + ")";
        }

        return result;
    }
}
```

### 🔍 Recursive Dry Run
```

  result = "1"
  left(2)!=null → add left parens
  tree2str(2)
    result = "2"
    left(4)!=null, right=null → add left parens only
    tree2str(4)
      result = "4"
      left=null, right=null → skip both
      return "4"
    result = "2(4)"
    right=null → skip right parens
    return "2(4)"
  result = "1(2(4))"
  right(3)!=null → add right parens
  tree2str(3)
    result = "3"
    left=null, right=null → skip
    return "3"
  result = "1(2(4))(3)"
  return "1(2(4))(3)" ✅
```

### ✅ Iterative Solution (Stack + visited set)
```java
class Solution {
    public String tree2str(TreeNode root) {
        if (root == null) return "";

        StringBuilder sb = new StringBuilder();
        Stack<TreeNode> stack = new Stack<>();
        Set<TreeNode> visited = new HashSet<>();
        stack.push(root);

        while (!stack.isEmpty()) {
            TreeNode node = stack.peek();          // Peek don't pop yet

            if (!visited.contains(node)) {
                // First visit: open paren + add value
                visited.add(node);
                sb.append("(").append(node.val);

                // Push children (right first — LIFO)
                if (node.left == null && node.right != null) {
                    sb.append("()");               // Empty left needed for clarity
                }
                if (node.right != null) stack.push(node.right);
                if (node.left  != null) stack.push(node.left);

            } else {
                // Second visit: close paren, pop
                stack.pop();
                sb.append(")");
            }
        }

        // Remove outermost parentheses added for root
        return sb.substring(1, sb.length() - 1);
    }
}
```

### 🔍 Iterative Dry Run
```

Peek 1: not visited → visited={1}
  sb="(1"
  left=2,right=3 → push 3, push 2
  Stack:[1,3,2]

Peek 2: not visited → visited={1,2}
  sb="(1(2"
  left=4,right=null → push 4 only
  Stack:[1,3,2,4]

Peek 4: not visited → visited={1,2,4}
  sb="(1(2(4"
  no children
  Stack:[1,3,2,4]

Peek 4: visited → pop, sb="(1(2(4)"
  Stack:[1,3,2]

Peek 2: visited → pop, sb="(1(2(4))"
  Stack:[1,3]

Peek 3: not visited → visited={1,2,3,4}
  sb="(1(2(4))(3"
  no children
  Stack:[1,3]

Peek 3: visited → pop, sb="(1(2(4))(3)"
  Stack:[1]

Peek 1: visited → pop, sb="(1(2(4))(3))"

Strip outer parens → "1(2(4))(3)" ✅
```

# 🟡 LC 105 — Construct Binary Tree from Preorder and Inorder Traversal

## Intuition
Preorder's first element is always root. Find that root in inorder — everything to its left is the left subtree, everything to its right is the right subtree. Use a HashMap for O(1) inorder lookups. Advance preorder index as you build left subtree first, then right.

### Arrays used:
```
preorder = [3, 9, 20, 15, 7]
inorder  = [9, 3, 15, 20, 7]

preorder[0]=3 → ROOT
Find 3 in inorder at index 1
Left inorder:  [9]       (indices 0..0) → 1 node
Right inorder: [15,20,7] (indices 2..4) → 3 nodes
```

---

### ✅ Recursive Solution
```java
class Solution {
    int preIdx = 0;
    Map<Integer, Integer> inorderMap = new HashMap<>();

    public TreeNode buildTree(int[] preorder, int[] inorder) {
        // O(1) lookup for root position in inorder
        for (int i = 0; i < inorder.length; i++)
            inorderMap.put(inorder[i], i);

        return build(preorder, 0, inorder.length - 1);
    }

    private TreeNode build(int[] preorder, int left, int right) {
        if (left > right) return null;              // No elements in range

        int rootVal = preorder[preIdx++];            // Consume next preorder value
        TreeNode root = new TreeNode(rootVal);

        int mid = inorderMap.get(rootVal);           // Split point

        // Build LEFT first — preIdx must advance through left subtree
        root.left  = build(preorder, left, mid - 1);
        root.right = build(preorder, mid + 1, right);

        return root;
    }
}
```

### ✅ Iterative Solution (Stack)
```java
class Solution {
    public TreeNode buildTree(int[] preorder, int[] inorder) {
        if (preorder.length == 0) return null;

        Stack<TreeNode> stack = new Stack<>();
        TreeNode root = new TreeNode(preorder[0]);
        stack.push(root);

        int inIdx = 0;                              // Pointer into inorder

        for (int preIdx = 1; preIdx < preorder.length; preIdx++) {
            TreeNode node = new TreeNode(preorder[preIdx]);
            TreeNode parent = null;

            // Pop nodes whose inorder value matches → we've finished their left subtree
            while (!stack.isEmpty() && stack.peek().val == inorder[inIdx]) {
                parent = stack.pop();
                inIdx++;
            }

            if (parent != null) {
                parent.right = node;               // Attach as RIGHT child
            } else {
                stack.peek().left = node;          // Attach as LEFT child
            }

            stack.push(node);
        }
        return root;
    }
}
```

# 🟡 LC 106 — Construct Binary Tree from Inorder and Postorder Traversal

## Intuition
Postorder's LAST element is always the root (mirror of preorder). Find root in inorder to split left/right subtrees. Process postorder index from right to left, building RIGHT subtree before LEFT (mirror of preorder approach).

### Arrays used:
```
inorder   = [9, 3, 15, 20, 7]
postorder = [9, 15, 7, 20, 3]
                             ↑
                       ROOT = 3 (last element)
```

---

### ✅ Recursive Solution
```java
class Solution {
    int postIdx;
    Map<Integer, Integer> inorderMap = new HashMap<>();

    public TreeNode buildTree(int[] inorder, int[] postorder) {
        postIdx = postorder.length - 1;            // Start from END of postorder

        for (int i = 0; i < inorder.length; i++)
            inorderMap.put(inorder[i], i);

        return build(postorder, 0, inorder.length - 1);
    }

    private TreeNode build(int[] postorder, int left, int right) {
        if (left > right) return null;

        int rootVal = postorder[postIdx--];         // Consume from END
        TreeNode root = new TreeNode(rootVal);

        int mid = inorderMap.get(rootVal);

        // Build RIGHT first — postIdx reads right subtree before left from end
        root.right = build(postorder, mid + 1, right);
        root.left  = build(postorder, left, mid - 1);

        return root;
    }
}
```

### 🔍 Recursive Dry Run
```

postIdx=4

  rootVal=post[4]=3, postIdx=3
  mid=1, root=node(3)

  RIGHT: build(post, 2, 4)     ← inorder[2..4]=[15,20,7]
    rootVal=post[3]=20, postIdx=2
    mid=3, root=node(20)
    RIGHT: build(post,4,4)     ← inorder[4]=[7]
```

### ✅ Iterative Solution (Stack — mirror of LC 105)
```java
class Solution {
    public TreeNode buildTree(int[] inorder, int[] postorder) {
        if (postorder.length == 0) return null;

        Stack<TreeNode> stack = new Stack<>();
        int n = postorder.length;
        TreeNode root = new TreeNode(postorder[n - 1]);
        stack.push(root);

        int inIdx = n - 1;                          // Inorder pointer from right

        for (int postIdx = n - 2; postIdx >= 0; postIdx--) {
            TreeNode node = new TreeNode(postorder[postIdx]);
            TreeNode parent = null;

            // Pop nodes whose inorder matches → finished right subtree
            while (!stack.isEmpty() && stack.peek().val == inorder[inIdx]) {
                parent = stack.pop();
                inIdx--;
            }

            if (parent != null) {
                parent.left = node;                 // Attach as LEFT child
            } else {
                stack.peek().right = node;          // Attach as RIGHT child
            }
            stack.push(node);
        }
        return root;
    }
}
```

# 🟡 LC 109 — Convert Sorted List to Binary Search Tree

## Intuition
Find middle of linked list using slow/fast pointers — that's the root. Cut the list before middle so left half is a separate list. Recurse on left half and right half (from middle.next onward). This mirrors the sorted array approach but uses pointer-based mid finding.

### List used:
```
-10 → -3 → 0 → 5 → 9

Find mid using slow/fast:
slow=-10,fast=-10
slow=-3, fast=0
slow=0,  fast=9   ← fast.next=null, stop

mid=0 → ROOT
Left:  -10→-3 (cut before mid)
Right: 5→9   (mid.next onward)
```

---

### ✅ Recursive Solution (Slow/Fast Pointer)
```java
class Solution {
    public TreeNode sortedListToBST(ListNode head) {
        if (head == null) return null;
        if (head.next == null) return new TreeNode(head.val); // Single node

        // Find middle with slow/fast pointers
        ListNode prev = null;
        ListNode slow = head;
        ListNode fast = head;

        while (fast != null && fast.next != null) {
            prev = slow;
            slow = slow.next;
            fast = fast.next.next;
        }

        // Cut list: left half ends at prev
        if (prev != null) prev.next = null;

        TreeNode root = new TreeNode(slow.val);    // Mid = root
        root.left  = sortedListToBST(head);        // Left: head to prev
        root.right = sortedListToBST(slow.next);   // Right: after mid

        return root;
    }
}
```

### ✅ Iterative Solution (Convert to array first)
```java
class Solution {
    public TreeNode sortedListToBST(ListNode head) {
        // Convert list to array for O(1) random access
        List<Integer> vals = new ArrayList<>();
        while (head != null) {
            vals.add(head.val);
            head = head.next;
        }

        // Now same as LC 108 — sorted array to BST
        return build(vals, 0, vals.size() - 1);
    }

    private TreeNode build(List<Integer> vals, int left, int right) {
        if (left > right) return null;

        int mid = left + (right - left) / 2;
        TreeNode root = new TreeNode(vals.get(mid));

        root.left  = build(vals, left, mid - 1);
        root.right = build(vals, mid + 1, right);

        return root;
    }
}
```

> 💡 **Note:** The array conversion approach is O(N) time and O(N) space. The slow/fast pointer approach is O(N log N) time but O(log N) space (no array). The array approach is preferred in interviews for clarity unless O(1) extra space is required.

# 🔴 LC 1008 — Construct BST from Preorder Traversal

## Intuition
Use BST property to avoid needing inorder. Pass valid `[min, max]` range for each node. Process preorder left to right — consume next element only if it falls within current valid range, otherwise it belongs to a different subtree.

### Array used:
```
preorder = [8, 5, 1, 7, 10, 12]

BST ranges:
8  → root     (−∞, +∞)
5  → 5 < 8   → left  of 8 (−∞, 8)
1  → 1 < 5   → left  of 5 (−∞, 5)
7  → 7 > 1, in (5,8) → right of 5 (5, 8)
10 → 10 > 8  → right of 8 (8, +∞)
12 → 12 > 10 → right of 10 (10, +∞)
```

---

### ✅ Recursive Solution (Bounds Trick)
```java
class Solution {
    int idx = 0;

    public TreeNode bstFromPreorder(int[] preorder) {
        return build(preorder, Integer.MIN_VALUE, Integer.MAX_VALUE);
    }

    private TreeNode build(int[] preorder, int min, int max) {
        if (idx == preorder.length) return null;

        int val = preorder[idx];

        // Current value outside valid range → doesn't belong in this subtree
        if (val < min || val > max) return null;

        idx++;                                      // Consume this element
        TreeNode root = new TreeNode(val);

        // Left subtree: values must be < val
        root.left  = build(preorder, min, val);
        // Right subtree: values must be > val
        root.right = build(preorder, val, max);

        return root;
    }
}
```

### ✅ Iterative Solution (Stack with bounds)
```java
class Solution {
    public TreeNode bstFromPreorder(int[] preorder) {
        if (preorder.length == 0) return null;

        TreeNode root = new TreeNode(preorder[0]);
        Stack<TreeNode> stack = new Stack<>();
        stack.push(root);

        for (int i = 1; i < preorder.length; i++) {
            TreeNode node = new TreeNode(preorder[i]);
            TreeNode parent = stack.peek();

            // Find correct parent: pop until we find where this node belongs
            while (!stack.isEmpty() && preorder[i] > stack.peek().val) {
                parent = stack.pop();               // This could be our parent
            }

            // Attach node
            if (preorder[i] < parent.val) {
                parent.left  = node;                // Goes left of parent
            } else {
                parent.right = node;                // Goes right of last popped
            }

            stack.push(node);
        }
        return root;
    }
}
```

# 🔴 LC 889 — Construct Binary Tree from Preorder and Postorder Traversal

## Intuition
Preorder[0] = root. Preorder[1] = left child's root. Find preorder[1] in postorder — everything before it in postorder is the left subtree. Use left subtree size to split both preorder and postorder arrays. Recurse on each half.

### Arrays used:
```
preorder  = [1, 2, 4, 5, 3, 6, 7]
postorder = [4, 5, 2, 6, 7, 3, 1]

pre[0]=1 → ROOT
pre[1]=2 → left child root
Find 2 in postorder at index 2
Left subtree size = 2+1 = 3
Left preorder:  [2,4,5]      (pre[1..3])
Left postorder: [4,5,2]      (post[0..2])
Right preorder:  [3,6,7]     (pre[4..6])
Right postorder: [6,7,3]     (post[3..5])
```

---

### ✅ Recursive Solution
```java
class Solution {
    int preIdx = 0;
    Map<Integer, Integer> postMap = new HashMap<>();

    public TreeNode constructFromPrePost(int[] preorder, int[] postorder) {
        // Map postorder values to indices for O(1) lookup
        for (int i = 0; i < postorder.length; i++)
            postMap.put(postorder[i], i);

        return build(preorder, postorder, 0, postorder.length - 1);
    }

    private TreeNode build(int[] preorder, int[] postorder,
                           int postLeft, int postRight) {
        if (postLeft > postRight) return null;

        TreeNode root = new TreeNode(preorder[preIdx++]); // Next preorder = root

        if (postLeft == postRight) return root;            // Leaf node

        // Left child root = preorder[preIdx]
        int leftChildRoot = preorder[preIdx];
        int leftChildPostIdx = postMap.get(leftChildRoot); // Position in postorder
        int leftSize = leftChildPostIdx - postLeft + 1;    // Size of left subtree

        // Left subtree: postorder[postLeft .. leftChildPostIdx]
        root.left  = build(preorder, postorder,
                           postLeft, leftChildPostIdx);

        // Right subtree: postorder[leftChildPostIdx+1 .. postRight-1]
        root.right = build(preorder, postorder,
                           leftChildPostIdx + 1, postRight - 1);

        return root;
    }
}
```

### ✅ Iterative Solution (Stack)
```java
class Solution {
    public TreeNode constructFromPrePost(int[] preorder, int[] postorder) {
        Stack<TreeNode> stack = new Stack<>();
        TreeNode root = new TreeNode(preorder[0]);
        stack.push(root);

        int postIdx = 0;                           // Points to expected left subtree root in postorder

        for (int preIdx = 1; preIdx < preorder.length; preIdx++) {
            TreeNode node = new TreeNode(preorder[preIdx]);

            // Assign as left child if possible, else right child
            while (stack.peek().val == postorder[postIdx]) {
                stack.pop();                       // This node's subtree is complete
                postIdx++;
            }

            if (stack.peek().left == null) {
                stack.peek().left  = node;         // Fill left first
            } else {
                stack.peek().right = node;         // Then right
            }

            stack.push(node);
        }
        return root;
    }
}
```

# 📊 Final Summary Table

| Problem | Key Technique | Golden Trick |
|---|---|---|
| LC 108 — Sorted Array → BST | Divide and conquer | `mid = left+(right-left)/2` as root every time |
| LC 617 — Merge Two Trees | Simultaneous DFS | Return non-null node when one tree is null |
| LC 606 — Tree to String | Preorder DFS | Omit right `()` if null; NEVER omit left `()` if right exists |
| LC 105 — Pre+Inorder | preIdx + inorderMap | Build LEFT before RIGHT; HashMap for O(1) split |
| LC 106 — Post+Inorder | postIdx from end | Build RIGHT before LEFT; consume postorder right to left |
| LC 109 — List → BST | Slow/fast pointer mid | Cut list before mid; recurse on two halves |
| LC 1008 — BST from Preorder | Min/max bounds | Skip element if outside `(min,max)` range |
| LC 889 — Pre+Postorder | Left subtree size | `pre[preIdx+1]` in postorder gives left subtree boundary |

---

## 💡 3 Golden Rules for Tree Construction

> **Rule 1:** **Preorder first = root, Postorder last = root.** Find that root in Inorder to split left and right subtrees. This is the universal construction algorithm.
>
> **Rule 2:** **Left before Right in Preorder, Right before Left in Postorder.** The order you build subtrees must match the order the index is consumed.
>
> **Rule 3:** **Always use a HashMap for inorder index lookup.** Linear search makes it O(N²). HashMap makes it O(N) — a critical optimization in every construction problem.
